# Яркие субтитры N1–N12 (HyperFrames + GSAP)

`bright-n1-n12.html` — рабочая композиция-демо: 12 стилей на реальной речи (word timings).
Каждый стиль — ветка в цикле по словам (`st === "neon"`, `"d3"`, `"grad"` …): копируй нужную в ролик,
подставь свои слова/время в массив `P`. Шрифты: Google Fonts (Dela Gothic One, Montserrat, Rubik,
Russo One, Exo 2, Comfortaa, Sofia Sans Extra Condensed) в `assets/fonts/`. Описание: vault/03-techniques/caption-styles-catalog.md.

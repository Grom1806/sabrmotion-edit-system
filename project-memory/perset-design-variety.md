User (2026-10-18): don't use the same PERSET colors/brandbook every time. Sometimes pure white background instead of cream, sometimes other accent colors, different styles per reel, glowing/gradient text on key phrases. Logo and fonts stay.

**Why:** reels looked repetitive.
**Update (2026-10-18, same day):** user corrected: main colors stay by default, not a new palette every video; ask each time (color question in ask-before-edit).
**How to apply:** before each PERSET reel ask "основные цвета или вариант?" and offer these variants (white bg, other accent, glowing text); no answer = main brand colors. Log the choice in the reel lesson note. See [[client-perset]], [[variety]].

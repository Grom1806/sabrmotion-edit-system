User (2026-10-08): heavy motion kills context (viewer watches effects/sounds, misses the point, rewatches or drops off). Edit must support the words. Before every edit ask which tier; no answer = Стандарт.

- **Минимал** (ready studio): frame/background untouched, color grade + spot subtitles on key phrases only, face 100%, SFX ~0, music optional.
- **Стандарт** (default, refined 2026-10-11): background NEVER changes or is replaced, speaker in own frame 100%, full animated subtitles in fresh modern styles, graphics without backing float over the frame in front of the speaker but never fully cover the face; event every 1.5-2.5 s, SFX 0.3-0.5/s quiet, no full-screen scenes/PiP/shake/glitch/particles.
- **Мощный**: reference style IMG_6708/6709, face 35-50%, event every 0.8-1.2 s, SFX ~1/s, a calm 1-1.5 s "breath" every 6-8 s.
- **Ультра**: full [[motion-library]] density (reel 2 v3), event every 0.4-0.8 s, SFX 1.5-2.3/s.

Full spec: /mnt/project-files/lessons/motion-tiers.md (PC copy claude-edit\_lessons\motion-tiers.md, synced by the PC session on next edit).

**Why:** different clients need different density; meaning must read on first view.
**How to apply:** ask tier in the brief, log it in [[edit-lessons-log]]; [[motion-library]] / [[reference-style]] numbers apply to Мощный/Ультра only.

User 2026-10-21: «все наши техники использовать по ситуации», «не должны быть использованы каждый раз», «потом у нас будут одинаковые видео каждый раз».

Rule vault/01-rules/techniques-by-situation.md (SYSTEM.md item 11). Every per-reel quota in the vault is now a guideline, not a requirement. That includes ≥N techniques, ≥4 transition types, 3 wow moments, 3-5 UI-card techniques, ≥5 of the 64 techniques, ≥1 never-used asset+technique, and the pro-baseline items. Pick only what fits the beat and the video type.

**Why:** mandatory checklists make every reel look the same.
**How to apply:**
- In the brief, add a line «Приёмы этого ролика».
- Don't repeat the hook move, main transition, main text move or finale from the last 2-3 reels in 04-lessons/reels.
- Log «Взятые приёмы» in each lesson note.
- Within a reel too (user 2026-10-21 13:57): a technique is an accent in 1-3 scenes. Never every scene, never two scenes in a row; some scenes get no technique at all. Mark each beat in the storyboard.
- Quality norms and bans (sharpness, no grain, reading time, SFX tied to events, no music, original background) stay mandatory.

The main «Пульт монтажа» panel asks about this (since 2026-10-21). techmode: situ/mine/clean/rich. repeat: fresh/series/part. pro: T1/T3–T7/angles/vtext/scale/card. Spec in vault/07-system/control-panel.md. Ticked techniques are wishes, not quotas. When building new topic panels, include these questions.

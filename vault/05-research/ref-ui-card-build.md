# Как сделан моушен «UI-карточка» и как это повторять

Пользователь 2026-10-20: «научись этому дизайну монтажа… в дальнейшем будешь использовать эти техники». Тайминг по секундам: reels/2026-10-20_ref-ui-card/breakdown.md. Здесь — **почему это красиво** и рецепты.

## Главная идея
Одна сцена, один объект, ноль резов. Весь ролик — **камера, которая гуляет по одной карточке**, пока карточка сама себя достраивает. Глаз всегда знает, куда смотреть: в каждый момент рождается ровно одна вещь, и камера уже едет к месту, где родится следующая.

## 16 техник

**Рождение объекта**
1. **Линия → карточка.** Первый кадр — едва видимая серая линия (opacity ~20 %), за 0.1 с темнеет, потом растёт ТОЛЬКО по высоте: 0.1→1.0 с, ширина постоянная, скругление в px постоянное (поэтому линия сначала выглядит пилюлей). Кривая ease-in-out: высота 6→12→26→46→70→90→103→112→118 (из 118) по десятым — медленный старт, быстрая середина, долгий мягкий settle, без overshoot. AE: shape-прямоугольник, ключи Size Y, Roundness фиксированный, Influence 70/80 %.
2. **Тень растёт вместе с объектом.** Мягкая тень (blur ~60, opacity ~20 %, сдвиг вниз ~4 % высоты) есть с первого кадра линии, растёт с ней — объект сразу «весит».
3. **Контейнер растёт с контентом.** Белая панель въезжает снизу внутри карточки (1.1–1.5 с), упирается в верх — и карточка сама вытягивается в высоту, освобождая место (1.5–1.8 с). Ничего не «вставлено» в готовую рамку, рамка подстраивается.
4. **Рифма формы.** Тот же приём «линия → блок» повторяется внутри: серая вертикальная полоска → длинная пилюля → скруглённый квадрат → широкая плашка «Have a project…» (6.1–6.6 с; сначала растёт высота, потом ширина). Один мотив проходит через весь ролик — это и даёт ощущение дизайна, а не набора эффектов.

**Камера**
5. **Расфокус-переход вместо реза.** 1.8–2.1 с: камера влетает в карточку (масштаб ×2.5+) и одновременно весь кадр уходит в сильный гауссов blur (~20–30 px), на 2.1–2.4 с резкость возвращается уже в новом крупном плане. Работает как рез, но без склейки. Тот же приём на финальном отъезде (12.7–13.0 с).
6. **Живая камера по станциям.** Кадр разбит на «станции»: заголовок слева → хэндл и плашка справа → цена и кнопка слева → список снизу слева → список снизу справа → общий план. Между станциями проезд 0.5–0.7 с с motion blur + лёгким расфокусом на пике скорости. **На станции камера не стоит**: медленный дрейф (push-in ~2–3 % или боковой сдвиг), поэтому кадр никогда не мёртвый.
7. **Проезд = диагональ + зум.** Ни один проезд не чисто горизонтальный: pan по X сочетается со сдвигом по Y и изменением масштаба (едет вправо и чуть наезжает), плюс лёгкий наклон перспективы карточки. AE: 3D-камера или нуль «Камера» с Position+Scale, ease 33/80, Motion Blur 180°/16 сэмплов + Camera Lens Blur, ключ на пике скорости.
8. **Камера опережает контент.** Новый элемент начинает рождаться, когда камера ещё доезжает (последние 20–30 % проезда). Нет паузы «приехали — ждём».
9. **Кадрирование с обрезкой.** Карточка почти всегда обрезана краем кадра, текст режется на полуслове («eos», «ople watching»). Это ощущение близости и масштаба, крупный текст при этом занимает 40–60 % ширины.

**Типографика**
10. **Побуквенная волна блюра.** Каждая буква: opacity 0→100, blur ~12→0 px, scale 115→100 %, y +8→0, светлее→свой цвет; длительность одной буквы ~0.25 с, шаг между буквами ~65–75 мс, значит одновременно «проявляются» 3–4 буквы — бегущая волна резкости слева направо. AE: Text Animator (Opacity, Blur, Scale, Position, Fill Color), Range Selector по Characters, Offset ключами, Shape = Ramp Up, Ease High 60 / Low 0, Smoothness 100 %. Конечный blur ровно 0 ([[sharpness-guard]]).
11. **Иерархия временем.** Заголовок чёрный жирный печатается побуквенно; серая вторая строка — пословно и быстрее, наезжая на конец первой; мелкий надзаголовок — сначала звёздочки ✦ по краям, потом текст «заполняет» пространство между ними.
12. **Звук = буква.** Каждая буква — свой тик кадр в кадр ([[sfx-expressive]]).

**UI-элементы**
13. **Заглушка-предвестник.** Иконка следующего пункта списка (чек-кружок) появляется бледной ДО своего текста, а иконка «!» — точкой, которая раздувается. Глаз заранее знает, где будет следующая строка.
14. **Кнопки как физические объекты.** Пилюля «Work with me» въезжает снизу с blur, overshoot ~105 %, settle в 100 %; тень растёт с задержкой 2–3 кадра — кнопка «приземляется» на поверхность.
15. **Каскад списка.** Пункты через ~0.25 с: иконка → текст blur-in → следующая иконка уже видна. Вторая колонка запускается во время проезда камеры к ней.

**Финал**
16. **Сборка → общий план → точка.** Расфокус-отъезд показывает всю карточку целиком (награда: «вот что собралось»), 0.8 с покоя с лёгким дыханием масштаба, затем карточка схлопывается в точку (ease-in) — зеркало начала (линия из ничего → точка в ничто). Идеальная петля для зацикленного просмотра.

## Палитра и ритм
Монохром: фон #ECECEC, карточка #131410 с диагональным бликом, панель #FDFDFD, серый текст #8A8A8A, пилюли #E2E2E2. Никаких акцентных цветов — красоту делают движение, типографика и тени. Событие каждые 0.3–0.5 с, паузы-«вдохи» 0.5–0.8 с только на проездах.

## Как использовать в наших роликах
- Любой список услуг/фич/фактов → карточка, достраивающая себя, + камера по станциям (техники 1, 3, 6, 13, 15).
- Переход между темами без реза → расфокус-влёт (5).
- Заголовки хука → побуквенная волна блюра + тик на букву (10, 12).
- Мотив «линия → блок» как фирменная рифма ролика (4).
- Финал-петля «в точку» (16) для зацикливания рилса.
Брендовый вариант: тот же приём в цветах бренда (Sabrmotion: графит + один красный/зелёный акцент), но монохромный исходник хорош сам по себе. Камера разрешена ([[camera-allowed]]).

# SaaS-промо на пастели (IMG_0577, IMG_0584)

## IMG_0577 — промо приложения HowDo (48 с, 16:9)
Берём монтаж внутри карточки (табы Intro/Problem/Use Case/CTA и фиолетовая рамка вокруг = упаковка автора, не копируем).

**Идея ролика:** классическая продуктовая реклама «проблема → решение → сценарии → призыв». Проблема подана как ощущение («каждый день есть что-то, в чём хочется разобраться»), решение — одно слово «Simple», дальше 3 сценария жизни (дом/еда, покупка по QR, обучение), финал «Learn it. Do it. Make it Done».

**Внутри по секундам:**
- 0–2.5 Intro: телефон в руках (экран 9:41), над ним вылетают глянцевые 3D-объекты (шары, звёзды, фрукты) и надпись «HowDo» с хроматическим объёмом.
- 2.5–9 Problem: белый фон с лиловой «дымкой» снизу; «Every day, there's something exciting to figure out.» — слова появляются по одному, слово «something» фиолетовым; затем **слова превращаются в мелкие иконки** (day → значки-эмодзи вылетают из буквы) и обратно.
- 9.5–12.5: «You just want solution?» → вокруг текста **вырастает кольцо из фото-карточек и 3D-объектов**, вращается (орбита), «but find the solution».
- 13: «S im pl e» — буквы разъезжаются по направляющим сетки (видны тонкие линии-гайды), собираются.
- 13.5–15: точка → кольцо-логотип → «O» становится частью «HowDo» (**логотип из буквы**).
- 15.5–19: фон-пейзаж, отъезд камеры: пейзаж оказывается обоями на **iMac**, сбоку въезжает человек за ноутбуком (живое видео в окне), потом снова зум внутрь экрана iMac → интерфейс поиска: курсор печатает «want pizza», кликает.
- 24–26: **телефон горизонтально в руках**, внутри видео как делают пиццу + UI рецепта поверх.
- 26.5–30: «Whatever you are doing» (слова прыгают по разным строкам), «can guide you», «New [иконка-рука/ноутбук/будильник меняются] product» — **слот-иконка между словами**, курсор кликает её.
- 30–33: живое видео: коробка с QR, рамка-сканер находит QR; переход — телефон встаёт в кадр и экран показывает этот QR (**match cut через телефон**).
- 33–38: телефон на градиенте, экран листается (продукт → видео-уроки), вокруг облачка-подсказки и иконки.
- 38.5–40: «Learn it / Do it / Make it Done|» — набор с курсором, слова стираются и перепечатываются.
- 40.5–44: облака, логотип собирается из кольца, затемнение в чёрное, финал Instagram.

## IMG_0584 — пересборка UI Revolut (19 с, 16:9)
Пастельный размытый градиент (бирюза/розовый/персик) на весь фон. Логотип R + «Business» печатается → карточка логина **собирается по полям** (поле пароля, кнопка), точки пароля заполняются → список «Popular Stocks» въезжает строками с лёгким stagger и блюром → баланс «£2,503.73» **дотикивает до £2,840.05**, под ним рисуется линия графика слева направо, кнопки-иконки всплывают по одной → всё растворяется в блюр, остаётся «R», дописывается «Revolut» → бейдж-автограф автора.

**Идея IMG_0584:** без слов показать «весь банк за 15 секунд»: вход → рынок → твой баланс растёт → бренд. Каждый экран приложения = один кадр-мысль.

**Приёмы для нас:**
1. Структура «проблема → одно слово-решение → 3 сценария → призыв».
2. **Слово → иконка** и **слот-иконка** между словами («New [🖐→💻→⏰] product»).
3. **Кольцо-орбита карточек** вокруг ключевой фразы (лучше любого коллажа).
4. **Логотип из буквы**: точка → кольцо → буква O.
5. **Зум из экрана в экран** (пейзаж → обои iMac → интерфейс), **match cut через телефон** (реальный QR → QR на экране).
6. **UI собирается по элементам**, число дотикивает, график рисуется — готовый рецепт для финансовых тем (PERSET!).
7. **Печать–стирание–перепечатка** с курсором («Learn it → Do it → Make it Done»).

**Как собрать:** HyperFrames/GSAP, фон — Stripe-подобный mesh-градиент ([[brand-stripe]]); iMac/телефон-мокапы PNG + видео внутрь через CSS-маску; 3D-объекты из Blender (глянцевые сферы, [[motion-balls]]).
**Звук (без музыки):** мягкие «pop» на иконки, клик курсора, клавиатурный набор, «whoosh» на зум в экран, тики на дотикивающее число.
**Уровень:** Стандарт (UI-сборка, слово→иконка, тики) – Мощный (орбита, зум экран-в-экран). Пастель подходит не всем брендам: для SABRMOTION переводить в чёрный + акцент.

# Портфолио-визитка «это Ихсан» (IMG_0579)

**Идея ролика:** рассказ о монтажёре в третьем лице («это Ихсан… он сотрудничал с…»), как визитка-рекомендация: кто он → с кем работал → в чём подход → цифры → «и это лишь часть работ».

**Покадрово:**
- 0–1: слева скруглённая карточка с фото героя, справа «это Ихсан» — имя зелёным градиентом с хроматическим свечением.
- 1–2.5: **тёмная шторка въезжает слева** (чёрная панель с мягким краем), на ней синие фигуры (квадрат, круг, звезда, «солнце»-шестерёнка) плавают и вращаются; «видео-монтажер» → «контент-producer», последние буквы переливаются фиолетово-розовым градиентом; слово сменяется через блюр на месте.
- 2.5–4: белый фон, **3D-иконка часов iOS** + «за время своей работы»; иконка уезжает, текст сжимается и меняется («он сотрудничал»).
- 4.5–9: **веер из скриншотов профилей Instagram**, стоящих в 3D-перспективе (как карты), камера скользит; сверху меняются слова-категории: «строительными компаниями / ресторанами / заведениями / предпринимателями / медиа-личностями».
- 9.5–13: **3D-иконка портфеля** (эмодзи-стиль) → разворачивается в тёмно-синюю карточку, справа список «отдельный ✦ стиль ✦ задача ✦ подход» пунктами по одному; карточка уменьшается.
- 13.5–21.5: стопка видео-кадров разлетается → **экран режется на 4–5 вертикальных полос**, в каждой свой клип из портфолио; слева герой говорит в кадр; поверх субтитр-фраза по слову («самая ошибка», «которую сделают», «сделай красиво»), часть слов в фигурных скобках { } или на красной плашке «не продают».
- 22–22.5: «за его плечами» — текст **влетает с 3D-поворотом** (наклон по перспективе) и выравнивается.
- 23–24.5: **цифра «10» жёлтым на тёмной скруглённой плитке**, вокруг цветные лучи (оранжевый/синий/розовый) крутятся, подпись «роликов».
- 25–27: «которые набирали миллионы просмотров» — **сверхплотный текст стопкой** (кернинг минус), «и это лишь его работ»; финал Instagram.

**Приёмы для нас:**
1. **Тёмная шторка-панель** с плывущими фигурами как переход белое → тёмное.
2. **Веер профилей/скринов в 3D** под словами-категориями (клиенты, кейсы).
3. **Эмодзи-3D-иконка разворачивается в карточку-список**.
4. **Экран из вертикальных полос-клипов** + говорящая голова слева = «вот моё портфолио» за 2 секунды.
5. **Цифра-герой в лучах** ([[brand-spotify-wrapped]] в другом исполнении).
6. Слова в { } и на плашке как акцент внутри субтитра.

**Для SABRMOTION:** почти готовый шаблон рилса-визитки (кто я → с кем работал → как работаю → цифры → CTA). Музыку автора не берём.
**Как собрать:** HyperFrames/GSAP; иконки 3D — из asset-паков или Blender; полосы-клипы через clip-path; лучи — conic-gradient с вращением.
**Звук (без музыки):** swipe на шторку, «card flip» на веер, pop на пункты списка, «riser + hit» на «10».
**Уровень:** Стандарт – Мощный.

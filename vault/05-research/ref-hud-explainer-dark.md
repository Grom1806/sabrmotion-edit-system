# Тёмный HUD-эксплейнер (IMG_0578)

Берём только монтаж, который идёт НА ЭКРАНЕ (ноутбук и съёмка комнаты = упаковка автора, её не копируем). Внутренний ролик ~70 с.

**Идея ролика:** «ИИ пишет анимацию кодом, а не рендерит картинку». Структура: вопрос-хук «What if I told you…» → обещание (motion graphics без After Effects) → «как это работает» (код → рендер → видео) → демо (команды словами меняют анимацию) → возражение анкетой «заменит ли AE? — NOT REALLY, но для этих задач да» → итог одной строкой «PRETTY INSANE.». Каждая мысль = своя мини-сцена-схема, объяснение через визуальную метафору, а не через текст.

**Что видно внутри (по секундам внутреннего ролика):**
- 0–3: курсор-точка, затем «What if I told you» печатается с красным свечением букв; фон: тёмная миллиметровая сетка + оранжевые направляющие (перекрестие).
- 3–5: «you can create MOTION GRAPHICS» — огромные слова, сначала оранжевым светом, потом остывают в белый (цвет как температура).
- 5–8: «without even opening After Effects?» поверх схемы таблицы, которую перечёркивает оранжевый X.
- 8–11: «And no —» + блок-схема (CLAUDE → SKY ARROW → AFTER EFFECTS), искра бежит по линии; глитч-растяжение по горизонтали как переход.
- 12–15: «This is CLAUDE OPUS 5.5» — хедлайн, цифры добиваются по одной.
- 15–20: график easing-кривой, «Instead of controlling After Effects, you basically tell Claude» — фраза в рамке-«поле ввода».
- 20–30: промпт печатается моноширинным шрифтом на 3D-наклонённой сетке-полу, ключевые слова подсвечены оранжевой плашкой (cinematic, kinetic typography, 3D elements, seamless camera movement); вокруг всплывают каркасные 3D-фигуры.
- 31–33: промпт размазывается горизонтальными полосами (streak), иконка ↵ влетает огромной оранжевой стрелкой → весь экран оранжевый, «AND THIS IS WHERE IT GETS CRAZY.» по одному слову (8 кадров/с видно: слово влетает с motion blur, на смене слов кадр-«склейка» с наложением двух слов).
- 33–40: «Claude doesn't actually generate an MP4 directly» — схема с крестиком, затем коробочка «code» с неоном, «It writes the animation itself as code» + слева код, справа превью.
- 40–50: превью-окно: слово MOTION, круг, квадрат, подписи-выноски «positions, shapes, transitions, particles, easing» появляются у объектов. Окно делает 3D-поворот, на ребре вспыхивает белым (засветка на всё окно ~0.5 с), возвращается уже с новыми подписями = «перезагрузка» сцены.
- 50–55: «Then that code is rendered frame by frame» — по превью пробегает оранжевая линия-сканер, окно размножается в киноленту из копий-кадров, лента едет в перспективе; «and turned into a video» — лента схлопывается в один плеер, кнопка Play заливается оранжевым.
- 11–12 (начало): «And no —» схема рассыпается горизонтальным глитчем, остаётся оранжевая искра в центре, от неё прочерчивается линия-подчёркивание, на ней пишется «This is», затем «CLAUDE» вспыхивает раскалённым оранжевым и остывает.
- 54–64: смена мира: светлая «бумажная анкета» FORM 2-B (монохром, машинописный шрифт), схема After Effects → layers → keyframes → graph editor перечёркивается красной линией от руки, затем Prompt → code → render → video и штамп «NO KEYFRAMES».
- 64–70: словарная статья «pro·ce·dur·al (adj.)» с определением (антиква, как в словаре).
- 70–80: «you can literally tell Claude:» — слева превью (квадрат ↔ круг), справа чат-список команд («Make this transition smoother», «Change the colour», «Slow this section down», «Make the ending loop») — каждая команда сразу меняет превью (белый → оранжевый, квадрат → круг).
- 79–82: «instead of you manually moving hundreds of keyframes» — экран заполняется сотнями ромбиков-ключей, они осыпаются.
- 82–88: FORM 9 «Does this replace After Effects?» с чекбоксами YES / NO / NOT REALLY (отмечен), затем список «But for certain types of motion graphics» с галочками.
- 88–93: дуга от точки «idea» к окну «working animation», под ней таймлайн «without touching a timeline».
- 93–94: «PRETTY INSANE.» огромным, оранжевый → белый.

**Приёмы для нас:**
1. **Субтитр-подсветка по слову**: фраза уже стоит серым, текущее слово загорается акцентом (оранжевый) и остывает в белый. Лучше обычных субтитров для эксплейнеров.
2. **Сетка-чертёж + направляющие** как фон для техно-тем (ИИ, софт, цифры).
3. **Промпт-строка, которая печатается**, с подсветкой ключевых слов плашкой.
4. **Вспышка на смене акта**: весь экран акцент + 4 слова по одному (smash-cut типографика) = «вау» на переломе.
5. **«Бумажная» вставка** (анкета, чек-лист, словарная статья) посреди тёмного ролика: смена фактуры удерживает внимание. Вопрос-чекбокс YES/NO/NOT REALLY = готовый приём для «мифов».
6. **Команда → результат**: список фраз справа, каждая сразу меняет объект слева (до/после в реальном времени).
7. **Перечёркивание от руки** старого процесса и штамп-итог.

**Как собрать:** HyperFrames/GSAP (текст по словам из whisper-таймингов, SVG-линии через stroke-dashoffset, 3D-наклон сетки через CSS perspective); флип окна, ленту кадров и streak-размазывание точнее сделать в After Effects MCP. Ролик собираем как полноэкранный, без рамки ноутбука.
**Звук (без музыки):** тики на каждое загорающееся слово, клик клавиш на печать промпта, «thump» + суб на оранжевую вспышку, скрип маркера на перечёркивание, штамп.
**Уровень:** Стандарт (подсветка по слову, промпт, вставка-анкета) – Мощный (вспышки, флипы, ключи-ромбики).

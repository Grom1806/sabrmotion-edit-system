# Spotify Wrapped: цифра-герой

- (наш разбор, источник fable.app закрыт для чтения) Огромная типографика, которая заполняет экран и ломает сетку; слова повторяются стопкой/эхом; жирные геометрические формы (круги, полосы, «капли») прыгают в ритм; дуотон-фото в ярких сочетаниях; персональные цифры как герой кадра («Ты слушал 54 321 минуту»).
- Переход = форма заполняет экран и становится фоном следующего слайда.
- **Для нас**: формат «личная статистика» для чисел в рилсах: цифра-герой + геометрическая форма, которая «отбивает» ритм речи.

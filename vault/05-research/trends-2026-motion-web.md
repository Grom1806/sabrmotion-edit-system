# Тренды моушена 2026: 20 новых приёмов

Запрос пользователя (2026-10-19): «в монтажах нет разнообразия, зайди в Pinterest, Behance, научись новому». Прямо Pinterest (robots запрещает) и поиск Behance из облака не открываются, поэтому брал Behance-проекты через Abduzeedo/Codrops и статьи о трендах 2026. Все приёмы ниже **не повторяют** [[motion-catalog]], [[brand-moves-table]] и [[refs-2026-10-18-overview]]. Музыку из трендов не берём ([[no-music]]).

Формат: **что видно → как собрать → уровень**. Инструменты: G = HyperFrames/GSAP, AE = After Effects MCP, B = Blender, F = ffmpeg.

## Фактура и «ручное» (против стерильного AI-вида)
- **N01 Рваная бумага между сценами.** Новая сцена «прорывается» сквозь старую: край неровный, с белым волокном и тенью. → PNG-маска рваного края (3-4 шт), сдвигаем по Y за 0.3 с, тень drop-shadow 12 px; SFX бумага/рвётся. G. Мощный. Источник: Videobolt trends 2026, GDJ «Grunge Street Opener».
- **N02 Графика «на двойках».** Видео идёт 30 fps, а графика (стикеры, иконки, стрелки) обновляется 12 fps: движение «ступеньками», ощущение stop-motion/ручной работы. → в GSAP `ease: "steps(N)"` или квантовать время слоя `Math.floor(t*12)/12`. G. Стандарт+ (на 1-2 элемента). Источник: Videobolt «torn paper + reduced frame rate».
- **N03 «Кипящая» линия (boiling line).** Нарисованные от руки обводки/стрелки/подчёркивания слегка дрожат каждые 2 кадра. → SVG `feTurbulence`+`feDisplacementMap`, seed меняется 12 раз/с, scale 2-3. G. Стандарт. Источник: Videobolt «hand-drawn visuals».
- **N04 Ризограф-печать.** Ограниченная палитра 2 цвета + полутон (halftone) + сдвиг цветов на 2-4 px (misregistration) + бумажное зерно. Для «плакатной» сцены или карточки цитаты. → F: `format=gray,…` + overlay halftone PNG; или CSS `mix-blend-mode: multiply` 2 слоя со сдвигом. G/F. Стандарт. Источник: LottieFiles «restrictive palettes» + «grain».
- **N05 Коллаж из вырезок.** Спикер вырезан (rembg/u2net) + бумажные фигуры + фото-вырезки с плоской тенью, всё выезжает/подпрыгивает. Только если тема «лёгкая». G (+u2net на ПК). Мощный. Источник: GDJ «Cutout Craft», «Mixed Media Collage».

## Типографика
- **N06 Кинетика с массой и инерцией (Knife Motion, «KINETIC TYPE v2», Behance, 14k+ оценок).** Слова как физические тела: разгоняются, **сталкиваются, толкают друг друга**, отскакивают и успокаиваются. Строгая сетка, базовая линия, слово растёт до краёв кадра. Чёрный шрифт на тёплом песочно-кремовом, текстура печати. → GSAP: слово A въезжает `power4.in`, на контакте B получает импульс `x+=40` и `elastic.out(1,0.5)`, A сплющивается scaleX 0.92 на 2 кадра. SFX — глухой «тук», не whoosh. G/AE. Мощный. Хорошо для PERSET (крем уже в бренде).
- **N07 Текст по траектории (kiel, «Type spread across exponential curves»).** Фраза бежит по кривой (спираль, экспонента, график роста), буквы разворачиваются по касательной. → SVG `<textPath>` + анимировать `startOffset` 100%→0%. G. Стандарт. Хорошо на словах «растёт», «путь», «день 90».
- **N08 Видео внутри букв.** Гигантское слово-маска, через буквы видна следующая сцена, потом буквы «раздуваются» до полного кадра — переход. → CSS `background-clip:text` / SVG mask, scale 1→30 за 0.5 с `expo.in`. G. Стандарт. (В каталоге есть «маска-окно», но не через буквы.)
- **N09 Каллиграфия штрихом (тренд Pinterest 2026 «Pen Pals»).** Ключевое слово/аят/название пишется «пером» вдоль штриха. Для исламских тем — арабская каллиграфия (бисмиллях, название раздела), для остальных — рукописная подпись. → SVG-контур буквы, `stroke-dasharray` + `stroke-dashoffset` 1→0 по порядку штрихов, 0.8-1.2 с; потом заливка fade. G/AE. Стандарт. ⚠ Аяты и имена Аллаха — только в достойном месте, не под «весёлые» SFX и не как фон.

## Композиция и экраны
- **N10 Бенто-сетка / модульный редакционный макет (Seb Cornelius «animated bento cards», Stud «Grid»).** Кадр делится на 3-6 скруглённых ячеек разного размера; ячейки раскрываются по очереди на словах; спикер живёт в одной ячейке, в других — цифра, иконка, скрин. В конце ячейка спикера растягивается на весь кадр. → CSS grid + FLIP-анимация (GSAP Flip). G. Мощный. Тренд «modular layouts» (Videobolt).
- **N11 Плёнка-лента (Nuevo.Tokyo «FILM STRIP»).** Сцены — кадры на киноленте с перфорацией; лента проезжает вертикально (для 9:16) и останавливается на нужной сцене, кадр «вылезает» на весь экран. → G: колонка из 3-5 кадров `y` прокрутка 0.6 с `power3.inOut` + motion blur. Мощный. Хорошо для «до/после», «3 шага».
- **N12 Стекло с дисперсией (Videobolt «dispersions and glass shapes»).** Полупрозрачная стеклянная фигура (капсула, линза, призма) скользит поверх кадра; по краям радужное расщепление RGB, под ней картинка чуть увеличена. → CSS `backdrop-filter: blur(6px) saturate(1.4)` + 3 копии края со сдвигом R/G/B ±2 px; либо B (настоящий glass BSDF + dispersion). G/B. Стандарт. Отличается от glassmorphism-карточек (там матовое стекло без линзы и дисперсии).
- **N13 Изометрическая схема.** Процесс («заявка → проверка → деньги») как изометрические кубики-платформы, по ним едет иконка. → B (ортокамера 35.264°) или SVG изометрия. B/G. Мощный. Источник: LottieFiles «isometric shapes».
- **N14 Плоское 2D внутри 3D-комнаты.** Плоские иллюстрации/скрины стоят как постеры в 3D-пространстве, камера облетает. → B: плоскости с текстурами PNG, камера dolly. Мощный/Ультра. Источник: Videobolt «hybrid 2D and 3D».
- **N15 Выноска, нарисованная поверх реального экрана (callout drawing).** На записи экрана рукой рисуется круг/стрелка + подпись (как N03). По анализу 100 UI-роликов 2026 (advids): дашборды в 73% роликов, экран показывают к 0:13-0:18, светлые фоны выросли с 35% до 55%. → G. Стандарт. Для демо приложений (Ummah Link и др.).

## Структура и переходы в кадре (снимаются с пользователем)
- **N16 Микро-петля.** Последний кадр совпадает с первым (та же поза/графика), ролик незаметно начинается заново → досмотры. → в сценарии финальная фраза подводит к первой; F: crossfade 3 кадра конца в начало. Любой уровень. Источник: CapCut transition trends.
- **N17 «Сначала результат».** В первые 1-2 с показать финал (готовый экран, цифру), потом процесс, потом CTA. Структура, не эффект. Любой уровень.
- **N18 Перекрытие объектом / рукой.** Спикер проводит ладонью/предметом через объектив → под ним уже другая сцена/образ. Нужна съёмка: штатив, одна траектория. G (склейка на кадре максимального перекрытия). Стандарт. Источник: CapCut «object wipe», «hand-cover reveal».
- **N19 Blink-cut.** Склейка на моргании или на щелчке пальцами, синхронно с коротким SFX «клик». Стандарт.

## Цвет из Pinterest Predicts 2026 (как варианты для вопроса 5 о цвете)
- **N20 Палитры-тренды:** «Cool Blue» (ледяной голубой, пастель, спокойные медленные переходы); «Mystic Outlands» (глубокий зелёный + туман, медленный дрейф дымки — подходит исламским темам); «Glamoratti» (шампань-золото, блик-«глинт» по золотым деталям — подходит PERSET); «Vamp Romantic»/«Opera» (вишнёвый/бордо + чёрный/золото) — для SABRMOTION (у бренда чёрный/красный). Добавлять в [[color-palettes-research]] при следующем цветовом ресерче. Только как вариант, по умолчанию основные цвета ([[ask-before-edit]]).

## Цифры, которые стоит помнить
- Хук решается за ~1.2 с; первым кадром — самый сильный визуал (Art of Styleframe).
- Кинетика на хуке: резы каждые 1-2 с; плавные появления 500+ мс в хуке проседают. ⇒ Apple blur-in 500 мс оставляем для середины, в хуке делать 250-300 мс.
- Безопасные зоны 9:16: без текста в верхних ~200 px и нижних ~300 px; шрифт ≥ 56 px semibold.
- Ролики-демо 2026: ~8.5 смен сцены в минуту, ~100 слов озвучки.

## Как применять
Каждый новый ролик: взять **2 приёма N01-N20** (не повторяя прошлый ролик) + правила [[variety]]. Отметить в [[motion-playbook]] → «Used so far» и в заметке ролика в 04-lessons/reels/.

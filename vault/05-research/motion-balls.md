# Motion balls и капли

1. **Metaballs / gooey-капли**: несколько кругов сливаются как жидкость. Сборка в HTML: группа кругов → SVG-фильтр `feGaussianBlur stdDeviation≈12` → `feColorMatrix` с альфа-контрастом `0 0 0 22 -9` (наш подбор). В AE: круги → Fast Box Blur 20–40 → Levels/Simple Choker по альфе. Для «капля отделяется от слова», «две идеи сливаются в одну». SFX: мягкий bloop/liquid.
2. **Глянцевые 3D-сферы** (Blender на ПК, RTX 5080): 3–7 сфер с материалом glossy/chrome или «глина» (матовый пастельный), отскок с squash&stretch (сжатие 15–20 % в момент удара), мягкие тени. Рендер с альфой → накладываем перед спикером, не закрывая лицо. SFX: резиновый bounce, стеклянный tick.
3. **Сфера-курсор**: светящийся шар ведёт взгляд зрителя к ключевому слову/объекту, оставляет motion trail.
4. **Сфера-перекраска** (Apple iMac): шар падает в кадр, от точки касания круговой маской расходится новый цвет/сцена (clip-path circle 0→150 %, 0.5 с, expo.out).
5. **Орбита**: маленькие шары (иконки, аватары) вращаются по эллипсу вокруг цифры/лица (rotate по эллипсу + scale по глубине: дальние 0.7 и затемнены, ближние 1.0). Для «вокруг тебя всё это…».
6. **Ньютоновы шарики / домино**: цепная реакция объясняет причину и следствие (одна сфера ударяет следующую на каждом слове).
7. **Hyperframes-реализация**: canvas/Three.js внутри композиции либо PNG-секвенция из Blender. Предпочтительно Blender-рендер для глянца, SVG-фильтр для жидкости.

# 15-секундный моушен-шоурил (IMG_0583)

**Идея ролика:** показать само понятие «motion» как азбуку: главы Rhythm / Form / Type / Timing / Choreography, в каждой одна демонстрация принципа. Один красный шар — сквозной герой от первой буквы до точки в логотипе.

Структура как у дизайн-документа: внизу слева подписи главы («01 INTRO», «02 RHYTHM», «03 FORM», «04 TYPE / TIMING», «05 CHOREOGRAPHY»), внизу справа полоска-прогресс, сверху справа счётчик времени. Палитра: красный #f0401f, ультрамарин #1f3ff0, кремовый, чёрный, акценты жёлтый. Шрифт: геометрический гротеск (Futura/Gilroy Bold), подписи разрядкой.

**Покадрово:**
- 0–1: «M_TION» — **красный шар падает и становится буквой O**, под словом разрядкой «A REEL IN FIFTEEN SECONDS 2026», тонкая линия-подчёркивание.
- 1.5: камера летит в O (zoom-through буквы) → красный экран.
- 2–3.5 RHYTHM: концентрические 3D-кольца (тор) закручиваются в спираль-туннель, камера проходит внутрь, белый шар в центре.
- 4–5 FORM: изометрическое поле из вокселей-кубиков (чёрные), волна красных столбиков поднимается кругом/рисунком (воксельная волна).
- 5.5: синий wipe на весь экран.
- 6–7.5 TYPE: синий фон, бегущие строки «DESIGN MOTION» в 3 ряда в разные стороны (крупно, полупрозрачно), спереди **красный «желейный» шар катится** и мнётся (squash & stretch).
- 8–9.5 TIMING: **глагол анимируется своим смыслом**: «STRETCH» тянется между двумя вертикальными линиями; «SPIN» с окружностью-орбитой вращается; «BOUNCE» буквы подпрыгивают с волной; «SNAP» щёлкает на место с жёлтой линией. Фон меняется на каждом слове (чёрный/красный/кремовый/синий).
- 10–12.5 CHOREOGRAPHY: рой сотен мелких 3D-фигур (сферы, кубы, торы, пирамидки) красный/синий/белый/жёлтый вокруг большого красного шара: облако → спираль-ДНК → кольцо → разлёт.
- 13–14.5: кремовый фон, «CLA..» печатается, собирается «CLAUDE» + **красная точка в конце**, подзаголовок разрядкой «MOTION DESIGN REEL 2026».

**Приёмы для нас:**
1. **Шар = буква O / точка** в логотипе (сквозная метафора одного объекта через весь ролик).
2. **Zoom-through буквы** как переход в следующую главу.
3. **Главы с подписями и прогресс-полосой** (дизайнерская «документальность»).
4. **Глагол делает себя** (STRETCH/SPIN/BOUNCE/SNAP) — то же, что «ТЯНУТСЯ» в [[ref-red-kinetic-poster]]: подтверждено двумя референсами.
5. **Рой фигур, меняющий форму** (облако → спираль → кольцо) на кульминацию.
6. **Воксельная волна** для темы «данные/рост».

**Как собрать:** 3D (кольца, воксели, рой, желейный шар) — Blender MCP на RTX 5080 (geometry nodes для роя и вокселей, soft body/shape keys для желе); шрифтовые сцены — After Effects MCP или HyperFrames. Темп 1 сцена ≈ 1–1.5 с.
**Звук (без музыки):** у каждой главы свой тембр: падение шара «boing», туннель «whoosh» с ризером, воксели «клик-клак» по волне, слова-глаголы со звуком действия (растяжение резины, свист вращения, отскок, щелчок), рой — шуршащие частицы.
**Уровень:** Мощный – Ультра; для Стандарта брать только «шар-буква» в логотипе и «глагол делает себя».

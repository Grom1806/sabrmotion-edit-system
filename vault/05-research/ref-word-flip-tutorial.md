# Слово-на-кадр и список-обучалка

## IMG_0581 — манифест «we don't just edit» (13 с, 9:16)
**Идея:** манифест студии через противопоставление «мы не просто X, мы Y» и быстрый список ценностей, последнее слово «repeat.» закольцовывает.
- Одно слово на кадр, центр, жирный округлый гротеск (типа Gilroy/Proxima Bold), на кадр 0.3–0.5 с: we / don't / just / edit / we / create / motion / art / visuals / energy / precision / vibes / graphics / ideas / repeat.
- **Фон инвертируется** на каждом слове: белый ↔ чёрный (23 жёсткие смены за 9 с), на тёмных кадрах мелкая пыль/зерно.
- Размер слова меняется по смыслу: «we don't» и «just edit» огромные (на всю ширину, «don't» крупнее «we»), перечисление мельче.
- «re → repea → repeat.» — слово допечатывается и последний кадр меняет фон = точка.
- **Для нас:** готовый хук/манифест SABRMOTION на 6–9 с: «мы не просто монтируем…». Работает и без голоса. Звук: щелчок/«tick» на каждую инверсию, разные по высоте, на «repeat.» глухой удар.

## IMG_0582 — «7 простых шагов монтажа» (63 с, 9:16, голос + субтитр по слову)
**Идея:** личный опыт как хук («потратил 5 лет — объясню за 60 секунд»), дальше нумерованный список с конкретными сервисами (польза = сохраняют), финал — кодовое слово в комментарии за бонусом.
- Палитра: тёмно-красный градиент с виньеткой ↔ почти чёрный с серой подсветкой в центре. **Фон меняется на новом пункте/мысли**, не на каждом слове.
- Хук 0–4 с: «Я ПОТРАТИЛ 5 ЛЕТ В МОНТАЖЕ» — иконка пера рисует линию-подпись, слова выплывают из блюра; «ВИДЕО» / «ПОНЯТЬ ЭТО» поверх полупрозрачной лампочки (фото на фоне, 30 % непрозрачности); «ЗА 60 СЕКУНД» + кружок-таймер «57», тикает.
- Субтитр: одно-два слова в центре, белый, без плашки; два шрифта: узкий кондансед капсом для эмоций («ОБЪЯСНЮ», «ЛЯМ»), обычный гротеск строчными для речи.
- **Номер пункта**: белый кружок «#1…#7» с розовой цифрой выплывает из блюра сверху, под ним название шага.
- Номер + цифры-плитки: «3 САМЫХ ПОПУЛЯРНЫХ» → плитки 1 2 3, каждая **переворачивается в иконку** (Pr, DaVinci, Final Cut).
- **Таблетки-ссылки**: белые скруглённые плашки с логотипом сервиса (gling, FireCut, Envato, Storyblocks, Pexels, fonts.google.com, dafont.com, motionarray…), появляются стопкой по одной, новая сначала серая/полупрозрачная, потом проявляется.
- Скрин-вставки: интерфейс Premiere/Resolve в скруглённой рамке (вертикально обрезан), курсор двигается, субтитр стоит поверх; промпт ChatGPT в «стеклянной» плашке с блюром.
- Видео-вставка (b-roll про себя) в рамке с размытыми краями (feather mask) поверх красного фона, большой текст поверх.
- Финал: «пиши ЛЯМ» — слово-кодовое для комментария, розовый, повторяется с разными надписями сверху (готовую / формулу / продвижения / через рилс), затем затемнение + Instagram.

**Приёмы для нас:**
1. **Инверсия фона на слово** (манифест, хук).
2. **Номер-кружок пункта** + смена фона на пункт = понятная структура списка.
3. **Плитка-цифра переворачивается в иконку** (flip 1→Pr).
4. **Стопка таблеток-ссылок** с логотипами (для «сервисы/инструменты»).
5. **Кодовое слово CTA** крупно и повторно («пиши ЛЯМ»).
6. **Видео-вставка с мягкими краями** вместо жёсткой рамки.

**Как собрать:** HyperFrames/GSAP, субтитры по whisper-таймингам (на ПК), блюр-вход 20→0 px (как в нашей Apple-сигнатуре), flip через rotateY.
**Звук (без музыки):** pop на номер-кружок, мягкий «tick» на таблетку, «flip» на переворот плитки, whoosh на смену фона.
**Уровень:** Минимал/Стандарт (0582 — образцовый Стандарт без лица), 0581 — Стандарт-хук.

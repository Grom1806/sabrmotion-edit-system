# Красно-чёрный кинетический постер (IMG_0580)

Берём только монтаж на экране (монитор, стол, рука и плашка сверху = упаковка автора, не копируем). Внутренний ролик на русском, палитра: красный, почти чёрный, белый; шрифт широкий жирный гротеск (типа Druk Wide / Unbounded Black), второстепенные строки моноширинным.

**Идея ролика:** диалог со зрителем от первого лица («да, ладно! так-так-так… прикинь, я это видео вообще не монтировал»). Структура: реакция-хук → интрига «это не плагин и не шаблон» → раскрытие (Claude, пишешь промпт) → демонстрация возможностей, где каждое слово само показывает себя → «вспомни, как обычно» (боль: слои, ключи, час рендера) → решение (промпт → генерация → готово за 9 с) → «и это видео тоже» → CTA. Разговорные короткие фразы, каждая = отдельный кадр-постер.

**Покадрово (время видео):**
- 3–4.5: белая вспышка → «ДА» собирается из крупных пикселей и «докручивается» в чёткий шрифт → белый кадр, в центре мультяшная бомба с горящим фитилём → взрыв = «ЛАДНО!» на красном (восклицательный знак падает отдельно и отскакивает).
- 4.5–6: «ТАК, ТАК, ТАК.» стопкой, каждое следующее ярче, фон чёрный → белый; маленькое «ха» красным сбоку.
- 6.5–8.5: «ПРИКИНЬ.», «Я ДЛЯ ЭТОГО ВИДЕО», «ВООБЩЕ НЕ» + зачёркнутое красное слово (глитч-RGB сдвиг).
- 9–10: «AFTER EFFECTS» + скрин таймлайна, перечёркнутый красным X.
- 10.5–12: белый фон, «И СРАЗУ ОТВЕЧУ» + большой красный «?», затем «НЕТ.» на чёрном с красной точкой.
- 12.5–14: «ЭТО НЕ» + две иконки-стикера «плагин», «шаблон» с волнистой стрелкой.
- 15–17: логотип-звезда + «CLAUDE» с красным свечением и частицами.
- 17–19: «ПРОСТО ПИШЕШЬ» + поле ввода с печатью «что хочешь».
- 19–21: «А ОН САМ СОБИРАЕТ» + плашка YouTube; «АНИМАЦИЮ» — буквы проявляются через красное пятно-блюр.
- 21.5: «И ВСЁ.» на красном (жёсткая смена фона).
- 22–26: «НУЖНО ТОЛЬКО НАПИСАТЬ» с курсором, затем окно «ПРОМПТ»: «Сделай 15-секундную киношную анимацию», числа подсвечены красной плашкой.
- 26.5–30: перечисление возможностей, каждое на своём фоне: «КИНЕТИЧЕСКАЯ ТИПОГРАФИКА» (красный, буквы скачут по базовой линии), «ПЕРЕТЕКАЮЩИЕ ФИГУРЫ» (чёрный, фигуры-блобы), «3D ЭЛЕМЕНТЫ» (белый, вращающийся красный куб), «ПЛАВНЫЕ ПРОЛЁТЫ КАМЕРЫ».
- 31.5–36: «А ТЕПЕРЬ СМОТРИ НА БУКВЫ» (буква О в «СМОТРИ» = красный круг) → белый фон, «ТЯНУТСЯ» сначала узкое и сжатое, затем растягивается по ширине за края экрана, фон мгновенно в красный, слово возвращается к норме (stretch + смена фона в момент максимума) → «СЛЕДИ ЗА КАМЕРОЙ» (speed-lines из центра) → «И ЖДИ ПЕРЕХОД» → туннель из вложенных многоугольников, вращающихся с разной скоростью, красный/белый, закручивается и «выплёвывает» звезду-взрыв.
- 42–44: «ТЫ СЕРЬЁЗНО?!» на белом с красной звездой-бёрстом (comic burst).
- 44–52: «ВСПОМНИ как это делается обычно» (подзаголовок рукописным курсивом, слово «это» в рамке) → «СЛОИ.», «КЛЮЧЕВЫЕ КАДРЫ.», «ГРАФИКИ СКОРОСТИ.» с реальными скринами AE → все слова слипаются в кучу (pile-up).
- 51–55: «И ПОТОМ ЕЩЁ ЧАС...» + таймер рендера 00:59:59, тикающий вниз, прогресс-бар; «РЕНДЕР.», «ЗДЕСЬ?» с глитчем.
- 54–58: «>_ПРОМПТ» (терминальный курсор), «ГЕНЕРАЦИЯ 58%» на красном, «ГОТОВО ✓» на белом с красной галочкой и строкой «рендер завершён 00:00:09».
- 57–62: «И ЭТО ВИДЕО ДА, ТОЖЕ» в рамке плеера с таймлайном; «ОТ ПЕРВОЙ ИДЕИ ДО ПОСЛЕДНЕГО КАДРА» с иконкой-лампочкой.
- 62–64: «СДЕЛАНО ОДИН ПРОМПТ.» (красный), «ОБАЛДЕТЬ.» — фон мигает белый/красный.
- 65–67: «ЕСЛИ ХОЧЕШЬ ОСВОИТЬ ИИ-МОНТАЖ» на тёмном с красным туманом и частицами.
- 67.5–71: макет профиля Instagram + красная таблетка «ССЫЛКА В ШАПКЕ ПРОФИЛЯ ↑».

**Приёмы для нас:**
1. **Фон меняется на каждой фразе** (красный → чёрный → белый) = ритм без склеек и без музыки.
2. **Слово делает то, что значит**: «ТЯНУТСЯ» тянется, «ПЕРЕТЕКАЮЩИЕ» перетекает, «КАМЕРОЙ» летит. Это главный урок ролика.
3. **Стопка-повтор** («ТАК, ТАК, ТАК.») — нарастание яркости.
4. **Таймер, тикающий вниз** + прогресс-бар для боли «долго», затем «ГОТОВО ✓ 00:00:09» для решения.
5. **Pile-up**: перечисленные термины падают в кучу = «перегруз».
6. **Comic-burst звезда** за вопросом-возражением.
7. **Туннель из фигур** как переход-«вау» в середине.

- Туннель (8 кадров/с): вложенные полигоны (треугольник, квадрат, пятиугольник) с белой и красной обводкой крутятся в разные стороны и меняют число углов (морф формы), из центра вылетают белые капли-блобы и красные кляксы, всё сжимается в звезду.
- Pile-up (8 кадров/с): под заголовком «ГРАФИКИ СКОРОСТИ.» слова «слои, ключевые кадры, прекомпоз…» падают сверху одно на другое, наслаиваются с прозрачностью в нечитаемую кучу = перегруз.

**Как собрать:** весь ролик реально сделан кодом (Claude): HyperFrames/GSAP — SplitText по буквам, scaleX для «тянется», SVG-полигоны с rotate разной скорости для туннеля, CSS filter для глитча. Для нашего бренда менять красный на палитру SABRMOTION (чёрный/красный/зелёный уже совпадает по духу!).
**Звук (без музыки):** удар на каждую смену фона, глитч-треск, тик таймера, «ding» на ГОТОВО, свуш-туннель с ризером.
**Уровень:** Мощный – Ультра (на Стандарте брать только «слово делает то, что значит» и смену фона на ключевых фразах).

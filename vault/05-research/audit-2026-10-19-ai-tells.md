# Аудит: почему наши ролики выглядят как ИИ

Отзыв пользователя 2026-10-19: «вообще не отходит от айфонского… иишный дизайн всё ещё», «v2 скучно, мало движения», «мало инфографики». Листы кадров: `05-research/refs/2026-10-19-audit/` (по 16 кадров на ролик, `grp0–6.jpg` — сводные).

## Топ-13 признаков, общих почти для всех роликов
1. **Одна UI-карточка / телефон по центру тёмного экрана** — в ~70 % кадров (81 %, ai-edit, dm, 4 ошибки, localai, планы 2–5, День 90 v1). Композиция «дашборд по центру + подпись снизу» повторяется кадр за кадром. → Кадр строится от сюжета (схема, карта, вырезка, рука, предмет), объекты выходят за края, 2–3 плана глубины.
2. **Субтитры-шаблон**: жирный капс-гротеск (Unbounded/Montserrat Black), 1–3 слова, одно слово красным/зелёным/золотым, всегда центр-низ, в каждом ролике одинаково. → Субтитр как часть вёрстки кадра, разные системы на ролик ([[captions-v2]]).
3. **Фейковый UI, собранный в HTML**: скругления 16–28, обводка 1 px, мягкие тени, «стекло», пилюли-бейджи («ПРОБЛЕМА 1/3», «02 / движение»), тумблеры, прогресс-бары. Выглядит как Dribbble-кит. → Настоящие скриншоты/съёмка экрана телефона рукой, или вообще не UI, а предмет/схема.
4. **HUD-мусор**: REC-таймер, ▶ в углу, уголки-рамки, полоса прогресса сверху, @ник — во всех SABRMOTION-роликах 13–19.10. Ничего не значит. → Убрать; служебная графика только если это часть мира ролика.
5. **Палитра «почти чёрный + неон»**: #0B… фон с радиальным свечением, акценты красный/зелёный/циан, glow-пятна вместо света. Одинаково в 12 из 20. → Свет и материал вместо glow: фотофон, бумага, реальная тень, палитра бренда, светлые фоны.
6. **Стат-слайд**: огромное число с градиентом по центру (81 %, 300, 10, 93 %, 60 000+, 557, 2/200, 0 ₽) — почти в каждом ролике одинаково. → Инфографика, которая объясняет: сравнение, шкала, схема, диаграмма с подписями, число рядом с тем, что оно измеряет.
7. **Одинаковые входы**: blur→sharp + scale-up + fade, пружина с перелётом у всех элементов; «появилось и стоит». Нет камеры, параллакса, глубины. → Разные типы движения: камера через сцену, объекты действуют (едут, падают, рисуются, режутся), match-cut, маски по форме.
8. **Иконки-заглушки**: Lucide-линии, плитки «приложений», серый силуэт человека (dm), папки/облака. → Реальные предметы, фото, вырезки, рукописные пометки; иконка только как часть схемы.
9. **Стерильная чистота**: нет зерна, бумаги, плёнки, реального света, фото-слоя; всё векторное и плоское. → Фактура и физика: скан бумаги, фото-вырезки, реальные тени, ч/б фото, печать/растр.
10. **Ритм-метроном**: событие строго каждые ~0.5–0.8 с одинаковой длины (v1-ролики) или наоборот всё стоит (День 90 v2). → Волны, но картинка всё время в движении (камера).
11. **Шаблонный финал**: «Отправь тому, кто…» + самолётик + зелёная кнопка / «напиши в директ» — в 6 роликах. → Финал продолжает мир ролика (итог инфографики, последний предмет).
12. **Голова на плоском светлом фоне** (adobe-free, openai): белая стена, без грейда и глубины, капс-сабы на груди красным. → [[talking-head-look]].
13. **Звук**: щелчок/свуш на каждое появление (v1), шум room tone (v2). → Мало звуков, но физичных; без фона на чистой озвучке ([[sound-v2]]).

## По роликам
- **PERSET reel02/03/04, invest01**: белые карточки-инвойсы по центру, сабы капсом на жёлтой плашке во всех кадрах, точечная карта как фон, «60 000+» стат-слайд, купюры/мосты как иконки на пустом фоне, финал лого+сайт / «Сохраните». Признаки 1, 2, 3, 6, 8, 11.
- **PERSET revolut (17.9 с)**: 3D-телефоны и монеты на тёмном с оранжевым glow, «65/83 страны» стат-слайд. Признаки 5, 6, 7.
- **adobe-free / openai-otmena**: голова на белой стене, капс-сабы красным на груди, тёмные UI-плашки сверху, REC/▶, финал «пиши в комментариях». Признаки 2, 4, 8, 11, 12.
- **reel6 81 %**: чёрный + красный неон, сетка иконок-людей, «81 %», «300», «93 %» подряд, окна кода с тремя точками. Признаки 1, 3, 4, 5, 6.
- **reel7 ai-edit, reel8 dm**: тот же чёрно-красный HUD, папки/волны/чат-пузыри по центру, серый силуэт человека. Признаки 1, 3, 4, 5, 8.
- **4 ошибки**: «01/02/03/04» + карточки со сток-лицом, графики кривых, чек-лист-карточка. Признаки 1, 3, 4, 6.
- **localai-studio**: тёмный + красный, «0 ₽ / месяц» неоновое кольцо, 3D-видеокарта с glow, GitHub-карточка. Признаки 1, 5, 6, 7.
- **be-honest**: тёмный + циан, «2/200», точечная сетка; бумажная карточка «мои 3 фразы» — единственный тёплый материальный кадр. Признаки 1, 4, 5, 6.
- **День 90 v1**: тёмный бирюзовый + золото, телефон-мокап по центру, капс-сабы, бейдж. **v2**: журнал на тёмном, 75 % статичных кадров, шум. Признаки 1, 2, 5, 6 / 5, 10, 13.
- **Визитка**: неоновые конфетти-фигуры, телефоны-мокапы, «10+» с лучами, Instagram-иконка. Признаки 3, 5, 6, 8, 11.
- **План 2 «Мечеть»**: тёмный зелёный, контурная мечеть-иконка, таймер, часы кольцом, телефон по центру. Признаки 1, 3, 4, 6.
- **План 3 offline**: перечёркнутый Wi-Fi, «$0 ∞», «1 2 3 шага» плитками, терминал-плашки. Признаки 1, 3, 6, 8.
- **План 4 честность**: тёмно-синий + циан, уголки-рамки, «2/200», точечная сетка. Признаки 1, 4, 5, 6.
- **План 5 приложения**: плитки-«приложения», телефоны по центру, «ПРОБЛЕМА 1/3» пилюли, «МНЕ НАДОЕЛО». Признаки 1, 2, 3, 8, 11.

## Что работало (оставить)
Точечная карта с маршрутом и дорисовкой линии (PERSET 02–03), бумажная карточка с печатной машинкой (be-honest), реальные записи экрана сайта, реальный график коммитов (День 90 v2), реальные числа.

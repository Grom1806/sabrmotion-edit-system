# Система монтажа v3

**Почему v3.** v2 (утро 2026-10-19) убрала ИИ-шаблон, но первый тест «День 90» v2 пользователь отверг: «скучно, мало движения, хуже первой версии», «стильный красивый стиль не нравится», «мало инфографики», шум и мыльные фото. Затем: «видео не отходит от айфонского… иишный дизайн», «уйти от личного» (от сигнатурного Apple-стиля), «вставляй как люди на таймлайне, а не скриптами». v3 = качество v2 + плотность прежних одобренных роликов + новые направления + видимая работа в AE.

**Главный принцип:** сначала идея и картинка, потом техника. Много движения и много инфографики — но на реальных данных и без шаблона.

**Приоритет:** `01-rules` (без музыки, оригинальный фон, не критиковать других, голос, факты, удаление) > этот документ > `07-system` > старые каталоги `03-techniques`, `05-research`. Где старое спорит (Apple по умолчанию, капс-субтитры, HUD, спокойная плотность v2, room tone), действует этот документ.

## Что изменилось в v3 (коротко)
1. **Apple-подача снова в системе** (пользователь 2026-10-19 21:51: «у Apple хороший стиль, его нужно использовать»): как основное направление D0 или как полировка поверх D1–D6 ([[directions-v3]]). Убираем не Apple, а шаблонный мусор (HUD, REC, капс с цветным словом, фальшивые окна). S01–S13 ([[styles-pro]]) — приёмы внутри.
1a. **Анимация** по [[motion-v3]]: всё плавное, ничего не появляется сразу, много анимации везде, расширение блоков/квадратов часто, bounce у героев.
2. **Плотность не ниже прошлых одобренных:** по умолчанию Мощный — событие ~каждые 0.8–1.2 с, в движении ≥80 % кадров, плато 1–1.5 с ([[rhythm-v2]]). **Камера и ракурсы разрешены (2026-10-20, пользователь: «можно использовать камеру и ракурсы»):** виртуальная камера AE (проезды, push-in/pull-back, панорамы, параллакс, 3D-ракурсы, наклон перспективы) — полноценный инструмент, см. [[camera-allowed]]. Старое правило «кадр не двигается» (отзыв «6236») отменено; из него остаётся только урок: не трясти кадр десятками резких ударов подряд, движения камеры плавные, с motion blur и смыслом.
3. **Инфографика в каждом бите** на реальных цифрах (код, сайт, документы): число становится формой или предметом (114 полос = 6236), а не «большая цифра с градиентом».
4. **Видимый таймлайн AE**: каждый элемент слоем с русским именем, обрезан на таймлайне, маркеры, лейблы, проект открыт, к превью — скриншот таймлайна ([[ae-pipeline]] раздел v3).
5. **Резкость и поля** (автопроверка [[sharpness-guard]]): вьювер и рендер Full, текст живыми слоями, без апскейла, без зерна и шума на фоне (пользователь: зерно = «мыло»), крупный текст в полях ≥60 px.
6. **Звук**: без room tone под чистый голос; SFX из мира направления, разные; в промо/инфографике SFX на каждое значимое действие ([[sound-v2]]). **Фон под голосом — только тихий нашид без инструментов** ([[ambience-library]]), на 18–24 дБ ниже голоса, или ничего. **Природные звуки и атмосферы запрещены навсегда** (пользователь 2026-10-19 23:23).
7. **Вопросы кнопками**, по одному на карточку; молчание пользователя = рекомендованное + блок «что я решил» ([[ask-before-edit]]).
8. **Факты проверены** ([[fact-check]]), **ничего не удалять** без «да» ([[no-delete-without-yes]]).
9. **Весь арсенал в работу** ([[use-everything]]): карта арсенала в брифе, `assets\КАТАЛОГ.md` + `assets\_usage.csv`, ≥1 ассет и ≥1 техника впервые. Но иконки — служебно, реальные предметы и скрины важнее (иконки-заглушки = признак ИИ).

## 9 этапов (каждый ролик)

**0. Подготовка.** Прочитать: этот файл, все `01-rules`, все `07-system`, заметку бренда, 2 последние заметки `04-lessons/reels/` (не повторить их направление, шрифты, палитру, финал), [[pipeline-gotchas]], `claude-edit\assets\КАТАЛОГ.md` и `assets\_usage.csv` ([[use-everything]], [[assets-library]]).

**1. Вопросы** — сначала прочитать бриф с [[control-panel]] (Пульт монтажа, ArtifactData `state/current`); чего там нет, спросить ([[ask-before-edit]]) кнопками: направление (3 из D0–D6, рекомендованное отличается от прошлых двух), уровень (по умолчанию Мощный), бренд, цвет. На открытый запрос — сначала 3 идеи.

**2. Идея (бриф на 1 экран)** ([[concept-first]]): фраза «мир ролика», сквозной объект/приём, раскадровка по битам: что говорится → что видно (доказательство, следствие, предмет, инфографика — не то же слово). Сценарий через [[no-negativity-about-others]] и [[fact-check]]. **Карта арсенала** по [[use-everything]]: что берём из ассетов (фото, инфографика, карты, паттерны, Lottie, SFX, шрифты, иконки служебно) и из техник vault, по битам, с минимумами и ≥1 ни разу не использованным ассетом и приёмом.

**3. Материал.** Реальные записи экрана (проверить живой сайт), скрины, фото полного разрешения, снятые кадры, фактуры. Говорящая голова — монтаж по [[live-editing-v3]] (raw-premium: плотные резы, кроп-планы, субтитры dynamic minimalism), свет и кожа — [[talking-head-look]]. Ассеты: `claude-edit\assets\` (иконки только служебно).

**4. Стиль-фреймы.** Сначала [[sharpness-guard]] (preflight 0 FAIL). 3 направления × (хук, середина, финал) из AE на материале этого сценария → пользователю картинкой, один рекомендован. Проверить по [[anti-ai-qa]] (композиция, шрифт, фактура, нет 10 признаков ИИ). «Делай сам» = рекомендованное без остановки.

**5. Сборка в After Effects** ([[ae-pipeline]]): в открытом окне AE, человеческий таймлайн; LIB-прекомпы мастер-проекта, `timeline.json` из таймингов слов; аниматик (Draft) → правки → финал (motion blur или «на двойках» по направлению, грейд, без зерна). HTML/HyperFrames — только если AE не отвечает (сказать пользователю).

**6. Субтитры** ([[captions-v2]]): фразами, обычный регистр, своя система на ролик, ≥56–60 px Bold, на подложке или чистом фоне; не капс с цветным словом.

**7. Ритм и звук** ([[rhythm-v2]], [[sound-v2]]): плотность Мощный по умолчанию, кадр неподвижен (движутся элементы), ре-хуки на 15/30 с, одна короткая пауза перед главным; SFX из мира направления (пользователь хочет их больше), без тональных, без синтетического room tone, тихий нашид на фоне из [[ambience-library]] (без природных звуков); −14 LUFS, TP ≤ −1.

**8. Проверка и сдача:** [[sharpness-guard]] (preflight + sharpcheck зелёные — иначе не показывать) + [[qa-frame-by-frame]] (синхрон, глитчи, первый кадр не пустой, текст не выходит за блоки и поля, резкость 100 %) + [[anti-ai-qa]] (п.19 — карта арсенала выполнена) → строки в `assets\_usage.csv` → мастер (CRF 14) + light **1080×1920 CRF 18** (720p только как отдельный preview) + контакт-лист + скриншот таймлайна → проверить, что файлы дошли до треда → после отзыва заметка в `04-lessons/reels/` ([[self-learning]]), финал в `VIDEOS\` ([[video-storage]]).

## Запрещено по умолчанию (10 признаков ИИ-вида, аудит 20 роликов)
Карточка/телефон по центру тёмного фона; капс-субтитры с одним цветным словом по центру внизу; фальшивый UI (стекло, скругления, тонкая обводка, «ПРОБЛЕМА 1/3», окна с тремя точками); REC/▶/уголки/прогресс-бар; чёрный фон + неон; огромная цифра с градиентом как слайд; одинаковый вход blur+пружина и статика без камеры; иконки-заглушки вместо реальных вещей; стерильность без фактуры и фото; финал «Отправь тому…» с самолётиком и зелёной кнопкой. А также: текст на экране = голос; элементы, которые появляются без анимации. Можно только если это осознанная часть идеи и записано в брифе.

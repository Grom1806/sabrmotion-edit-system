**Зеркало для облачных тредов** — `/mnt/project-files/vault/`. Старые `_lessons\`, `lessons/`, `style/` больше не правим: они заморожены как архив.

## Протокол для Claude перед монтажом (экономия токенов, до v2)
Не читать всё подряд. Порядок:
1. Прочитать [[INDEX]] (~6 KB): одна строка на заметку с тегами и summary.
2. Прочитать ВСЕ заметки `01-rules/` (короткие, ~0.5 KB каждая) — они действуют всегда.
3. Спросить [[ask-before-edit]] (уровень + бренд). По ответу открыть только:
   - уровень → [[motion-tiers]];
   - бренд → его заметку в `02-brands/` (без бренда → направление из [[directions-v3]]; Apple-стиль с 2026-10-19 не по умолчанию);
   - 1 приём бренда → [[brand-moves-table]] + одна заметка `05-research/`;
   - нужные разделы каталога → 2–4 заметки из `03-techniques/motion/` (по тегу), а не весь каталог;
   - источник видео → [[color-playbook]].
4. Поиск по теме: `rg -l "tags:.*transition" vault/` или `rg -i "glow|свечение" vault/ -l`, затем открыть найденное.
5. После ролика: [[self-learning]] (заметка в `04-lessons/reels/` по шаблону, потом `python _scripts/build_index.py`).

Было: ~82 KB плейбуков и каталогов читались целиком. Стало: INDEX + правила + 4–6 нужных заметок ≈ 20–30 KB.

## Как добавлять новое
- Новое правило от пользователя → `01-rules/` по шаблону `_templates/rule.md`.
- Новый клиент → `02-brands/<клиент>.md` по `_templates/brand.md` (файлы лого/шрифтов остаются в `claude-edit\branding\<Клиент>\`).
- Разбор стиля/бренда → `05-research/` по `_templates/research.md`, строку в [[brand-moves-table]].
- Одна заметка = одна тема. Ссылки в двойных квадратных скобках по имени файла. В frontmatter всегда `tags` и `summary` (по ним строится INDEX).

## Синхронизация
Правит vault на ПК сессия Remote Control. Облачные треды не видят ПК напрямую, поэтому облачный тред правит зеркало, а сессия на ПК в начале каждого монтажа сверяет `vault\` с зеркалом (новее побеждает). Кто правит, обновляет `updated:`.

## Поиск в Obsidian
- Встроенный поиск: `tag:#rule`, `tag:#tier/standard`, `path:05-research glow`.
- Семантический поиск: плагин **Smart Connections** (локальные эмбеддинги, бесплатно, без ключей). Подробно: [[obsidian-search-setup]].

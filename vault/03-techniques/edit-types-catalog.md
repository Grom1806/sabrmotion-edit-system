# Типы монтажа и сборки

Пользователь 2026-10-18: «дай на выбор типы, не один, а несколько, чтобы их соединять внутри одного видео; каждый раз разные объединения и уникальные дизайны». Поэтому перед монтажом (см. [[ask-before-edit]]) показываем это меню: **основной тип + 1–3 дополнительных**, или готовую сборку, или свою смесь. Уровень моушена ([[motion-tiers]]) спрашивается отдельно и задаёт силу каждого типа.

## Как спрашивать (формат вопроса)
Одной карточкой/списком, без длинных описаний:
1. **Уровень**: Минимал / Стандарт / Мощный / Ультра.
2. **Типы**: предложить 3 сборки, подходящие под тему (рекомендуемая помечена), + «свой набор: назови коды Т». Можно выбрать несколько сборок и смешать: тогда основной тип = первый названный, остальные идут вставками.
3. Бренд и переходы — как в [[ask-before-edit]].

## Правила уникальности
- Не повторять сборку из прошлого ролика; не повторять один и тот же основной тип 2 ролика подряд, если пользователь сам не выбрал.
- Даже при той же сборке менять минимум 2 из: палитра акцента, шрифтовая пара, тип переходов, «вау»-момент, приём из [[brand-moves-table]] (K/K10), звуковая палитра.
- Внутри ролика: каждый тип живёт блоком 3–10 с, на стыке типов — бесшовный переход (морф/зум в экран/match cut), если пользователь не выбрал резкие резы.
- Записывать в заметку ролика (`04-lessons/reels/`): уровень, коды типов, сборку, что заменили ради уникальности.
- Ограничения проекта действуют всегда: без музыки, фон оригинальный на Стандарте, графика не закрывает лицо полностью ([[no-music]], [[keep-original-background]]).

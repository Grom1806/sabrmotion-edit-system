# SABR-kit

**Зачем:** реф больше не копируем целиком. Стиль разобран на **модули**, и каждый ролик собирается из них по ситуации: можно смешивать, можно придумывать новые на их основе.

**Где лежит:**
- код: `tools/style-kit/` (`sabr-kit.js`, `sabr-kit.css`, шрифты-список, пример `example-iphone-duo-v4.html`);
- копии: PC `claude-edit\tools\style-kit\`, `/mnt/project-files/tools/style-kit/`.

**Подключение (HyperFrames):**
```html
<link rel="stylesheet" href="assets/sabr-kit.css"><script src="assets/sabr-kit.js"></script>
<script> const tl = gsap.timeline({paused:true}); SK.use(tl);
  const w = SK.mk('#front','sk sk-cond sk-y sk-lift','дорогой',{left:'0',right:'0',textAlign:'center',top:'600px',fontSize:'250px'});
  SK.bounce(w, 0.72);  SK.whip(w, 1.76, 'up');  SK.punch('#cam', 3.10, 1.12); </script>
```
**Позиция только инлайн-стилем** (left/top/fontSize), не через `#id {}`: копии для slice/rgb теряют id и должны встать точно на место.

## 1. Модули
### Типографика (роли, `sabr-kit.css`)
| Класс | Шрифт | Где |
|---|---|---|
| `sk-cond` | Oswald 700, капс (аналог Anton/Druk, кириллица есть) | главные слова, за головой, цены |
| `sk-script` | Playfair Display Italic 600 | связки: «самый», «только что», «или», «а за» |
| `sk-sans` | Montserrat 900 | стопки сбоку, белые сцены |
| `sk-ui` | Inter 600 | подписи окон, мелкие ярлыки |

- Цвета: `sk-y` #EAD43A, `sk-w`, `sk-k` #0E0E10, `sk-r` #E5162B (+ зелёный #19C46B из бренда SABRMOTION).
- `sk-lift`: контактная тень для текста на живой стене.
- `sk-bloom`: многослойный блум с горячим ядром, только для 1–2 ключевых слов.

### Входы (E) — у каждого своя «физика»
| # | Функция | Что делает | Характер |
|---|---|---|---|
| E1 | `SK.pop` | scale 0.55→1 с перелётом (`back.out(2.4)`) + вертикальное размытие движения | постер 0637, базовый |
| E2 | `SK.bounce` | падает сверху, отскакивает от базовой линии (`bounce.out`) + сжатие-растяжение (`elastic`) | **bounce**, удар по смыслу |
| E3 | `SK.spring` | из 0 с упругой пружиной (`elastic.out(1,.45)`) и докруткой | стикеры, чипы, иконки |
| E4 | `SK.slide` | горизонтальный влёт, размытие по X 28 px, 3D-поворот Y −40° | слайд-стек 0636 |
| E5 | `SK.depth` | издалека: scale 2.4→1 + defocus 18→0 px | футур, вопросы |
| E6 | `SK.slice` | 3 горизонтальные полосы влетают с разных сторон и «защёлкиваются» | футур, вердикт, смена слова |
| E7 | `SK.scan` | проявление за яркой линией сканера слева направо | футур, подписи, UI |
| E8 | `SK.rgb` | красная и голубая копии сходятся пружиной к белой/жёлтой | футур-акцент, название продукта |
| E9 | `SK.letters` | буквы снизу волной (`back.out(3)`, шаг 35–45 мс) | только крупные заголовки |
| E10 | `SK.type` | печать по символам | окна, UI, код |

### Выходы (X)
- `SK.whip(els, t, 'down'|'up'|'left'|'right')`: рывок 0.22 с с размытием движения 40 px по направлению. Это выход по умолчанию.
- `SK.fade`: только для мелочи.
- `SK.shrink`: схлопывание стикеров.

### Камера (K) и переходы
- `SK.punch('#cam', t, 1.12)`: панч-ин или панч-аут резом с зум-блюром 7 px за 0.16 с. **Держим ≤1.12** ([[sharpness-guard]]).
- `SK.push('#cam', a, b, 1.06)`: медленный наезд внутри сцены.
- Открытие из окошка: кадр `#win0` scale 0.58 → 1 с радиусом. Закрытие наоборот (рифма «начало = конец»).
- `SK.flash(el, t, цвет)`: вспышка 2–3 кадра. Белая на резе в продукт, красная на вердикте.
- `SK.leak(el, t)`: тёплый засвет-свип, **гладкий, без зерна**.
- Смена сцены: полноэкранный слой въезжает или уезжает (`yPercent`/`xPercent`) за 0.2 с, `expo.out` / `power3.in`.

### Объекты (инфографика вокруг человека)
- `SK.win(parent, {x,y,w,h,title,style:'glass'|'retro',html})` + `SK.open(w, t)`: окно с роликом, фото или рисунком.
  - В `#behind` (под маской человека) — **за головой**.
  - В `#front` — перед ним.
- `SK.cursor` + `SK.glide` + `SK.click`: курсор ездит и кликает. Окно на клике пульсирует 1.06.
- `SK.count(el, t, from, to)`: счётчик цены.
- Чип-карточка (`.chip`) с полосой (`.bar`).
- `SK.karaoke([[el,t],…])`: тусклые будущие слова, активное слово загорается (0639).
- Стикер-кнопка (`.stop`), 3D-плитки устройств, рисованные iPad/iPhone (`.ipad`, `.iph`).

### Слои композиции (шаблон)
`#bg` → `#win0 > #cam > [видео головы, #behind, person.webm]` → `#front` → полноэкранные сцены → `#top` → `#leak` → `#flash`.

`person.webm` = маска человека (MediaPipe, `v4/matte.py`, VP9 yuva420p). Она даёт «текст и окна за головой». HyperFrames рендерит альфу корректно (проверено 2026-10-25).

## 2. Образы (готовые сочетания)
| Образ | Из рефа | Модули |
|---|---|---|
| **L1 Постер** | 0637 | `sk-cond` жёлтый + `sk-script`; E1/E2; X whip; слово за головой; окна с роликами + курсор; панч-ины |
| **L2 Слайд-стек** | 0636 | `sk-sans` белый стопкой сбоку, ключ `sk-bloom`; E4; засвет; жёлтая студия с 3D-объектом; белая кинетика (E5 + росчерк) |
| **L3 Тёмное караоке** | 0639 | `SK.karaoke` на груди, разные размеры строк; E3 стикеры; красная вспышка; голова в окошке/телефоне |
| **L4 Футур** (новый) | наш | E6 slice, E7 scan, E8 rgb, E5 depth; окна «тёмное стекло»; графитовый стол-сетка; открытие и закрытие окном |

## 3. Правила смешения (чтобы было про, а не каша)
1. **1 основной образ + 1 акцентный.** v4: L1 основа, L4 акцент, по одной сцене L2 и L3.
2. **Шрифтов на кадре максимум 2** (+ `sk-ui` для подписей). Акцентный цвет **один** на сцену.
3. **Один модуль входа не больше 3 раз подряд.** Чередуем pop → slide → bounce.
4. **По смыслу:**
   - bounce — на «весомом» слове (дорогой, купить, очень);
   - slice / rgb — на вердикте и названии;
   - scan — на подписях;
   - karaoke — на длинной фразе;
   - count — только на цифре.
5. **Сцена меняется каждые 3–6 с:** голова → окно → студия → голова с инфографикой → белая сцена → b-roll.
6. **Две фразы не видны одновременно:** выход раньше следующего входа. `readcheck` ловит OVERLAP.
7. Нормы [[reading-time]], [[sharpness-guard]], без зерна, звук на каждое движение ([[sfx-expressive]]).

- Итог v4: 106 звуков, ~4 в секунду. SFX отдельно −19.7 LUFS при голосе −15.8: громко, но голос сверху. Мастер −14 LUFS.

## 5. Новые стили на основе модулей (придумано, бери в следующие ролики)
| # | Название | Сборка из модулей | Когда |
|---|---|---|---|
| F1 | **Голо-шторка** | scan + sk-bloom; линия сканера оставляет за собой тонкую сетку 1 px, которая гаснет за 0.3 с | технологии, характеристики |
| F2 | **Магнит** | буквы разлетелись по кадру (случайные x/y ±400), на слове стягиваются пружиной (`elastic`) | «собрать», «соединить» |
| F3 | **Слайс-переключатель** | slice, где полосы несут **новое** слово, а старое уходит полосами в другую сторону | «было → стало», цены |
| F4 | **Проекция на стену** | corner pin ([[text-in-space]] П4) + scan + `mix-blend: screen` | цитаты, тезис за спиной |
| F5 | **Тяжёлый bounce + пыль** | bounce + 6 мелких частиц-точек вылетают из-под базовой линии при ударе | весомое слово |
| F6 | **Глубинный стек** | depth по строкам; прошлые строки уходят назад (scale .8, blur 6, opacity .4), а не исчезают | списки, шаги |
| F7 | **Окно-портал** | окно открывается, в нём следующая сцена; камера влетает в окно (scale до заполнения) = переход | смена темы |
| F8 | **Разлом** | slice на 5 полос с разной задержкой и красная полоса-вспышка между ними | вердикт «нет», «не советую» |

Каждый новый стиль сначала проверяем в демо (5–8 с), затем записываем сюда с пометкой «проверено в ролике …».

## 6. Чек перед показом
- `node tools/readcheck/readcheck.mjs <comp>` → 0 FAIL / 0 OVERLAP. Призраки slice/rgb помечены `aria-hidden`, readcheck их пропускает.
- Кадры 1:1 на каждом переходе: ничего не обрезано краем (широкие слова ≤ 960 px при панч-ине 1.12).
- Контраст жёлтого на светлой стене: `sk-lift` обязателен.

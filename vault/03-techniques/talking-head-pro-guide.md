# Видеоблог «говорящая голова» — pro-гайд

Читать вместе с [[live-editing-v3]] (базовые нормы резов/субтитров), [[talking-head-look]] (свет и грейд), [[sfx-expressive]], [[sharpness-guard]], [[camera-allowed]].
**Поправка к [[live-editing-v3]] п.3:** запрет «медленный наезд / кадр не движется» отменён правилом [[camera-allowed]] (2026-10-20). Наезды и панорамы по кропу 4K разрешены — плавно, с motion blur, без серии резких ударов.

## 0. Что делает монтаж «ИИшным» на живой съёмке (и чем заменяем)
| ИИ-признак | Pro-замена |
|---|---|
| Субтитры приклеены к одной точке экрана, всегда внизу по центру | Текст **живёт в пространстве кадра**: привязан к голове/плечу/стене трекингом, меняет сторону вслед за позой (§3) |
| Графика — плоская наклейка поверх, не реагирует на человека | Графика в слоях: фон → графика → **человек (маска)** → субтитры. Человек может пройти перед текстом, рука «задевает» объект |
| Зум на каждом резе 100→110 % «бум» | Смена плана только на смене мысли, 3 крупности, иногда плавный push-in через фразу (§2) |
| Один и тот же whoosh/pop на всём | Звук описывает **конкретное событие**: скорость, массу, направление (§4) |
| Эмодзи, стоковые иконки, капс с красным словом | Реальные предметы, скрины, B-roll с телефона автора, типографский момент 1 раз на 5–10 с ([[captions-v2]]) |
| Мёртвая точность «в такт»: событие строго каждые 0.5 с | Ритм идёт от речи и жестов человека: волны, вдох перед главной фразой ([[rhythm-v2]]) |
| Пластиковая кожа, AI-фон, AI-голос | Оригинальный фон ([[keep-original-background]]), кожа без ретуши, голос только чистка ([[voice-processing]]) |

Главная мысль: **в живом видео главный «моушн» — сам человек.** Графика и звук подхватывают его движения, а не живут отдельно.

## 1. Подготовка материала
1. Проверить SAR/rotation, VFR→CFR, HLG→Rec.709 ([[phone-clips]]).
2. whisper large → `words.json` (тайминги слов) — сразу копия в `_inbox\ДАТА\` (не в .tmp, см. [[no-delete-without-yes]]).
3. **Карта человека** (нужна, когда в ролике есть текст у/за головой или трекинг), один проход скриптом по исходнику:
   - **Лицо/голова:** MediaPipe Face Landmarker (Python, RTX 5080) → на каждый кадр: центр лица, рамка, наклон (roll), поворот (yaw), масштаб. Сохранить `face_track.json`. Фоллбэк в AE: Mask → Track Mask → *Face Tracking (Detail Analysis)* — даёт точки глаз/носа/рта.
   - **Тело/руки:** MediaPipe Pose + Hands → плечи, запястья, кончики пальцев → `pose_track.json`. Нужно для SFX на жесты и для текста «в руке».
   - **Маска человека:** RVM / MatAnyone (или Roto Brush в AE) → альфа-последовательность PNG 16-bit. Нужна для текста за человеком и для грейда фона.
   - **События-жесты:** скрипт находит пики скорости запястий (> порога, напр. 1.2 ширины лица/с), кивки (пик скорости по Y центра лица), повороты головы (|Δyaw| > 15°). → `gestures.csv` (время, тип, сторона, сила). Это основа для SFX и акцентов.
4. Импорт в AE: трекинг-данные → **нули** с русскими именами: `ТРЕК Голова`, `ТРЕК Плечо Л`, `ТРЕК Рука П`, `ТРЕК Стена` (видимый таймлайн, [[ae-pipeline]]).

## 2. Черновой рез и планы
- Резы по словам ([[live-editing-v3]] п.2): паузы >300–500 мс вон, после реза 150–250 мс, оговорки и дубли вон, вдох перед главной фразой оставить.
- **Рез по движению:** резать в момент, когда человек моргнул или начал жест/кивок — склейка прячется в движении (*cut on action / blink cut*). Скрипт выбирает точку реза в окне ±3 кадра от паузы по ближайшему морганию (EAR из Face Landmarker) или старту жеста.
- **Jump-cut без «прыжка»:** если голова на двух сторонах склейки сдвинулась > 3 % кадра, менять крупность (100 ↔ 118 %) — тогда это смена плана, а не дёрг.
- Три крупности из 4K: общий 100 %, средний 115–120 %, крупный 135–150 % (редко, на кульминацию). Лицо по горизонтали — правило третей, взгляд «в сторону воздуха»; **воздух оставляем там, где будет текст**.
- **Кадрирование следует за головой мягко:** вертикальный кроп из горизонтали двигается по `ТРЕК Голова` со сглаживанием (скользящее среднее 0.5–0.8 с + мёртвая зона ±4 % ширины), чтобы кадр не «плавал» за каждым покачиванием.
- Плавный push-in 100→106 % за фразу на эмоциональной мысли — разрешён ([[camera-allowed]]), но ставим его на смысл, не чаще 1 раза на 8–12 с, и **оседание ровно на целом %** без дрожания ([[sharpness-guard]]).

## 3. Текст, который «живёт» в кадре (главная тема)
Пять уровней, от простого к сложному. В одном ролике — 2–3 уровня, смешивать по смыслу; уровни ротировать между роликами ([[variety]]).

### У1. Субтитры, которые уступают голове (база, всегда)
- Субтитры по умолчанию в зоне **55–75 % высоты** (ниже подбородка, выше UI Reels; safe zone: сверху 14 %, снизу 35 %, по бокам 6 %).
- Скрипт проверяет каждый кадр: если рамка лица (+10 % запаса) пересекается с блоком субтитров → блок **плавно сдвигается** (0.3–0.4 с, ease in-out) в свободную зону, а не прыгает. Лицо субтитры не закрывают никогда.
- Это не трек «намертво», а мягкое следование: позиция = сглаженный трек, обновляется только при выходе из мёртвой зоны.

### У2. Подпись, привязанная к голове/плечу (head-locked label)
- Короткая подпись 1–4 слова (ключевая мысль, цифра, имя) стоит **рядом с головой**, со стороны воздуха, и едет вместе с ней: текст **parent → `ТРЕК Голова`**, смещение = 0.9–1.2 ширины лица в сторону воздуха.
- Сглаживание: `smooth(0.25, 7)` на позицию; наклон текста = 30–50 % от roll головы (не 100 % — иначе пьяно).
- Человек повернул голову в другую сторону → подпись **перетекает** на новую сторону за 0.4 с (сначала уходит, потом входит), со звуком перетекания.
- Масштаб подписи следует за масштабом лица (смена плана 100→118 % → подпись тоже), иначе видно, что она «нарисована на стекле».

### У3. Текст за человеком (depth / occlusion)
- Слои: исходник → крупный текст → **исходник с маской человека** сверху. Человек перекрывает буквы, голова «внутри» слова.
- Только на **пиках** (1–2 раза на ролик): хук, главная фраза. Так же делают HeyGen embedded-captions: «embedding every word — частая ошибка».
- Текст получает грейд и лёгкий defocus как у фона на этой глубине, + тень от человека (маска, сдвиг, blur 40 px, 15–25 %) — тогда он «стоит в комнате».
- Край маски проверять кадрово на волосах и пальцах (ореолы = мыло/ИИ-признак).

### У4. Текст и графика на стене/столе (planar track)
- Mocha AE (есть штатно): трек плоскости стены/стола → Corner Pin / Transform на текст или карточку. Человек — holdout-маской, чтобы не сорвать трек.
- При статичной камере трек всё равно нужен, если есть кроп-движение кадра (§2) — иначе графика «съезжает» относительно стены.
- Перспектива, освещённость и цвет как у поверхности; motion blur от движения камеры включён.

### У5. Текст, которым «управляет» человек (gesture-driven)
- Жест из `gestures.csv` запускает анимацию: рука разводится → слово раздвигается; указание пальцем → подпись вылетает из кончика пальца (parent к `ТРЕК Рука`, затем отвязка и оседание); ладонь «отодвигает» блок → блок уезжает в сторону движения руки с той же скоростью.
- Человек считает на пальцах → числа 1/2/3 появляются у пальцев.
- 1 раз на 10–15 с — это самый «неИИшный» приём, потому что его невозможно сделать без исходного видео.

### Технические нормы текста
- Шрифты с кириллицей ([[captions-v2]]), живые текстовые слои, не картинкой; мелкий текст — только opacity+y, без blur ([[sharpness-guard]]).
- Время чтения по [[reading-time]].
- Тень/подложка подбирается к фону в этом месте кадра (проверка контраста ≥4.5:1 на всём пути трека, а не на одном кадре).

## 4. SFX на каждое значимое действие
Основа — [[sfx-expressive]] (каждый объект свой звук, тик на каждую печатную букву, нет «сиротских» звуков). Для живой съёмки добавляется слой **звуков человека и монтажа**:

| Событие (источник) | Звук | Норма |
|---|---|---|
| Смена плана 100↔118 % (рез) | короткий мягкий «тук»/воздушный щелчок, только на смене мысли | не на каждом резе: ≤1 из 3 резов; простые jump-cut тихие |
| Плавный push-in / панорама | низкий нарастающий воздух (rise), пик в момент оседания | длина = длине движения ([[camera-allowed]]) |
| Жест рукой (взмах, указание) | swish со стерео-панорамой **в сторону движения руки**, длина и «вес» = скорости жеста | из `gestures.csv`, порог силы; ≤1 на 2 с, иначе каша |
| Кивок / резкий поворот головы | очень тихий воздушный «фых» или ничего | только если на него анимирован текст |
| Хлопок, щелчок пальцами, удар по столу (реальный звук в записи) | **усилить реальный** звук + слой той же природы | не подменять синтетикой |
| Подпись У2 появилась / перетекла | мягкий поп / двойной свуш | разные для «вход» и «перетекание» |
| Текст за человеком (У3) | глубокий «тум» + хвост | только на пиках |
| Графика на стене (У4) | звук материала поверхности (бумага, стекло, дерево) | мир направления ([[directions-v3]]) |
| B-roll вставка | J-cut: звук B-roll начинается за 3–8 кадров до картинки | реальный звук сцены, если он есть |
| Печать текста | тик на букву ([[sfx-expressive]]) | |

Правила звука на голове:
- **Голос главный:** SFX на 10–16 дБ тише голоса во время речи; самые громкие события ставить в паузы/вдохи. Сайдчейн-дакинг SFX под голос 3–4 дБ.
- **Форма звука = форма движения** (Sonilo/Morphic): атака на старт, пик на «приземление», хвост на оседание; маленький жест → лёгкий короткий, большой → широкий длинный. Громкость сравнивать выровненной — громче ≠ лучше.
- Стерео-позиция по X события в кадре (лево/право), центр — для смен плана.
- Один файл не повторяется подряд; для повторных событий ±1 полутон и разный старт сэмпла.
- Без музыки, без природных атмосфер; фон — только тихий нашид или ничего ([[no-music]], [[ambience-library]]).
- Таблица аудита «время → событие → звук» перед сдачей (правило NO ORPHAN SFX).

## 5. B-roll и вставки
- Каждые 8–15 с «что-то новое»: B-roll, графика, смена плана, типографский момент.
- B-roll — реальные съёмки автора (руки, экран, предмет), фото CC0 из `assets\photos`, скрины сайтов в DPR 2–3. Без апскейла.
- Форматы вставки (ротировать): полный экран 1.5–3 с; карточка рядом с головой (голова уходит на 1/3, карточка по трекингу плеча); split 50/50; «окно» внутри фона за человеком (через маску); вставка, которую человек «держит» в руке (трек ладони).
- Переходы на голову обратно — cut on action или match по форме ([[ref-ui-card-build]] «shape rhyme»), не пакетные переходы.

## 6. Цвет и картинка
По [[talking-head-look]]: фон −1…−2 стопы относительно лица через маску человека, кожа через HSL, единый LUT на серию, без зерна, без бьюти-ретуши, оригинальный фон. Резкость: никакого апскейла выше 150 % от 4K, кроп-движение с субпиксельной точностью, рендер Full ([[sharpness-guard]]).

## 7. Звук голоса
[[voice-processing]]: без de-reverb/de-echo; HPF 80 Гц, лёгкий EQ на разборчивость 2–5 кГц, компрессия 2:1–3:1, де-эссер, −14 LUFS, TP −1. Шумодав только мягкий, если фон реально шумит (проверить ухом).

## 8. Сборка в AE (видимый таймлайн)
Сверху вниз, все слои с русскими именами и маркерами ([[ae-pipeline]]):
`SFX …` (в аудио-композиции) · `ТЕКСТ субтитры` · `ТЕКСТ У2 подпись у головы` · `ЧЕЛОВЕК маска (для У3)` · `ТЕКСТ У3 за спиной` · `ГРАФИКА на стене (Mocha)` · `B-ROLL …` · `ГРЕЙД фон (маска)` · `ИСХОДНИК план 100/118/140` · нули `ТРЕК …`.
Маркеры: каждое событие из `gestures.csv` и каждый рез — маркер с подписью (жест/план/текст), по ним же стоят SFX.

## 9. QA-чеклист (до показа, плюс [[qa-frame-by-frame]], [[anti-ai-qa]])
- [ ] Лицо не перекрыто текстом ни в одном кадре (скрипт: пересечение рамки лица и bbox текста = 0).
- [ ] Трекинг не дрожит: прогон на 100 %, на скорости 0.5×; подпись не «отстаёт» от головы > 2 кадров.
- [ ] Маска человека: края волос/пальцев без ореола на всех кадрах У3.
- [ ] Каждый SFX привязан к видимому событию (таблица аудита), нет звука без события и громкого события без звука.
- [ ] Резы прячутся в движении/моргании; нет jump-cut с прыжком головы на том же плане.
- [ ] Safe zones соблюдены на всём пути трека.
- [ ] sharp preflight + sharpcheck зелёные ([[sharpness-guard]]).
- [ ] Приёмы уровней У1–У5 и форматы B-roll не повторяют прошлый ролик ([[variety]]); записать в урок ролика.

## 10. Что попросить у автора при съёмке (коротко)
4K, горизонтально (запас кропа и сдвига для трекинга) или вертикально 4K; камера на уровне глаз; 1.5–3 м до фона; **жестикулировать естественно** — жесты станут поводами для графики и звука; 2–4 перебивки на телефон (руки, экран, предмет по теме); 2–3 секунды тишины в начале для шумового профиля. Подробнее — [[talking-head-look]], [[talking-head-editing-2026]] §1.

## Правило (2026-10-20, отзыв на тест 2)
9:16 из горизонтали: **лицо всегда в центре** по трекингу (или по замеру на сетке, если камера статична), без «художественных» боковых сдвигов; проверять каждый план на контакт-листе. Грейд **не темнит** исходник: без виньетки над спикером, яркость лица сверять с raw.

- Минимальный план лица 1.5 с (лучше 2–4 с, хук ≥ 2.5 с), щели между вставками < 0.6 с закрывать; плотность — внутри кадра с лицом, не нарезкой. Никаких пустых плашек/стекла без содержимого (2026-10-20).

- Чередовать крупности: общий / средний / крупный, не только крупные; менять крупность на смене мысли, плавный наезд/отъезд с motion blur, без апскейла выше 100 % (1080p-исходник: общий план на оформленном фоне или сплит вместо фейкового крупного) — пользователь 2026-10-20.
- Перед тестом проверять «сырьё» с YouTube: часто это шоурил или уже смонтированная версия с музыкой (Outlive Creative, MrDenoise) — смотреть лист кадров и тишину под речью (silencedetect −45 dB) до монтажа.

**Продолжение (2026-10-21):** сложный «дорогой» уровень — обложка за головой, морф слова, слова выходят из-за головы, выноска с ленивой коробкой, 4 ракурса из одной камеры, 9 переходов, сквозная инфографика, SFX от событий — в [[pro-advanced-editing]].

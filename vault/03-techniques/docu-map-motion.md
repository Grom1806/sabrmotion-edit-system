# Документальный моушен на карте

**Когда брать:** ролик **без человека** (source = только голос / с нуля), тема с местом и временем: история, путь, распространение, сравнение стран, хронология. Пульт: тип «Видео с нуля», build = `map`, пресет «Документальный на карте» ([[ummah-ideas-panel]]). Разбор приёмов Д1–Д24 — [[ref-docu-motion-2026-10-21]]. Это **один из типов**, а не шаблон на всё ([[techniques-by-situation]]): из 24 приёмов в ролик 30 с берём 6–10.

Эталон: `VIDEOS\ummah\2026-10-21_bukhari-path\bukhari30_v1.mp4`, урок [[2026-10-21-ummah-bukhari-path]].

## Порядок работы
1. **Сценарий под карту.** Каждый бит отвечает на вопрос «где мы на карте?». Пишем биты как станции: город → перелёт → город. На 30 с: 5–6 предложений, ~60 слов, 1 хук-вопрос, 1 цифра-контраст, 1 финальный предмет.
2. **Бюджет голоса до озвучки.** ElevenLabs eleven_v4 ≈ **0.4 кредита на символ** (777 символов → 310). Посчитать символы с ударениями (`len(text)`), сверить с остатком; не влезает — ужать текст, а не дробить на дубли. Одна попытка, без тестовых запросов.
3. **Голос** (Remote Control на ПК): `node tools/tts.js <voice> take30 audio/voice30.txt`, затем скопировать `take30.mp3/json` из корня рилса в `work/vo/` (tts.js пишет в корень, words.js читает из work/vo) и `node tools/words.js take30 1.0` → `work/voice.wav` + `work/words.json`. Проверка текста: faster-whisper small (cloud).
4. **Все времена — из слов.** `cue('слово', n, end)` по words.json (ударения и «» срезаются). Никаких секунд руками: при новой озвучке ролик перестраивается сам. До озвучки — фейковые тайминги (14.5 симв/с, паузы на точках), потом подмена файла.
5. **Стиль-фреймы** (3 кадра: хук, маршрут, сцена-объект) → затем анимация.
6. **Рендер кусками параллельно** (~3 с на кадр на ядро в облаке): `render.py out t0 t1`, 4–5 кусков, склейка concat без перекодирования.
7. **SFX из событий** (`sfx30.py` → таблица) → микс → −14 LUFS → контактные листы каждые 0.5 с → сдача.

## Звук (без музыки)
- Каждый звук = событие в том же кадре ([[sfx-expressive]]). Таблица `sfx_audit*.tsv` время → событие → файл → дБ.
- **Перелёты камеры озвучиваются автоматически:** ищем пики `cam_speed` > 14 px/кадр; > 60 → windy_swoosh, > 30 → whoosh_long, иначе short_sweep; пик звука выравнивается в кадр пика скорости.
- Буквы хроники: `desk/key_01–06` по кругу, −31 дБ, панорама слева направо по строке. Города: `ui/kenney_drop_002` с питчем ±2 полутона. Плашки: card_drop/card_slide. Лупа: tick на звено. Счётчик: `el_slot_ticks`, обрезан под длину счёта. Большое слово: impactSoft_heavy + sub_hit по пику.
- Микс: голос −1 дБ, SFX с сайдчейном −3.7 дБ под речью, двухпроходный loudnorm −14 LUFS / TP −1.5. В «Бухари» 129 SFX на 28 с.

## Ошибки, которые уже были
- Подпись города налезла на хвост хука → ставить камеру так, чтобы город был **ниже** текста хука (центр камеры севернее на ~1.5–2°).
- Контур страны резал крупное слово → маска полосы текста (y 220–980) на время хука.
- Печатная машинка 0.028 с/символ + тик на букву = треск → 0.042 с; длинную подпись хроники сокращать.
- `pgrep -f` в цикле ожидания находит сам себя → ждать по PID или по числу кадров в кусках.
- `/mnt/project-files` переписывает .mp4 при записи (md5 файла другой, поток тот же: сверять `ffmpeg -c copy -f md5`). Файлы > 25 MB на ПК — частями `split -b 20M` → commit → `cat`.

# Анти-ИИ для живой говорящей головы (2026-10-20)

Pro = решения человека; ИИ = пресет на всё. Признак ИИ → замена → наш ассет:

1. Все слова субтитров одного размера внизу → слово-герой 3–6× другим шрифтом, остальное мелко на груди → пара курсив-антиква+гротеск, позиция по трекингу головы.
2. Капс с красным словом в каждой фразе → акцент ≤1 на 3–5 с, цвет по смыслу → красный=проблема, зелёный=решение.
3. Эмодзи/стоковые иконки как главная графика → реальные предметы, свои съёмки, скрины, 3D-телефон со спикером → assets\photos, Blender, скрины DPR2–3; иконки служебно.
4. Голова 100 % → ≤50–60 %, остальное B-roll/экраны/карточки.
5. Зум на каждом резе → смена крупности на смене мысли, push-in раз в 8–12 с.
6. Один свуш на всё → ~1 атака/с с речью, звук от материала события, разные файлы, без музыки.
7. Текст на стекле → цифры за головой, рука перед буквами, тумблер под жестом (маска человека, gestures.csv).
8. Плоский кадр → фон темнее лица, практики, виньетка; фон оригинальный.
9. Пресет-переходы → склейка + 1–2 особых (вспышка-шар, iris, push в карточку).
10. Одинаковые экраны → экраны-паузы 1–2 цветов, каждый раз новая композиция; 26 шаблонов инфографики.
11. Дашборд → одна цифра/кривая на экран, реальные данные.
12. Список сразу → пункты по одному, текущий цветной, прошлые серые.
13. Текст = голос → экран показывает следствие/доказательство.
14. Мыло/зерно → живые слои, glow только на крупном слове, NO GRAIN.
15. AI-фон/бьюти → реальная комната, естественная кожа.
16. Метроном → ритм от речи, плато 1–2 с.
17. «Подпишись» → луп, логотип SABRMOTION, слово тает.
18. Одинаковый стиль → основа A/B/C/D + 3–5 рецептов R1–R15.
19. Кадры фильмов/деньги → нельзя; свои съёмки, CC0.
20. Видны склейки → рез на моргании/жесте или со сменой крупности.

## Карта арсенала (ориентир, по ситуации — [[techniques-by-situation]])
2 шрифта (новые), ≥2 фото, ≥1 3D, ≥1 инфографика на данных, иконки служебно одним семейством, свой SFX на тип события, ≥1 рецепт R впервые (запись в assets\_usage.csv).

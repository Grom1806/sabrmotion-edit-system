# Анти-ИИ для живой говорящей головы

Общий принцип из референсов: **pro-монтаж выглядит как решения человека** — одно главное слово, одна идея на экран, свой материал, звук от событий. ИИ-монтаж выглядит как применённый ко всему пресет.

| # | Признак ИИ-вида | Как делает профи (референс) | Что берём у нас |
|---|---|---|---|
| 1 | Все слова субтитров одного размера, внизу по центру | Одно слово-герой в 3–6× крупнее другим шрифтом, остальные мелко на груди (A, B, C) | Шрифтовая пара из [[captions-v2]]: курсив-антиква + гротеск; позиция по трекингу головы ([[talking-head-pro-guide]] У1–У2) |
| 2 | Капс пословно с одним красным словом на каждой фразе | Акцент ≤1 на 3–5 с, цвет по смыслу (проблема/решение), а не на каждой фразе | Палитра бренда ([[sabrmotion]]): красный = проблема, зелёный = решение |
| 3 | Эмодзи и стоковые иконки как главная графика | Реальные предметы, свои съёмки, скрины, 3D-телефон со спикером (A, C) | `assets\photos` (314 CC0), 3D-предметы в Blender, скрины DPR 2–3; иконки только служебно (пункты списка) |

| 11 | Инфографика-шаблон «дашборд» | Одна цифра/кривая на экран, реальные данные, растёт по ходу речи (B: кривая с точкой) | [[use-everything]] — инфографика на реальных данных |

## Карта арсенала для ролика с живой головой (минимум)
- Шрифты: 1 антиква-курсив + 1 гротеск с кириллицей (не те, что в прошлом ролике).
- Фото/фактуры: ≥2 из `assets\photos` или съёмки автора.
- 3D: ≥1 предмет (Blender) или 3D-телефон со спикером.
- Инфографика: ≥1 экран на реальных данных из `assets\infographics`.
- Иконки: только служебно, одно семейство (iconoir/hugeicons).
- SFX: свой файл на каждый тип события, таблица аудита без «сирот».
- Техника впервые: ≥1 из R1–R15, которой ещё нет в `assets\_usage.csv`.

Проверка: этот список + [[anti-ai-qa]] на стиль-фреймах и перед сдачей; записать в урок ролика, какие пункты сработали.

# Каталог субтитров = SABR-kit

**Решение пользователя (2026-10-25 03:28):** старые стили (S1–S10, T1–T8, C1–C8 и «яркие» N1–N12) некрасивые и старые, их убрать. Остаётся только то, что выучено по его референсам.

Старые стили лежат в архиве `vault/_archive/captions-old-2026-10-25/` и **не используются**.

## Что берём
Только модули и образы [[style-kit]]:

| Образ | Суть | Когда |
|---|---|---|
| **L1 Постер** | жёлтый #EAD43A узкий капс (Oswald) + курсив-антиква (Playfair Italic); слово за головой (маска), над головой, на груди; pop / bounce, выход рывком | основа большинства роликов |
| **L2 Слайд-стек** | белый тяжёлый гротеск (Montserrat 900) стопкой сбоку или над головой, ключевое слово жёлтое с блумом, влёт со смазом по X | мнение, «я думаю», перечисления |
| **L3 Тёмное караоке** | вся фраза тусклая, сказанное слово загорается; стикеры-кнопки, красная вспышка | длинные фразы, объяснения |
| **L4 Футур** | slice, scan, RGB-сведение, из глубины; окна «тёмное стекло» | вердикты, названия, цифры |

**В ролике:** 1 основной образ + 1 акцентный. Модули меняем, чтобы ролики не повторялись.

Новые стили придумываем **на основе** модулей (рецепты F1–F8 в [[style-kit]]) и записываем туда же.

## Нормы (не отменяются)
1. **Безопасная зона Reels/TikTok** (с 2026-10-25, проверяет `readcheck`, статус SAFE):
   - текст не выше y 210 (шапка) и не ниже y 1480 (ник, подпись, музыка);
   - справа колонка кнопок: при y 640–1480 ничего не заходит правее x 910;
   - центрированный текст выравниваем по x≈475, а не по 540 (класс `.c`).
2. **Лицо не закрываем:** при крупном плане (1.8–1.9) текст выше лба или ниже подбородка.
3. **Две фразы не видны одновременно** (OVERLAP).
4. Время чтения по [[reading-time]].
5. **Шрифтов 2** на кадр (+ `sk-ui` для подписей), **акцентный цвет 1**.
6. Свечение только `sk-bloom` на 1–2 ключевых словах.
7. Без зерна.
8. На светлой стене жёлтый текст всегда с `sk-lift`.

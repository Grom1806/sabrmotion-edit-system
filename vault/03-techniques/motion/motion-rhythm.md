# I. Ритм сцены (шаблон фразы 3.5 с)

0.0 переход (whip/mask) → 0.2 объект-герой pop → 0.6 лейбл/пилюля → 1.0 действие объекта (деньги летят/счётчик тикает/телефон звонит) → 2.0 ударное слово: punch-in + штамп/слово-slam → 2.8 подготовка перехода (камера уже едет) → 3.5 следующий переход.

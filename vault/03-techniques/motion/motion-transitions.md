# D. Переходы между сценами

20. **Whip pan** — сдвиг 100 % кадра за 0.18 с + directional blur 40 px. SFX: whip.
21. **Match cut** — круг-аватар → монета → «0» в цифре: форма сохраняется, содержимое меняется на пике скорости.
22. **Mask/shape wipe** — терракотовый круг/полоса расширяется из объекта (clip-path circle 0→150 %). SFX: whoosh + sub.
23. **Morph-переход** — карточка растягивается в полный экран и становится фоном новой сцены.
24. **Glitch cut** — 3–4 кадра RGB-split, смещение полос, шум. Для «наоборот», «−1 000 000». SFX: glitch.
25. **Liquid/ink transition** — заливка «жидкостью» по маске (готовые альфа-видео или SVG-turbulence). Редко, для смены главы.
26. **Light leak / film burn** — 6–10 кадров тёплой вспышки поверх склейки. SFX: soft swell.

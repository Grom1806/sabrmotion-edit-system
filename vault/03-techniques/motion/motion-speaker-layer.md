# F. Спикер как слой

33. **PiP-круг / скруглённое окно** в углу, двигается по кадру между сценами.
34. **Cut-out спикер** — вырезанный по маске человек поверх графики (робаст-маттинг), за ним сцены меняются.
35. **Спикер за графикой** — графика полностью перекрывает лицо, сквозь «окно» карточки видно только глаза/рот на эмоциональных словах.
36. **Freeze-frame + обводка** — стоп-кадр спикера, белая обводка-стикер, он «вылетает» из кадра. SFX: record scratch / freeze.
37. **Split screen** — слева спикер, справа сцена (база для 16:9 из референса 6709).

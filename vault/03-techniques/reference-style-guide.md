# Style guide по референсам (IMG_6708 вертикаль, IMG_6709 горизонталь)

Оба референса — тот же сценарий «Шкала должника» (52.7 с и 61.7 с), смонтированный «как у профи». Это эталон, к которому тянем все говорящие головы.

## 1. Концепция
- **Ролик = интерфейс/игра.** Постоянный HUD «ШКАЛА ДОЛЖНИКА · УРОВЕНЬ 01/12» + сегментированный прогресс-бар (12 сегментов). Каждый пункт списка = новый «уровень».
- **Каждой фразе — своя мини-сцена-метафора** в виде UI-макета (не просто текст): календарь «до зарплаты» с обратным отсчётом, карточка банковского перевода «ожидается на днях» со счётчиком дней и неделей, пуш-уведомление «Вернуть долг брату» которое смахивают (счётчик ×0→×7), чат «Должник печатает…» с «новых сообщений: 0», банковская карта «0,00 ₽» + штамп «НЕДОСТАТОЧНО СРЕДСТВ», экран входящего звонка + перечёркнутый колокольчик и счётчик пропущенных, переписка где собеседник меняет тему, «+1 000 000 ₽» → «−1 000 000 ₽», сетка алфавита «должен 10 из 20», круговая схема «долгов» (должен тем, кто сам должен), финал «а кому?».
- **Повтор структуры = ритм.** Одинаковая сетка каждого уровня: HUD сверху → иллюстрация (верхняя половина) → аватар + цитата → «СУММА ДОЛГА» внизу. Зритель учится читать экран за 2 уровня, дальше только ловит новое.

## 2. Компоновка 9:16 (1080×1920)
- Хук (0–4 с): спикер на весь кадр, снизу плашка-лейбл «● ШКАЛА ДОЛЖНИКА · 12 УРОВНЕЙ», заголовок печатается по словам, последнее слово — белым по терракотовой плашке с наклоном −3°: «должник?».
- Переход в формат: лицо **сжимается в круглый аватар** (~200 px, обводка терракота 3 px) и уезжает влево-вниз к цитате (~0.5 с, ease-in-out); сверху въезжает HUD.
- Нижняя треть: «ДОЛЖНИК · 0N» мелким капсом над пузырём-цитатой (кремовый #f4ece4, радиус 18, тёмный текст). Цитата появляется по словам с размытием (blur→0), как набор.
- «СУММА ДОЛГА» внизу слева: сначала «??? ₽» серым, потом «слот-машина» — мелькают размытые случайные числа (17 400, 640 000, 1,7 …) 0.6–1 с, приземляются на диапазон «30–50 тыс ₽» терракотой, жирно, с подчёркиванием, которое прорисовывается слева направо; в момент приземления — вылет 3–6 купюр (₽-банкноты) из угла с вращением.
- Финал: полная заливка терракотой, спиннер-«?» загрузки, «Вопрос не сколько, **а кому?**», плашка «от 10 млн ₽+», дождь из купюр; потом обратно спикер крупно + «А ты узнал / своего / [должника?]» (последнее на плашке).
- 16:9 версия (6709): спикер слева ~45 % кадра без обрезки в круг, справа колонка: HUD, плоская иконка (Lucide-подобные, линия + терракотовая заливка детали: песочные часы, стикер, колокольчик, люди, стрелка-разворот, ₽ по кругу), цитата, сумма.

## 3. Цвет и айдентика
- Фон: почти чёрный #090708 с тёплым радиальным свечением сверху/по центру (#2e1914 → #110d0a), лёгкое зерно и виньетка. Видео спикера тёмное, низкий ключ, тёплая кожа, тени уходят в чёрное (обрезка снизу в градиент).
- Акцент: терракота **#c85a43** (диапазон #c05840–#d05840), финальная заливка #c8634f.
- Карточки/пузыри: крем **#f4ece4**, текст на них #1a1a1a; вторичный серый #8a8580; неактивные сегменты #3a3330.
- Один акцент на кадр. Никаких других цветов.

## 4. Типографика
- Гротеск с кириллицей. Цифры и суммы — широкий ультражирный (похоже на Druk Wide / Unbounded Black / Montserrat Black); тексты цитат — Inter/Manrope Medium–SemiBold; служебные лейблы — капс 11–13 pt, трекинг +15–20 % (ШКАЛА ДОЛЖНИКА, УРОВЕНЬ, СУММА ДОЛГА, ДОЛЖНИК · 01).
- Номер уровня крупно «01» + мелко «/12».
- Бесплатные замены: Unbounded (Black) для цифр, Inter / Manrope для текста — оба Google Fonts, кириллица есть.

## 5. Анимация (что даёт «дорогое» ощущение)
- Вход карточек: сдвиг 60–120 px + **motion blur** (directional blur по ходу) + scale 0.92→1 + лёгкий наклон 2–4°, ease out-back/out-expo, 0.35–0.5 с. Выход — уезжает в сторону с blur, 0.25 с.
- Внутри карточки всё живёт: счётчики тикают (17→0 дней, 1→61 день, ×0→×7, пропущенных 2→16, 0→10 из 20), выбранный день недели перескакивает, «печатает…» точки пульсируют, уведомления складываются стопкой и смахиваются.
- Штампы («ЗАРПЛАТА!», «НЕДОСТАТОЧНО СРЕДСТВ») падают со scale 1.4→1 и наклоном −8°, с микротряской.
- Текст: появление по словам с blur 8px→0 и y+10→0.
- Числа «−1 000 000»: перечёркивание/смена знака с глитч-сдвигом.
- Плотность: новое визуальное событие каждые **0.5–1.0 с**; смена уровня каждые ~3.5 с.
- Камера на спикере в хуке: медленный push-in + рывковый зум на ключевом слове.

## 6. Звук
- Громкость: −17 LUFS интегр. (наш таргет −14 оставляем), LRA 2–4 LU.
- В 6708 **постоянная музыкальная подложка** (низ не проседает в паузах, нижний перцентиль энергии на 27 дБ выше, чем в 6709). Тёмный минималистичный бит/пэд, тихо, под голос.
- **SFX ~55–65 на минуту ролика (≈1 в секунду)**: детектор высокочастотных транзиентов нашёл 58 (6708) и 67 (6709). Плюс 30–40 низких «бумов»/sub-hit (смена уровня, приземление суммы, финал).
- Карта SFX по событиям: вход карточки → whoosh короткий; тик счётчика → мягкие клики/тики (каждая смена цифры); печатание цитаты → лёгкий keyboard/typing; уведомление → iOS-подобный ding/pop; смахивание → swipe; штамп → thump; сумма-слот → быстрые тики + cash register / coin при приземлении; купюры → paper flutter; смена уровня → sub hit + UI-click; звонок → вибро/рингтон; финал → riser + boom + money rain.

## 7. Субтитры
- Отдельных субтитров нет: речь «встроена» в графику (заголовок хука, пузырь-цитата, суммы), без дублирования. В финале — крупный текст по словам с плашкой на последнем.

## 8. Чек-лист «уровень референса»
1. Есть сквозная айдентика (HUD/прогресс/лейблы) — да/нет.
2. Каждый смысловой бит имеет визуальную метафору (UI-макет, иконка, фото).
3. Ни один кадр не статичен дольше 1 с.
4. SFX по [[sound-v2]], музыку не брать ([[no-music]]), громкость −14 LUFS, TP ≤ −1.
5. Палитра: чёрный + терракота + крем, один акцент.
6. Motion blur на всех быстрых движениях.
7. Финал меняет фон (заливка) и возвращает спикера крупно с CTA-вопросом.

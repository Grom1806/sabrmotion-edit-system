# Анти-ИИ проверка

Делается дважды: на стиль-фреймах (пункты 1–7, 13) и на готовом ролике (все). Идёт вторым шагом после [[qa-frame-by-frame]]. Если пункт не выполнен — исправить или записать в бриф, почему так задумано.

1. Идею ролика можно назвать одной фразой, и это не «карточки по словам» ([[concept-first]]).
2. 20 кадров рядом с контакт-листом прошлого ролика легко отличить (стиль, шрифт, палитра, композиция).
3. Нет без смысла: REC-таймера, ▶, полосы прогресса, окон с тремя точками, «дашборд»-карточек, одинаковой зелёной CTA-кнопки, тёмного фона с неоном по умолчанию.
4. Минимум 3 бита показывают то, чего нет в речи (доказательство, следствие, предмет). Текст на экране не повторяет голос слово в слово.
5. Хотя бы один элемент намеренно не по центру или выходит за край; композиция по сетке.
6. Есть реальный материал: снятый кадр, скриншот реального продукта/статьи, фото или фактура (зерно, бумага). Графика «вплавлена»: общий грейд, зерно, тени.
7. Шрифтовая пара и система субтитров отличаются от прошлого ролика минимум по 2 пунктам ([[captions-v2]]).
8. Субтитры фразами, обычный регистр; акцент ≤1 на 3–5 с и только на смысловом слове; не капс пословно с красным словом.
9. Есть хотя бы одна пауза ≥1.5 с без нового события и без SFX; ритм волнами ([[rhythm-v2]]).
10. В Graph Editor нет линейных ключей; motion blur на движущейся графике (кроме стилей «на двойках»); у разных типов элементов разные входы.
11. Переходы только на смене сцены/пике; не больше одного вида перехода подряд.
12. SFX в пределах нормы уровня; не на каждом появлении; есть записанные звуки; нет одного файла дважды подряд; нет тональных звуков ([[sound-v2]]).
13. Цвет выставлен по скоупам и проверен на телефоне; фон говорящей головы темнее лица ([[talking-head-look]]).
14. Хук: сильнейший визуал в первом кадре, смысл в первые 1–3 с.
15. Чужие продукты не критикуются ([[no-negativity-about-others]]).
16. (v3) Нет ни одного из 10 признаков ИИ-вида ([[SYSTEM]]); направление не то же, что у двух прошлых роликов ([[directions-v3]]); всё плавное, ни один элемент не появляется без анимации ([[motion-v3]]).
17. (v3) Плотность не ниже Мощного (если не выбран другой уровень): статичных кадров ≤40 %, инфографика на реальных данных в каждом бите.
18. (v3) Резкость на 100 %: текст живыми слоями, растр не увеличен, крупный текст не обрезан полями при ударе камеры; таймлайн AE читается человеком (слои с именами).
19. Карта арсенала из брифа выполнена ([[use-everything]]): каждая строка в ролике с тайм-кодом или снята с причиной; есть ≥1 ассет и ≥1 приём, ни разу не использованные раньше; файлы записаны в `assets\_usage.csv`.

Записать результат (сколько пунктов прошло, что исправили) в заметку ролика в `04-lessons/reels/`.

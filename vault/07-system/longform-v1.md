# Длинный формат v1 (видео от 5 минут)

Главнее [[live-editing-v3]] и [[rhythm-v2]] для роликов ≥5 мин. Учебник с источниками — [[longform-pro-editing-2026-10-21]].

## Почему (разбор ролика Уорда Каннингема, 2026-10-21)
Ролик технически чистый, но сделан как «интервью с наклейками», а не как фильм:
1. **Нет истории.** Шли в порядке интервью; хук — общая фраза, а не загадка или конфликт; нет актов, нет ре-хуков, нет причины смотреть дальше.
2. **~90 % экрана — говорящая голова.** B-roll был только вшитый в исходник; ни одного своего архива (скрины старого c2.com, HyperCard, Mosaic, карты, таймлайн 1987→1995→2001).
3. **Одна форма графики на всё** — бумажная карточка слева. 100+ раз одно и то же = монотонность и «ИИ-шаблон».
4. **Ровная плотность.** Нет всплесков и пауз; наезды расставлены автоматом, а не по смыслу.
5. **Звук-шум**: 1500 тиков машинки ≠ звуковой дизайн; нет тишины-акцента и звуковых сцен.
6. **Цвет**: B&C +4 вместо грейда — нет отделения лица от фона и своего вида у архива.
7. Кроп 1080p до 125 % = мягкая картинка на крупных планах.

## Процесс (каждый длинный ролик)
**0. Материал.** Полная расшифровка с таймкодами слов. Список архива, который реально можно найти (Википедия/Commons, Wayback Machine, архивы, свои съёмки предметов). Без архива длинный ролик не начинаем — сначала собрать «коробку доказательств» ≥20 единиц на 8–10 мин.

**1. Paper edit (до монтажа, документом `story.md`).**
- Одна фраза — **центральный вопрос** фильма (например: «Как программа, которая разрешает всем всё портить, стала самой надёжной энциклопедией?»).
- **3 акта**: А1 (0–20 %) завязка + событие-толчок; А2 (20–80 %) осложнения, поворот в середине; А3 (80–100 %) ответ + эмоциональный вывод.
- **Хук 0–30 с** = самый сильный конфликт/парадокс из всего материала + обещание ответа, а не первая фраза интервью. Порядок интервью можно менять, смысл слов — нельзя (без франкенбайтов).
- **Карта ре-хуков**: каждые 2–3 мин строка «новый вопрос / поворот / цифра»; каждая глава начинается с вопроса и заканчивается крючком на следующую.
- Сокращать: у каждой цитаты вопрос «работает ли история без неё».

**2. Радио-кат.** Собрать только звук; прослушать целиком как подкаст. Если скучно на слух — картинка не спасёт, вернуться к п.1.

**3. Картинка — карта покрытия (`coverage.md`).**
- **B-roll/архив/графика на весь экран ≥35 % времени** (ориентир док. 60/40); лицо — на эмоциях, признаниях, шутках, выводах.
- Визуал **добавляет / контрастирует / предвосхищает**, а не повторяет слово в слово.
- **Разнообразие форм** (минимум 6 разных за ролик, ни одна не дольше 25 % графики): полноэкранный архив с движением (въезд со смещением + блюр 8 кадров), скрины статей с подсветкой фразы, match cut по тексту, карта, таймлайн, предмет «руками» на столе, сплит лицо+архив, текст за человеком, полноэкранная типографика главы, инфографика на реальных числах, 2.5D-параллакс фото.
- **Своя съёмка** где можно (руки, распечатки, экран) — единый «ручной» мир.

**4. Ритм по Пирлман/Мёрчу.**
- Рез — по эмоции и смыслу (правило шести), моргание/жест — для маскировки.
- Волны: план с лицом 8–25 с; **всплеск 5–10 быстрых событий каждые 2–3 мин** (архивная последовательность, match cut); после откровения — 1–2 с тишины на лице.
- Крупности: пропускать ступень, не «средний → средний»; лицо в пределах 10 % между планами. На 1080p-исходнике кроп ≤115 %, крупный план — только если есть 4K.
- Переходы только на смене акта/главы и откровениях; J/L-cut на входах в B-roll (звук архива за 3–8 кадров).

**5. Звук.** Каждое действие на экране мотивировано звуком (Vox), но **один звук на объект, а не на букву** в длинном видео (тик на букву — только для 1–3 крупных заголовков). Звуковые сцены для архива (звук эпохи: модем, клавиатура, принтер — нетональные). Тишина-акцент 1 раз на главу. Room tone только из исходника. Музыки нет ([[no-music]]).

**6. Цвет.** Интервью — натурально и одинаково (кожа, контраст), фон на 0.5–1 стопа ниже лица мягкой маской (без затемнения лица); архив/скрины — свой отдельный вид (например, чуть холоднее и мягче). Проверка по скоупам.

**7. Типографика.** Главы — полноэкранные «сцены» 2–4 с (не только плашка), в каждой главе свой визуальный мотив внутри единой системы.

## Чек-лист «как у профи» (перед сдачей, все пункты «да»)
- [ ] Центральный вопрос формулируется одной фразой; хук — парадокс/конфликт, не вступление.
- [ ] Есть 3 акта и поворот в середине; ре-хук каждые 2–3 мин (таблица таймкодов).
- [ ] Радио-кат прослушан целиком и работает без картинки.
- [ ] Полноэкранный B-roll/архив/графика ≥35 % времени; ≥20 единиц настоящего материала.
- [ ] ≥6 разных форм визуала, ни одна не >25 %; нет «одной карточки на всё».
- [ ] Ни один план с лицом не стоит >40 с без события; нет 2 с мёртвого воздуха.
- [ ] Всплески каждые 2–3 мин и тишина после главных фраз.
- [ ] Звук: один звук на объект, тишина-акцент в каждой главе, голос всегда разборчив.
- [ ] Грейд: интервью ровное, архив свой вид, лицо отделено от фона.
- [ ] Факты на экране проверены ([[fact-check]]), чужие продукты не ругаем ([[no-negativity-about-others]]).

# Анимация v3

**Главнее старых заметок про «на двойках», Hold-ключи и жёсткие появления.** Где [[directions-v3]] или [[practitioners-web-2026-10-19]] советуют ступенчатую анимацию (8–12 fps), это теперь только приём для отдельного кадра по идее, не база.

## 5 правил пользователя
1. **Всё плавное.** 30/60 fps, мягкие кривые, motion blur на движении, никаких рывков и резких дёрганий. Кадр целиком не двигается ([[SYSTEM]]) — плавно двигаются элементы.
2. **Ничего не появляется сразу.** У каждого элемента есть вход (и выход): текст, плашка, цифра, скрин, иконка, стрелка. Ни одного «вклеенного» кадра без анимации.
3. **Много анимации везде.** На экране всегда что-то живёт: вход, вторичное движение (лёгкий дрейф 2–6 px, пульс, перетекание цвета), выход. Пустых статичных секунд нет (кроме задуманной паузы перед главной фразой).
4. **Расширение блоков/квадратов — чаще.** Плашки, карточки, рамки, выделения раскрываются из точки, из линии или из угла; блоки раздвигаются, освобождая место новому; квадрат вырастает и становится фоном следующей сцены.
5. **Bounce.** Красивый мягкий отскок на входах героев (цифры, карточки, иконки, кнопки): перелёт 6–12 % и 1–2 затухающих колебания. Не на каждом мелком элементе — у второстепенных просто плавный ease-out.

## Apple-подача снова в системе
Пользователь: «у Apple хороший стиль, его нужно использовать». [[apple-style-signature]] снова рабочий стиль: чистые кадры, крупная типографика, плавные expo-кривые, расширение блоков, светлые/тёмные чистые фоны, один акцент. Он может быть основным направлением ролика (D0 в [[directions-v3]]) или «полировкой» поверх других направлений. Отличие от старого ИИ-вида — не в отказе от Apple, а в том, что убираем шаблонный мусор (HUD, REC, капс с красным словом, фальшивые окна) и даём реальные данные.

## Словарь входов (менять внутри ролика, не один на всё)
| Вход | Как в AE | Где |
|---|---|---|
| Расширение из точки | Shape Rectangle: Size [0,0] → [w,h], expo-out 10–14 к, скругление растёт вместе | плашка, карточка, фон-блок |
| Линия → блок | сначала Size [w,4] за 6–8 к (линия), потом высота за 8–10 к | подписи, цитаты, «табличка» под цифрой |
| Раскрытие из угла | Anchor в угол, Scale 0→100 с overshoot | карточки-доказательства, скрины |
| Раздвигание | соседние блоки уходят в стороны (Position, ease-in-out), в щель вырастает новый | списки, сравнения, этапы |
| Квадрат → сцена | блок растёт до размера кадра и становится фоном следующей сцены | переход между частями |
| Маска-шторка | Rectangle mask expansion/path слева→направо, текст под маской | заголовки, субтитры-акценты |
| Bounce-поп | Scale 0→100 + выражение overshoot (ниже) | цифры-герои, иконки, кнопки |
| Стаггер | Text Animator по словам/буквам, задержка 2–3 к, ease-out | заголовки, списки |
| Счётчик | Slider + Math.round, ease-out 20–40 к | любые цифры |

Выходы — зеркально, но быстрее (60–70 % длительности входа) и без bounce.

Пользователь попросил выучить этот моушен и использовать дальше: [[ref-ui-card-build]] — линия→карточка, контейнер растёт с контентом, расфокус-переход вместо реза, живая камера по станциям, побуквенная волна блюра с тиком на букву, заглушка-предвестник, рифма формы, финал-петля в точку. Брать 3–5 из них в каждый ролик с моушен-графикой.

## Библиотека 64 приёмов
Полный каталог с рецептами AE, кривыми и 8 выражениями лежит в [[animation-techniques-2026-10-19]]. В нём шесть групп: входы и выходы, вторичное движение, переходы без движения кадра, инфографика и UI, текст, Apple. В каждом ролике берём ≥5 приёмов, из них ≥1 ещё не использованный.
Топ-10 для старта:
1. №1 точка → линия → плашка;
2. №33 блок вырастает на весь экран (как открытие приложения в iOS);
3. №63 Apple Blur Rise (проявление из размытия, expo-out, 30–36 кадров);
4. №6 pop 0→108→97→100;
5. №55 побуквенный blur-стаггер;
6. №52 сборка bento-сетки;
7. №5 каскад с шагом 3 кадра;
8. №36 переход сеткой квадратов 3×5;
9. №44+45 столбцы растут вместе со счётчиком;
10. №32 многослойная шторка.

Приём №43 (сцена сжимается в карточку) применять только в варианте без сжатия кадра.

## Кривые
- Базовая: expo-out (Graph Editor: влияние входа 80–90 %, выхода 10–20 %) — «эппловская» мягкость. Без линейных ключей.
- Длительность входа: мелкое 8–12 к, средние блоки 12–18 к, герой 18–24 к (при 30 fps).
- Motion blur 180° на всём, что двигается.

## Выражение bounce (на Scale/Position после последнего ключа)
```
amp = .08; freq = 2.5; decay = 6;
n = 0; if (numKeys > 0){ n = nearestKey(time).index; if (key(n).time > time) n--; }
if (n > 0){ t = time - key(n).time;
  if (t < 0.7){ v = velocityAtTime(key(n).time - thisComp.frameDuration/10);
    value + v*amp*Math.sin(freq*t*2*Math.PI)/Math.exp(decay*t); } else value;   // через 0.7 с ровно в значение: иначе вечный микросдвиг = мыло
} else value;
```
Мягче: amp .05, decay 8. Для цифр-героев: amp .1, freq 2, decay 5.

**По разбору Tasty Edits ([[tastyedits-2026-10-19]]):** у профи bounce короткий и редкий (100→110→100 % за 3–4 к, только иконки и акцентные слова), основное — ease-out без отскока. В D0 Apple: overshoot 3–6 % с одним колебанием на плитках, текст без отскока. Каждый вход меняет 2–3 свойства сразу (scale + blur + opacity): субтитры 2–3 к, плашки 4–8 к, сцены 12–20 к. После входа слои медленно дрейфуют; на входах light leak/glow.

## Проверка
- **Резкость в покое ([[sharpness-guard]]):** после входа размытие ровно 0, масштаб ровно на ключе, glow выключен. Перед фреймами и рендером запускать `_tools/ae_sharp_preflight.jsx`.
- В контакт-листе нет ни одного элемента, который в соседнем кадре «вдруг есть» без промежуточной фазы.
- Минимум 3 разных входа из словаря в ролике; расширение блоков — в каждой сцене с плашками.
- Bounce только у героев; движение плавное на просмотре 100 % (без рывков и подтормаживаний).

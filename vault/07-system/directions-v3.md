# Направления v3

> **Обновление 2026-10-19 21:51:** пользователь вернул Apple-стиль («у Apple хороший стиль, его нужно использовать») → добавлено направление **D0 Apple** и Apple-полировка поверх любых направлений; «всё должно быть плавным» → анимация на двойках/Hold-ключах больше не база, см. [[motion-v3]].

**Почему (раньше в тот же день):** пользователь: «не отходит от айфонского… иишный дизайн всё ещё», «полностью уйти от личного (сигнатурного) стиля». Apple-стиль ([[apple-style-signature]]) больше НЕ стиль по умолчанию ни для SABRMOTION, ни для роликов без бренда. Из него остаются только отдельные приёмы (пустота перед главной фразой, match cut), и только если они нужны идее.

**Требования пользователя, общие для всех направлений:** много движения (по умолчанию плотность Мощный, см. [[rhythm-v2]]), много инфографики, графика всегда на реальных данных продукта, чёткая картинка, без музыки.

## Меню (основное направление + 1 приём из другого)
| Код | Направление | Как выглядит | Сильно для | Референсы |
|---|---|---|---|---|
| D0 | Apple (keynote / реклама) | чистый фон, крупная типографика, один акцент, плавные expo-кривые, блоки раскрываются из точки/линии, продукт крупно, bounce у героев | всё: продукт, цифры, говорящая голова | Apple keynote и реклама iPhone/Mac, [[apple-style-signature]] |
| D1 | Редакционный коллаж / стол исследователя | вырезанные экраны и фото со стикерной обводкой, скотч, маркер, полутон, бумага, вырезки въезжают и ложатся на стол (кадр стоит) | разборы «почему так», религиозные и исторические темы, «90 дней работы» | Vox, Johnny Harris, Sam Ellis, Ariel Costa, Winston Hacking |
| D2 | Ризо-плакат / кинетическая типографика | 2–3 печатные краски, набор на весь кадр, слова режутся, сдвиг приводки, сетка; инфографика как плакат | цифры продукта, анонсы фич, хук-фразы | DIA, Studio Dumbar, Nicolas Ménard, Moross, ManvsMachine |
| D3 | Рисую поверх жизни (draw-over) | живое видео/реальный телефон в руке, поверх покадровые линии на двойках, стрелки, кольца, гэги | говорящая голова, демо приложения, тёплый личный тон | Golden Wolf, BUCK, Animade, Casey Neistat |
| D4 | Тактильный предметный документ | один объект, глухой фон, руки, плёночное зерно, машинописные титры | только как акцент или бренд-ролик (пользователю мало движения) | Giant Ant, Allen Laseter, Cleo Abram |
| D5 | Редакционная сетка (Swiss) | видимая модульная сетка, контраст кеглей, асимметрия, блоки перестраиваются в ритм | PERSET, финтех, AI-новости | Experimental Jetset, Pentagram motion |
| D6 | Данные как предмет | каждый факт = физическая инфографика: полосы, стопки, штрих-код, счёты, табло; объект из данных собирается и перестраивается в кадре | продуктовые цифры, «было/стало», итоги | Bloomberg, Vox charts, Spotify Wrapped (без градиентов) |

Старые стили S01–S13 ([[styles-pro]]) остаются библиотекой приёмов. S03 Apple — только приём.

## Как выбирать
1. Не повторять основное направление двух прошлых роликов (смотреть `04-lessons/reels/` и КАТАЛОГ.md ([[video-storage]])).
2. Показать 3 направления **стиль-фреймами на материале этого сценария** (хук, середина, финал), один рекомендован. Вопрос кнопками ([[ask-before-edit]]). «make all recommended» / «делай сам» = рекомендованное без остановки.
3. Выбранное записать в бриф одной фразой «мир ролика» ([[concept-first]]).

## Приёмы анимации, которые пользователь просил (2026-10-19)
- **Риг/«кости»:** Puppet Pin (штатный AE) или риг на нуль-объектах с parent — предметы и формы гнутся и двигаются как живые, а не просто масштабируются (бриф «Аят аль-Курси»).
- Каждый ролик — заметно другой дизайн анимации, чем прошлый ([[variety]]).

## Обязательно в каждом направлении
- Инфографика в каждом бите на реальных данных (числа из кода/сайта/документов, не выдуманные). Не «огромная цифра с градиентом по центру» — цифра должна стать формой или предметом (114 полос = 6236).
- Реальный материал: скрин/запись настоящего продукта, фото, фактура.
- Кадр неподвижен, движутся элементы внутри (без ударов/зума всего кадра).
- Всё плавное ([[motion-v3]]): у каждого элемента вход и выход, разные входы из словаря (расширение из точки/линии, маска, bounce, стаггер), expo-кривые, motion blur. «На двойках» — только как редкий задуманный приём.
- Звук из мира направления (бумага/штамп/маркер/механика), не «вжух».
- Ни одного из 10 признаков ИИ-вида ([[threads-audit-2026-10-19]], [[anti-ai-qa]]).

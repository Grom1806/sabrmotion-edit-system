# After Effects: пайплайн v2

Пользователь (2026-10-19): «использовать на полную мощность After Effects и все инструменты». AE теперь основной инструмент моушена и композа. HTML/HyperFrames — запасной путь. Полные сниппеты (bezier → KeyframeEase, render queue, текстовые аниматоры, track matte): [[ae-pipeline-research]].

## Видимый таймлайн (пользователь 2026-10-19)
Ролик собирается **в открытом окне AE как у живого монтажёра**: каждый элемент — отдельный слой с понятным русским именем ("03 Коран · 05 текст «перевод»", "Озвучка", "SFX 07: ..."), in/out обрезаны прямо на слоях, маркеры сцен на компе и фразы озвучки маркерами на слое голоса, цветовые лейблы по типам (озвучка, экраны сайта, инфографика, текст, звуки, фактура). Без «запечённых» кусков и без общего прекомпа на всю сцену: камера — видимый нуль «Камера», к нему привязаны слои; прекомпы только для отдельного элемента (вырезка экрана, баннер) с видимыми слоями внутри. Проект сохраняется рядом с роликом (`reels/<ролик>/<ролик>.aep`, Reduce Project — только этот ролик) и остаётся открытым; пользователю отправляется скриншот таймлайна. Скрипт — только помощник для раскладки, а не замена монтажа.

## 5 главных правил
1. **Не строить графику с нуля скриптом.** Качество даёт мастер-проект `claude-edit\ae\MASTER_v01.aep` с заранее задизайненными LIB-прекомпами (титры, плашки, переходы, герои) и параметрами наружу (Essential Properties / Slider / Color / Checkbox Controls). Агент дублирует прекомпы и подставляет текст, цвет, тайминги. Генерация `addText/addShape` с нуля = тот же генерик, что HTML.
2. **Одна сборка = один большой JSX.** MCP-мост читает команды из файлов; десятки мелких вызовов медленные и хрупкие. Агент пишет `timeline.json` + `build.jsx` и делает один `execute-script` в одной undo-группе. Сборщик идемпотентный: удаляет и пересоздаёт `MAIN`.
3. **Рендер через `aerender` в фоне** (`-mfr ON 90`, `-RStemplate`, `-OMtemplate`, `-log`), не `renderQueue.render()` (вешает AE и мост). Перед рендером `app.project.save()`.
4. **Не скриптуется** Roto Brush, Mocha, анализ 3D Camera Tracker, Warp Stabilizer, панели Flow/Motion Bro/Overlord. Замены: маска человека — Python-маттинг на RTX 5080 (RVM / MatAnyone / SAM 2) → PNG-маска → track matte; 2D-трек — MediaPipe/OpenCV → `setValuesAtTimes`; 3D-трек камеры — Blender (bpy) → экспорт камеры в AE.
5. **Говорящую голову класть внутрь AE-компа**, когда нужен текст за человеком, трекинг, общий грейд. ProRes 4444 с альфой + ffmpeg-оверлей — только для простых оверлеев.

## Первичная настройка (один раз, на ПК)
- Какой MCP стоит: проверить. Лучшие по ресерчу: `a-y-ibrahim/after-effects-mcp` (57 инструментов: execute-script, populate-template, see-frame, contact-sheet, match-reference, render-aerender) и `kumoproductions/mcp-aftereffects` (AE 2024–2026, закрывает модальные окна). Если стоит слабее — предложить пользователю замену скриптом-установщиком (.ps1, классификатор ПК сам ставить не даёт).
- Шаблоны вывода создаются **в интерфейсе AE руками один раз** (из скрипта формат не выставить): `REELS_H264_40M`, `REELS_ProRes4444_Alpha` (Straight), `REELS_ProRes422HQ`, `PNG_SEQ`; Render Settings `Best Settings`, `Draft_Half`. Это сделает пользователь по инструкции или RC-сессия через UI.
- `lib.jsx`: json2.js (в ExtendScript нет JSON), findComp, applyBezier, addLib(event), setText, setColor, лог в файл, beginSuppressDialogs. `ping.jsx` (версия AE, открыт ли проект, есть ли модалки).
- `effects_registry.json` (matchName эффектов), `fonts_registry.json` (PostScript-имена, проверка до сборки).
- Guide-слой safe zones Reels: верх ~270 px, низ ~670 px, справа ~120 px.
- **LIB v01 (8–15 прекомпов), строится вместе с первым роликом новой системы:** субтитр-фраза (2 варианта), типографский момент, текст-за-спикером, обводка от руки, график-линия, счётчик-цифра, карточка-доказательство (скрин с тенью и маркером), переход-маска, переход-match, грейд (adjustment, без зерна), рамка телефона с реальным светом. Каждый ролик добавляет 1–2 новых LIB или вариант — так система растёт, а не повторяется.

## Порядок работы в ролике
1. `timeline.json` из таймингов слов (биты, LIB-элемент, текст ≤5 слов, позиция, SFX-метка).
2. Стиль-фреймы: `build.jsx --stills` → `saveFrameToPng` 3–5 кадров → пользователю.
3. Аниматик: `draft:true` (Draft_Half, без motion blur и тяжёлых эффектов) → контакт-лист ffmpeg → правки таймингов (текст появляется за 2–4 кадра до слова, уходит через 6–10 после).
4. Финал: `draft:false` (motion blur 180°, грейд, глоу; без зерна) → save → aerender ProRes 422 HQ → ffmpeg H.264 CRF 16, BT.709, faststart.
5. Маркеры событий экспортировать в JSON для звука ([[sound-v2]]).

## Плагины (скриптуются как обычные эффекты)
Deep Glow 2, Saber (бесплатно), Optical Flares, Trapcode, Universe, Sapphire, FilmConvert/Add Grain, GEOlayers (карты). Сложные настройки упаковывать в .ffx и применять одной строкой (`applyPreset`, комп должен быть активен). AE 26: тени в Advanced 3D, материалы Substance, параметрические меши — простые 3D-объекты можно без Blender. Что установлено — проверить на ПК и записать в [[tools-installed]].

## Blender
3D-герои (монета, карта, телефон, механизм) в EEVEE/Cycles, пассы (beauty, shadow, AO, cryptomatte) в AE; трек камеры; настоящее стекло с дисперсией. Стилл-рендеры для стиль-фреймов.

## Типичные сбои
| Симптом | Решение |
|---|---|
| MCP висит / queued | закрыта панель моста, модалка, AE ещё грузится → ping.jsx, закрыть модалку, aerender вместо render() |
| `JSON is undefined` | json2.js |
| aerender «template not found» | шаблоны создать в AE 2026 (они в prefs и пер-версионные) |
| рендерит старое | не сохранили проект |
| ореолы у графики | straight alpha для ffmpeg или `alpha=premultiplied` |
| рассинхрон звука | VFR телефона → CFR ffmpeg до импорта |
| выбеленная картинка | iPhone HLG → tonemap в SDR Rec.709 |
| графика «наклеена» | общий грейд, motion blur, тени (без зерна) |
| медленная сборка | `setValuesAtTimes`, закрыть вьювер |

Если AE не отвечает дольше разумного: сказать пользователю одной строкой и собрать на HyperFrames по тем же правилам v2, отметить в заметке ролика.

## Резкость (2026-10-19, отзыв «6236 мыльная»)
- Текст и цифры — только живые текстовые слои AE; растровые картинки не масштабировать выше 100 % (иначе апскейл); прекомпы с картинками — collapse transformations / Continuously Rasterize, качество слоя Best.
- Ризо-эффект: основная краска — обычное наложение (сплошная, резкий край), «призрак» второй краски Multiply со сдвигом 8–12 px только выглядывает. Основная краска в Multiply = светлый двойной контур = «мыло».
- Зерно поверх ≤5 %, без Gaussian/Box Blur и motion blur на статичном тексте.
- Удар камеры базово не выше 100 %: края режут крупные цифры; крупный набор держать в полях ≥60 px (обрезка краем — только задуманно).
- Скриншот для пользователя — вьювер Full, не Half/Auto (иначе «мыло» только на экране). Рендер: «Оптимальные настройки», Full.

## Против мыла (2026-10-19, ролик Ummah Link)
- Без зерна, бумаги и шума (пользователь 2026-10-19 22:37: видимое зерно = «мыло» даже под контентом). Фон — чистый цвет; допустим мягкий градиент/виньетка без шума. Фактура — только если прямо есть в брифе ([[sharpness-guard]]).
- Камера: между ударами масштаб ровно 100 % и поворот 0; без непрерывного зума; wiggle позиции округлять до целых пикселей.
- Скриншоты сайта снимать с devicePixelRatio 2–3 и не увеличивать выше 100 %.
- Рендер: aerender «Оптимальные настройки» (Best, Full) → ProRes «Высокое качество» → ffmpeg H.264 High, yuv420p, master CRF 14 `-tune animation`.
- **Light = 1080×1920**, CRF 18 (не 720p). 720p допустим только как отдельный «preview», не как версия для показа.
- Проверка перед сдачей: кадр 1:1 из AE (saveFrameToPng) vs master vs light на тексте и на скриншоте; если light мягче AE — виноват экспорт, если AE мягкий — слои/камера.

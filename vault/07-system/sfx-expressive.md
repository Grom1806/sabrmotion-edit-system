# Выразительные SFX (моушен-графика)

Для роликов без голоса (моушен-визитки, UI-истории, инфографика) отменяет норму «6–12 SFX на 30 с, субтитры без звука» из [[sound-v2]].

1. **Одна буква = один тик.** Число тиков в каждой надписи = числу видимых букв; каждый тик ровно в момент появления своей буквы (сдвиг 0, максимум 1 кадр). Пробел без звука. Запрещено: один звук на слово или строку, тики «в темп» без привязки к буквам. Тик один и тот же (как в референсе), допустим питч ±1 полутон и громкость ±2 дБ.
2. **Тики ставит скрипт, не глаз.** Сборщик AE считает время появления каждой буквы из Text Animator (линейный Offset, Ramp Up, Characters Excluding Spaces) и пишет `audio/events.json`; микшер (`tools/mix.cjs`) ставит по нему тики. Пример: `ae/build_uicard.jsx` + `reels/2026-10-20_sabrmotion-ui-card/tools/mix.cjs`.
3. **У каждого объекта свой звук:** пилюля, кнопка, иконка, каждая галочка списка, раскрытие блока (полоса и расширение отдельно), звёздочки. Рост карточки — серия нарастающих тиков.
4. **Вжух на каждом проезде камеры** (за 2–3 кадра до движения, HPF 150 Гц), схлопывание в конце + щелчок.
5. **Уровни:** буквенные тики −20…−26 дБ от акцентов, попы −8…−14, вжухи −14…−18. Мастер −14 LUFS, TP ≤ −1.
6. Тишина только в паузах 0.5–0.8 с. Без музыки ([[no-music]]), только нетональные звуки.
7. **QA:** посчитать буквы и тики в каждой надписи — числа должны совпасть; выборочно проверить кадр появления буквы против времени тика.

## Нет звуков просто так (2026-10-20 13:49)
Пользователь: «Иногда звуковые эффекты не подходят, просто так выходят — проверь и исправь».
- Каждый звук привязан к **видимому событию в том же кадре** (буква, объект, движение камеры, переход, клик курсора, тост). Звук без события — удалить. Никаких «заполняющих» ударов в начале сцен и в паузах.
- Тип звука по событию: поп — пилюля/кнопка, вжух — движение (за 1 кадр до него, не раньше), тик — буква, щелчок — клик, звук уведомления — тост.
- Звук с медленной атакой (reverse impact, длинный «ветреный» вжух) даёт пик позже события → брать короткие звуки, которые стартуют на событии.
- Декоративные слои (серые строки-заглушки, подложки иконок, разделители, точки статуса) — без своего звука: один объект = один звук.
- Куски таймлайна, вырезанные Time Remap, — их события не звучат (иначе звуки слипаются на склейке).
- Мелкий текст по словам: один тихий тик на слово (−27 дБ); крупные заголовки — по-прежнему тик на букву.
- QA: таблица всех SFX «время → кадр → событие → сдвиг» (`qa/sfx_table.md`), сдвиг > 1 кадра = ошибка; поиск окон 0.25 с с ≥ 5 громкими звуками.

См. [[sound-v2]], [[2026-10-20-ref-ui-card]].

## Документальный моушен (2026-10-21, «Путь аль-Бухари»)
- Перелёты камеры озвучиваем по **пикам скорости камеры** (> 14 px/кадр), пик звука в кадр пика скорости; сила свуша по скорости ([[docu-map-motion]]).
- Печатная машинка: тик на каждую букву при 0.042 с/символ; при 0.028 тики сливаются в треск — замедлить печать или сократить строку, но не пропускать буквы.

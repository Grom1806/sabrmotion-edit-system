# Выразительные SFX

**Пользователь 2026-10-20:** «у них SFX более выразительные. У каждой буквы даже есть свой звук. У каждого объекта свой звуковой эффект. Более выразительные эффекты должны быть и у нас. Сохрани в уроках.»

## Что измерено в референсе
101 отдельная атака за 14.6 с (~7 звуков/с, spectral flux). Печать текста = тик на каждую букву с шагом 65–75 мс; рост линии в карточку = серия нарастающих тиков; у каждой пилюли, кнопки, чек-иконки свой поп; вжух на каждом проезде камеры; финальное схлопывание. Тишина только в «вдохах» 0.5–0.8 с перед новой частью. Музыки нет: «сплошной» звук — это и есть плотные SFX.

## Правило
1. **Печать текста: ОДНА БУКВА = ОДИН ТИК** (пользователь 2026-10-20: «один тик должен быть с одной буквой»). Число тиков = числу видимых букв, каждый тик стоит ровно в кадр появления своей буквы (сдвиг 0, максимум 1 кадр). ЗАПРЕЩЕНО: один звук на целое слово, один звук на строку, тики «примерно в темп» печати без привязки к буквам. Тики расставлять скриптом по таймингу анимации каждой буквы (Text Animator range/offset → время каждой буквы → слой SFX), а не на глаз. Звук один и тот же тик-эффект (как в референсе), допустима лёгкая вариация питча ±1 полутон, чтобы не звенело. Пробел — без звука.
2. **Каждый объект — свой звук:** карточка/блок (мягкий «тум» + рост), пилюля/кнопка (поп/клик с хвостом), иконка (короткий тик), чек-пункт списка (щелчок), маска/раскрытие блока (шорох/свуш), схлопывание (втягивание + щёлк). Внутри одного ролика не повторять один файл для разных типов объектов.
3. **Камера:** каждый проезд/наезд/отъезд — свой вжух, начало за 2–4 кадра до движения, пик на максимальной скорости, панорама по направлению движения.
4. **Ритм:** паузы-«вдохи» 0.5–0.8 с перед новой частью сцены — тишина работает как акцент.
5. **Уровни:** буквенные тики −20…−26 дБ относительно акцентов, чтобы был «шелест», а не пулемёт; поп кнопок и объекты −8…−14; вжухи −14…−18 с HPF 150 Гц. Если есть голос, тики под голосом приглушать ещё на 6 дБ (сайдчейн), голос всегда разборчив.
6. По-прежнему: без музыки ([[no-music]]), без природного фона, звуки нетональные (без мелодичных «динь»).
7. **QA:** посчитать буквы и тики в каждой надписи — числа должны совпасть; покадрово проверить, что тик стоит в кадре появления своей буквы (сдвиг ≤1 кадра), и что у каждого объекта есть свой звук в кадре его движения.

Применяется ко всем моушен-графике и текстовым анимациям; у говорящей головы субтитры тоже могут тикать, но тише и под сайдчейном голоса.

## Нет звуков «просто так» (пользователь 2026-10-20, PERSET 05)
«Иногда какие-то звуковые эффекты не подходят, просто так выходят». Правило: **каждый SFX привязан к видимому событию в том же кадре** (буква, объект, движение камеры, переход). Звук без события — удалить. Характер звука соответствует событию: поп — для появления пилюли/кнопки, вжух — для движения, тик — для буквы, щелчок — для клика курсора, уведомление — для тоста. Не ставить «заполняющие» звуки в паузах.
QA: таблица всех SFX «время → событие на экране → кадр события»; строка без события или со сдвигом > 1 кадра = ошибка. Прослушать ролик целиком и отметить звуки, которые звучат неуместно.

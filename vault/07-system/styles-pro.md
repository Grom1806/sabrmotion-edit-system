# Стили S01–S13 (библиотека приёмов)

> **С 2026-10-19 основное меню — [[directions-v3]] (D1–D6).** S01–S13 — приёмы внутри направления. S03 Apple — только приём, не стиль ролика.

Ролик = **1 основной стиль + максимум 1–2 приёма из других**. Не повторять основной стиль прошлого ролика. Подробности, ссылки и примеры: [[pro-styles-2026]]. Старое меню типов Т01–Т15 ([[edit-types-catalog]]) остаётся библиотекой вставок, но выбор начинается отсюда.

## Связки по продуктам (рекомендации)
- **AI/tech говорящая голова:** S02 база + S01 доказательства + S10 пометки + 1 момент S11.
- **PERSET:** S05 + S13 + S03; имидж — S09. Кривые expo-out без overshoot, 12–18 к.
- **Исламское приложение:** (Instagram Ummah Link → D2/D1/D3 из [[directions-v3]], много инфографики) S12 + S04 (экраны) + S07 (орнаментальная фактура). Мягкий sine in-out 18–24 к, без пружин; арабский шрифт Amiri / Noto Naskh; живые звуки (страницы, шаги). Без изображений живых существ в фактурах, если это важно аудитории.
- **SABRMOTION (свой бренд):** с 2026-10-19 без сигнатурного Apple-стиля; направление из [[directions-v3]], приёмы S05 / S06 / S09 / S10.

## Как говорящую голову делают «дорогой» (Pinterest, before/after pro-монтажёров)
Главная разница «до/после» — **свет и грейд, а не графика**: фон темнее лица на 1–2 стопа и мягче, тёплые практические источники в глубине, контровой, насыщенная кожа. Субтитры у груди, смешение гарнитур в одной фразе (курсивная антиква + жирный гротеск), разный кегль слов. См. [[talking-head-look]].

## Чем убить любой стиль
Пресеты без доработки, один и тот же вход у всех элементов, стоковые ассеты как есть, стиль «на глаз» без сетки и кривых, эффект в каждом предложении.

# Фон под голосом: тихий нашид

**Главное правило (пользователь, 2026-10-19 23:23):** **никогда не ставить звуки природы на фон** (вода, река, дождь, ветер, птицы, сверчки, лягушки, огонь, пещера и т. п.). Атмосферы-подложки тоже отменены. На фоне либо **тихий спокойный нашид**, либо ничего.

## Нашид на фоне
- Только голосовой нашид, **без музыкальных инструментов** ([[no-music]]). Допустим дафф (бубен) или его нет — уточнить у пользователя. Без синтетических подкладок под видом «вокала».
- Громкость на 18–24 дБ ниже голоса, сайдчейн под голос −4…−6 дБ, HPF 120 Гц, LPF ~8 кГц, чтобы не мешать словам.
- Вход и выход fade 1–2 с. Под чтением Корана нашида нет, там тишина.
- Источник: `claude-edit\assets\nasheed\` (каталог `INDEX.md`: название, исполнитель, есть ли дафф, длительность, лицензия или «прислал пользователь»). Если подходящего нашида нет — фон пустой (голос + SFX), спросить пользователя.

## Звуки, которые присылает пользователь
- Каждый присланный файл **сохранять сразу**: `claude-edit\assets\from-user\YYYY-MM-DD\` (оригинал без изменений) и строка в `assets\from-user\INDEX.md` (дата, имя, что это, для чего).
- Нашиды из присланного копировать в `assets\nasheed\`, SFX — в нужную папку `assets\sfx\` с пометкой «от пользователя».
- Из облачного треда: файл из `/mnt/project-files/uploads/hearth/` переносить на ПК при ближайшем доступе к файлам.

## Что сделано с природными звуками
Все природные петли из `assets\sfx\ambience\` перенесены в `claude-edit\_to_delete\ambience_nature_2026-10-19\` (по правилу [[no-delete-without-yes]] — окончательно удалит пользователь или по его «да» на список). Комнатные room tone тоже не использовать как подложку ([[sound-v2]]).

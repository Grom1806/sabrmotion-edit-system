# Защита от «мыла»

2026-10-19 22:37: пользователь показал зерно на чёрном фоне «Твоей минуты» — видимое зерно/шум = мыло даже под контентом; по умолчанию запрещено, фон чистый.

**Правило:** ни один стиль-фрейм, превью или финал не показываем пользователю, пока оба отчёта не зелёные. Отчёты прикладываем к сдаче одной строкой: «preflight: 0 FAIL, sharpcheck: ok».

## Шлагбаум 1 — до стиль-фреймов и до рендера
Скрипт `vault/_tools/ae_sharp_preflight.jsx`, запуск через `ae\run.ps1`. Отчёт: `<папка проекта>\logs\sharp_preflight.txt`.
Сам исправляет: разрешение превью → Full; качество слоёв → Best; сэмплинг → бикубика.
Ловит (FAIL): растровый слой увеличен больше 100 %; размытие на неподвижном слое (вход не закончился ровно на 0); в покое масштаб растра или прекомпа не ровный (bounce не дотягивает); любой слой зерна/шума/фактуры с opacity > 0 (фон должен быть чистым).
Предупреждает (WARN): Glow на тексте в покое; shutter больше 180°; позиция растра в покое не на целом пикселе.

## Шлагбаум 2 — после рендера
`python sharpcheck.py --frames <PNG из AE> --video master.mp4 --video light.mp4`
- Кадр видео меньше 90 % резкости кадра AE → виноват экспорт: CRF, масштаб, 720p.
- Стиль-фрейм меньше 60 % медианы соседей → виноваты слои.

## Частые причины (наш опыт)
| Причина | Где было | Как не допустить |
|---|---|---|
| Фактура или зерно (даже под контентом) | Ummah Link ризо, «Твоя минута» | без зерна, фон чистый |
| Глобальная камера 100–103 % | Ummah Link ризо | запрет камеры ОТМЕНЁН 2026-10-20, [[camera-allowed]]; на станциях масштаб ровно 100 % или чётный, motion blur |
| Light в 720p | Ummah Link ризо | light 1080×1920 CRF 18 |
| Апскейл фото | «День 90» v2 | фото ≥ размера в кадре |
| Вечное затухание bounce, blur-in не до 0, Glow в покое | «Твоя минута» | выражение из [[motion-v3]] со снапом на 0.7 с; ключ blur = 0; glow только на входе |

См. [[ae-pipeline]] («Против мыла»), [[qa-frame-by-frame]], [[anti-ai-qa]].

## Блюр-появление мелкого текста (2026-10-20 13:43)
Пользователь прислал кадр PERSET 05 с подписями карточек в блюре: «text is in blur».
- Побуквенный blur-in — **только крупные заголовки** (кегль ≥ 60 px в 1080p): blur ≤ 8 px, буква ≤ 0.2 с, блюр отдельным аниматором уходит к моменту, когда буква непрозрачна на 50 %.
- Весь мелкий текст (подписи карточек, UI, второстепенные строки) — **без блюра**: по словам, opacity + y 6–8 px за 0.15–0.25 с, резкий с первого видимого кадра.
- Подпись карточки стартует не позже 0.3 с после заголовка; карточка не уходит и камера не уезжает, пока подпись не проявилась полностью.
- Блюр-эффект на текстовом слое (Gaussian Blur) — только на входе, к покою ровно 0. Исключение — расфокус-переход всей сцены.
- QA: скрипт сборщика пишет окна проявления каждой надписи и проверяет, что ни одно держание/уход не начинается во время проявления (`qa/reveal_conflicts.txt` = «нет»).

## Если на ПК нет Python
Замена `sharpcheck.py` одним ffmpeg (проверено: размытие 2 px роняет метрику до 0.43 от резкого кадра). Метрика — средний квадрат градиента Собеля, берётся число YAVG:
```
ffmpeg -v error -i кадр.png -vf "format=gray,sobel,lutyuv=y='val*val/255',signalstats,metadata=print:key=lavfi.signalstats.YAVG:file=-" -f null -
```
1. Стиль-фреймы: YAVG каждого кадра; меньше 60 % медианы → FAIL (кадр мягче соседей, проверить слои).
2. Рендер: для каждого фрейма кадр видео в то же время (`-ss <сек> -i master.mp4 -frames:v 1`, тот же фильтр); отношение видео/AE меньше 0.9 → FAIL экспорта.

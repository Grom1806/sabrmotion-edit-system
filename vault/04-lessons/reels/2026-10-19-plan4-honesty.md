# Рилс plan-4 — «Одна фраза, и ИИ перестаёт скрывать ошибки»

**Источник:** исходников нет; голос — клон пользователя (eleven_v4, stab .45, 3 дубля все дословные по whisper, взят 1-й, темп ×1.05). Факт сверен с аннотацией arXiv:2609.36139. Проект `claude-edit\plan4-honesty\` (пайплайн be-honest: tts → words → gaps → inject → dump → mix → verify_solo).
**Уровень / бренд / приём бренда:** Мощный · SABRMOTION в палитре Neon Noir B12 (циан = честность, маджента = скрытая ошибка, оранж = предупреждение) · Spotify Wrapped цифра-герой. Из «не пробовали»: whip-pan с blur, light leak, scramble/decode, слот-прокрутка.
**Что сработало:**
- Настоящий тест через `claude -p` (чистый контекст: `CLAUDE_CODE_DISABLE_CLAUDE_MDS=1`, `--setting-sources project`, `--tools ""`, `--system-prompt`; `--bare` не работает без API-ключа — «Not logged in»). Разницы не было (5/5 = 5/5) → текст бита честный, «фраза — бесплатная страховка». Чат-окна показывают реальные ответы.
- Хук: настоящий код пользователя, строка с ошибкой пульсирует маджентой ПОД стеклянным пузырём «Всё отлично ✓» (backdrop-filter) — метафора читается без звука.
- Мини-счётчик в углу → морф в бумажный лист (from: x/y/scaleX/scaleY/цвет пилюли) — бесшовный переход без отдельного эффекта.
- Номера 1-2-3 и пунктирные строки появляются на слове «три», потом текст печатается по словам — нет пустого листа.
**Что исправили (аудит 10 к/с):** пустые кадры после whip (растр и плашка источника сразу), тусклая сетка, мелкий текст в строке ввода и на листе, 0.5 с пустоты перед «ВОЛШЕБСТВО» (окна уходят на −0.38 с от слова), штамп поверх подзаголовка, вспышка субтитра «и» 0.1 с перед HIDE, 4 тональных SFX → клики/шум, hero-звук по onset.
**Баги пайплайна:** `s.split(a).join(b)`-замена «"sub1", "sub2", » задела и массив SUBK — заменять уникальными кусками. hyperframes `data-layout-allow-overlap` нужно ставить на самые вложенные текстовые span, не только на контейнер. `rm` с относительным glob после `cd` блокирует проверка безопасности — не чистить qa, просто перезаписывать.
**Цифры:** 40.7 с, 1080×1920 30 fps; −14.0 LUFS, TP −2.6; мастер 17.3 Мбит/с 88 МБ, light 720p 3.6 МБ; 76 событий (1.87/с), 58 SFX (1.43/с), 58/58 в ±50 мс; check 0 ошибок; лицо 0 %.
**Перенести в плейбуки:** «свой тест вместо пересказа» для новостных рилсов (честно, даже если результат не совпал); морф сквозного элемента в главную карточку; Neon Noir как альтернатива красному/зелёному для тем про ИИ.

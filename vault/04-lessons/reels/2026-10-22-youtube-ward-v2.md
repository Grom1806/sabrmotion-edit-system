# Уорд Каннингем v2 · YouTube 16:9 (2026-10-21/22)

**Итог:** 8:57 (голос 8:36 + 20 с конечной заставки с титрами), 1920×1080 23.976, 141 клип радио-ката, 261 слой в главной композиции. Доли до титров A 51 % / B 27 % / C 22 %. 40 SFX (только видимые события), −14.1 LUFS / TP −1.1. Выдача: `VIDEOS\tests\2026-10-21_youtube-ward-cunningham-v2\`.

**v1 → v2 одной строкой:** v1 — 419 слоёв нарисованных карточек поверх лица и 1526 SFX в порядке интервью; v2 — сюжет с хуком и петлями, лицо держит эмоцию, доказательства — настоящий архив, графика только отдельными сценами на пиках.

## Пайплайн v2 (повторять для длинных интервью)
`v2/cut_v2.json` (радио-кат из handoff) → `tools/faces_v2.py` (центр лица по клипам; 9 клипов без лица = вставки самого исходника) → `tools/plan_v2.cjs` (регистры по paper edit, крупности, тишины, субтитры из SRT радио-ката, SFX-таблица, главы) → `ae/build_ward_v2.jsx` (проект `v2\ward_v2.aep`, ~30 с) → `ae/frames_ward_v2.jsx` (QA-кадры) → `ae/run_preflight_ward_v2.jsx` → `ae/render_ward_v2_rq.jsx` (очередь AE) → `tools/mix_v2.cjs` (голос по местам + тон комнаты в паузах + SFX).

## Взятые приёмы (чтобы следующий ролик не повторял)
- Хук: самая сильная фраза («ужасный баг»), имя одним элементом ≤4 с, затем RecentChanges 1996 (правки незнакомцев по IP).
- Название — отдельная C-сцена после тишины 1 с с одним глухим ударом.
- C-формы, каждая один раз: ссылка → карточка из точки (пик 1), линия времени 1987→1994, сетка правок «≈80 % без подписи», доска объявлений «дописать, но не исправить», вики-правка на месте (закрытие П1), гант «ты, и ты, и ты» + штамп, рост из центра, 348 точек-разделов (sitematrix API).
- B: Wayback-страницы в окне браузера (без апскейла: 2×-снимок Chrome, масштаб 78 %), маркер по реальной строке; Commons-фото с годом и подписью автора; видео автобуса; финал — c2 1996 рядом со статьёй «Вики» сегодня.
- Петли: П2 «Почему WikiWikiWeb?» над архивом → закрыта настоящей страницей 1996, где Уорд сам пишет про «wiki wiki bus».
- Пик 2 «Получилось» — наезд 100→108 % + стоп-кадр в тишине.
- Звук: родной тон комнаты исходника (140.0–141.2 с, петля с кроссфейдом) в паузах и тишинах; музыки и атмосфер нет.

## Ошибки и решения
1. **Привязка к нулю (parent), когда у нуля масштаб 0** (окно «раскрывается из точки»), даёт ребёнку бесконечную локальную позицию — текст пропал. Решение: сначала `parent`, потом анимация масштаба нуля. При масштабе 96 % дети растягиваются на 4 % (разделители вылезли за окно). Позицию ребёнка, созданного в (0,0), задавать **после** привязки.
2. **`saveFrameToPng` асинхронный** — скрипт завершается раньше, чем появятся файлы (0 из 44). Решение: после каждого кадра ждать файл (`$.sleep` до 20 с) → 44 из 44 за 9 с.
3. **MCP `ae_render_frame` не видит AE, запущенный через `-r`**, и при `NO_INSTANCE` закрыл экземпляр. Для QA — свой jsx через `run.ps1`.
4. **Общий AE на ПК**: другая сессия перезапускала AE ради шрифта. Теперь замок `ae\ae_lock.ps1` (acquire/status/release) — брать перед любой работой в AE, снимать сразу после рендера.
5. Пути в jsx и json — прямыми слэшами (`C:/…`): обратные теряются при записи через bash heredoc/printf и в `eval`-парсере LIB.
6. В `v2clips.json` первый клип начинался с середины фразы (284.58); SRT/mp3 радио-ката — с 282.44. Сверять длительность первого клипа с SRT.
7. Субтитры на светлом архиве не читаются даже с ореолом → плотная тёмная плашка 190 px (82 %) в B-сцене.
8. Preflight: 44 FAIL = разрешённые крупности 100.5–110 % на 1080p и ложные «78.125 % не ровно» на даунскейле 2×-скриншотов.

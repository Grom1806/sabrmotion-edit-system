# br.heal — «Заказ за пару часов»

- Бриф с пульта br.heal (https://claude.ai/artifact/WuJPQ9aK5BtTSWsEyP1X78): покупателю, хук-цифра, с нуля, моушн + UI + инфографика, D0 + UI-карточка, ультра, кинетика, мужской голос, цвета логотипа.
- Движок: HyperFrames-кит, собран целиком в облаке (рендер 22 с ≈ 30 с). SFX подтянуты с ПК через stage (32 файла), mp3 → wav для mix.js.
- Сцены: «2 часа» с отскоком → полёт камеры вдоль двух полок (параллакс 0.45, банка у центра подпрыгивает каждые 0.55 с) → карточка «Сертифицированные» → 10 банок дугой падают в коробку, счётчик 0→50+ → сплит 3 полосы с галочками → круг раскрывает сцену, карточка растёт за контентом (5+ лет → маршрут Турция—СНГ) → шторка в тёмно-зелёный финал, логотип, лист влетает, кнопка WhatsApp.

## Взятые приёмы
полёт по полкам + параллакс, каскад предметов в коробку, счётчик-герой, сплит-экран, «блок → сцена» кругом (clip-path, без scale), контейнер растёт за контентом, линия → карточка, побуквенно только крупное.

## Уроки
- Грабли QA: sharpcheck берёт кадр t1+0.25 после надписи; если в этот момент уже едет камера с блюром, ложный FAIL «мягче соседей». Заканчивать надписи ≥0.3 с до старта камеры.
- Галочка/кольцо через strokeDashoffset оставляет точку (round cap) до начала рисования — прятать opacity 0 до старта.
- Падающие предметы ставить ПОД счётчиком по z-order, иначе закрывают цифру.
- Резервный ключ ElevenLabs = free: библиотечные голоса (русские) недоступны через API (402), только premade; free — без коммерческой лицензии. ПК (Cowork VM) не видит api.elevenlabs.io, облако видит.

## v2 «Путь одной коробки» (2026-10-22, после фидбэка)
Фидбэк на v1 (22 с): мало экшена, коротко, другой голос, другой сюжет. Ошибка: «до 45 с» в пульте я прочитал как максимум, а пользователь имел в виду 40–50 с. **Длину из пульта трактовать как целевую, не как верхнюю границу; при сомнении — середина диапазона.**
v2: 42 с, голос Brian (premade), 8 сцен, 185 SFX: 3D-коробка CSS (6 граней) с падением и вращением → whip-переход → конвейер с прессом-штампом и шестерёнками → полёт по полкам + бренд-слэмы по словам → сетка 6×7 сворачивается в телефон → чат WhatsApp с печатью по буквам и таймером-кольцом → печать чека 52 строки + счётчик 50+ → лупа/коробка/скотч/штамп → мини-коробка едет по маршруту (getPointAtLength) + календарь листает недели → 5 лет → CTA с курсором и нажатием.
Гочи: FT с from opacity:1 рендерит from-кадр сразу (кольцо-ripple висело точкой 2 с) — для «вспышек» ставить opacity через tl.set в момент события. sharpcheck даёт ложный FAIL на кадрах с плоской заливкой без деталей (голая коробка) — лечится деталью (маркировка, скотч, стрелки на гранях), а не размытием-нормой.

# Ролик LocalAI Studio — «Я удалил HeyGen, OpusClip и ElevenLabs»

**Источник:** исходников нет совсем. Озвучка ElevenLabs голосом пользователя (eleven_v4, stab .45, 3 дубля, whisper сверил — все дословные, взят 2-й), темп ×1.03, «вдохи» 0.15–1.15 с между битами (`tools/gaps.js`). Сценарий v2 от координатора (v1 «ноль рублей» сделан и заменён).
**Уровень / бренд / приём бренда:** Мощный · SABRMOTION Apple-сигнатура · Apple macro-to-wide.
**Что сработало:**
- Настоящий интерфейс: клон репо → `npm i && vite` → headless Chrome скриншоты по hash-роутам (`#video/generate`, `#avatar/create`, `#video/clips`) ×2 DPR; плашку «СЕРВЕР НЕ ДОСТУПЕН» и плейсхолдеры прячет `<style>` в локальной копии index.html; кроп панелей ffmpeg → парящие 3D-карточки, поверх печать промпта и нажатие кнопки.
- Blender: видеокарта из примитивов (кожух, 2 вентилятора с крутящимися лопастями, красная световая линия, PCIe-гребёнка), карта повёрнута вертикально под 9:16. Кадр 1 = втулка с красным кольцом ⌀540 px в центре → match cut с кольцом, которое обводит зелёный «0» хука. 140 кадров Eevee ≈ 10 мин.
- After Effects (MCP, eval.run выключен — только атомарные ops): кольцо установки на trim paths с «рваным» прогрессом 0→22→25→68→71→100, перекраска в зелёный, галочка, вспышка 12 лучей (repeater). HTML-счётчик % повторяет те же ключи.
- Шум → кадр: SVG feTurbulence в data-URI внутри карточки + дрожание позиции каждые 0.05 с.
**Что исправили (QA):**
1. Регэксп `/^видео/` ловил «видеокарта» → анимации стартовали на 2 с раньше. Слова матчить с `$` (`/^видео$/`).
2. `inject.js` выкидывал `e` (конец слова) → все события «на конец слова» пропали молча (NaN). Теперь пишет `{w,t,e,line}`.
3. `String.replace` в node-скриптах правки: `$$` в строке замены превращается в `$` → `[...$("…")]` сломал таймлайн. Для правок с `$$` использовать `split().join()`.
4. `mix-blend-mode: screen` на `<video>` в HyperFrames не работает (виден чёрный квадрат). Решение: поднять чёрный в самом видео до цвета фона (`lutrgb val*242/255+13`) + радиальная маска на контейнере.
5. Остатки v1 (красные зачёркивания) висели с кадра 0; счётчик заканчивался «0 000» → первые три барабана гаснут перед «0».
6. Слово-экран «ЛОКАЛ» 230 px вылезало за 1080 → 186 px. Lint: left/top у карточек рилсов → x/y + scaleX/scaleY.
**Цифры:** 27.55 с, 1080×1920 30 fps, 18 Мбит/с; −13.95 LUFS, TP −1.5; 0 % лица; 65 событий (2.36/с); 60 SFX (2.17/с) после фильтра, verify_solo: все в ±50 мс (макс 40). 8 новых SFX ElevenLabs: маркер, раскрутка вентиляторов, power-down, ножницы, двойной клик, механическая клавиатура, слот, блик. 6 переходов разных типов: match cut кольцо→вентилятор, zoom-through, whip-pan, 3D-флип, засасывание в точку, тёмная пауза.
**Проход скиллом onetake (по просьбе пользователя «use new skills»):** на ПК нет системного Python → отдельный `uv venv` (numpy, scipy, pillow, opencv, matplotlib) только для `verify_promo.py`. Первый прогон FAIL: rest 18 % неподвижных кадров (норма ≥ 25 %), пик аудио −1.4 dBFS (норма ≤ −3 после AAC), тихих кадров 13 % (норма ≥ 15 %). Исправили: (1) три стыка «смена сцены» → carry: кадр готового видео перелетает и становится карточкой фото; карточка фото сплющивается в плёнку; галочка установки летит вверх и сжимается в точку REC (вместо тёмной паузы); (2) убрали push-in и медленные дрейфы в сценах UI/репо/CTA и на финальном лого, зерно статично → rest 26.6 %; (3) мастер TP −3.7, фон вентиляторов обрезан до 2.4 с, финальный блик короче, хвост +0.3 с → quiet 15 %. Итог VERDICT: PASS. Конфликт: Apple-сигнатура «кадр всегда дышит» против onetake «нужны неподвижные паузы» — дыхание оставили в хуке/видеокарте/C1, в остальном покой.
**Перенести в плейбуки:** приём «реальный UI из репо через vite+headless скрин» — для любых роликов про софт; match cut «круг цифры → круг 3D-объекта»; AE trim-ring как готовый блок прогресса.

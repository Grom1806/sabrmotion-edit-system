# UI-карточка Sabrmotion (повтор референса)

Файлы: `VIDEOS\sabrmotion\2026-10-20_ui-card\` (master CRF 14, light CRF 18, extra\ — aep, сборщик, события, микс, листы QA). Референс и разбор: `reels\2026-10-20_ref-ui-card\`.

## Урок 1 — как собрано
- Одна комп 1080×1920 30 fps 14.6 с, 40 слоёв с русскими именами, 12 маркеров. Вся карточка в «координатах карточки» (общий план референса ×5 = 2520×2535), слои привязаны к видимому нулю «Камера»: Anchor = точка фокуса на карточке, Scale = зум (30 % общий план … 90 % крупный). Motion blur 180°.
- Размеры шрифта подобраны по ширине строк референса (`fit()` меряет строку референса через sourceRectAtTime). Шрифт Arial Bold (Inter не установлен).
- Побуквенная волна: Text Animator (Opacity 0, Blur, Scale 115, Y), селектор Ramp Up, Characters Excluding Spaces, линейный Offset; буква 0.25 с, шаг 25–70 мс. В покое blur ровно 0.
- Тени и блюр-эффекты на векторных слоях считаются после трансформации → расстояние/мягкость тени умножать на масштаб камеры выражением.
- Панель и блик внутри карточки — через новую Track Matte на скрытый слой-маску (тень карточки в матте не попадает).

## Урок 2 — звук: буква = тик
- Сборщик пишет `audio/events.json`: время появления каждой буквы (из Offset окна), каждый поп, фазы блока. `tools/mix.cjs` ставит по ним 212 тиков (один сэмпл, ±1 полутон, ±2 дБ) + 42 объектных/камерных звука, двухпроходный loudnorm −14 LUFS. QA: букв = тиков во всех 14 надписях, тик в первом кадре проявления буквы.

## Урок 3 — техника референса (разбор координатора)
Рост карточки ease-in-out без перелёта; расфокус-переходы blur ~25 px вместо реза (1.8–2.4 и 12.6–13.1 с); камера на станциях дрейфует, проезды = диагональ + зум; иконки-предвестники появляются раньше текста; тень кнопки с задержкой 3 кадра. Полный разбор: [[ref-ui-card-build]] (облачная копия, на ПК ещё не перенесён).

## Грабли
| Симптом | Причина | Решение |
|---|---|---|
| Всё в 3.3 раза крупнее | `layer.parent = cam` компенсирует масштаб нуля (30 %) | `setParentWithJump(cam)` |
| QA-кадры «не обновились» | `saveFrameToPng` асинхронный, часть файлов не перезаписалась | кадры QA через MCP `ae_render_frame` |
| ffmpeg: Permission denied на mix.wav | AE держит импортированный wav | версии `mix_vNN.wav` + `mix_latest.txt` |
| Скрипт молча не запустился | `//`-комментарий после кода съел `})();` в той же строке | `node --check` копии без `#include` перед запуском |
| preflight FAIL на расфокусе | слой «в покое» по transform, хотя blur анимируется | preflight: анимирующийся blur — не покой (правка 2026-10-20) |
| shot_ae.ps1 снял браузер | SetForegroundWindow не сработал | скрин таймлайна не делать вслепую; проверять, что в кадре AE |

# Тест 2 (akimbosd, 2026-10-20)

**Что было:** сырьё с YouTube (только для учёбы, не публикуем), 2560×1440, два ракурса; 60 с 9:16, стиль C: 9 диорам Blender, 4 счётчика, пословные субтитры, 98 SFX. Проект ПК `reels\2026-10-20_practice-akimbosd\`.

## Замечания → причина → правило

| # | Пользователь сказал | Причина | Правило |
|---|---|---|---|
| 1 | «Он не в центре кадра, сбоку» | Кадр сдвигали вбок на 60–150 px «для разнообразия» и неверно оценили, где лицо в исходнике | 9:16 из горизонтали: лицо по центру по трекингу (x≈540, глаза ~40 % сверху), сглаживание 0.5–0.8 с + мёртвая зона ±4 %, свой сдвиг на каждый ракурс; проверить каждый план на контакт-листе |
| 2 | «Плохая цветокоррекция, тёмное видео» | Исходник сам тёмный (лицо ~38 %), виньетка и тёмные поля добавили мрака | Грейд никогда не темнит исходник: сверять яркость лица с raw (цель ~60–70 IRE), без виньетки и зерна, чёрный не давить; кадры «raw / до / после» перед сдачей |
| 3 | «Шрифты некрасивые» | Шрифты не выбирались осознанно, у счётчика мутное свечение | Перед монтажом 2–3 варианта шрифтовой пары на одних кадрах; выбрано A: Segoe UI Variable (субтитры) + Georgia Italic (слова-герои); свечение только на крупном слове и чёткое |
| 4 | «Лицо на миллисекунду показывается и выходит — некачественно» | Щели 0.03–0.12 с между вставками (лицо мигало 5 раз), вставка 0.55 с, лицо в начале 1.06 с | План лица ≥1.5 с (лучше 2–4 с, хук ≥2.5 с); лицо↔вставка не чаще ~1.5 с; плотность внутри кадра с лицом (субтитры, счётчики, плашки, наезды), серии вставок блоками; проверять таймлайн на щели |
| 5 | «Чистый блок без текста, похож на стекло» | Карточка на слове «transparent» без содержимого | Никаких пустых плашек/стекла без содержимого; перед сдачей список всех панелей с таймкодами |
| 6 | «В следующий раз не только крупных планов» | Почти все планы одной крупности | Чередовать крупности: общий / средний / крупный, смена на смене мысли; при низком разрешении — широкие раскладки (карточка спикера на фоне, сплит), не апскейл |

## Как применять
- Эти 6 пунктов добавить в QA перед сдачей вместе с [[anti-ai-qa]] и [[talking-head-anti-ai]].
- Норма «≥30 смен на 60 с» из [[ref-blog-shot-by-shot-2026-10-20]] выполняется событиями ВНУТРИ кадра с лицом, а не частой нарезкой ухода с лица.
- Итоговая версия v5 (лицо 2.3–4.8 с на план, −14 LUFS). Отзыв на v5 ещё не получен.

## Поиск сырья для практики (тест 3, 2026-10-20)
YouTube-ролики с названием «raw / talking head footage» дважды оказались не сырьём: шоурил студии из 8 людей с музыкой (Outlive Creative) и готовый монтаж с водяным знаком и музыкой (MrDenoise). Правило: проверять кандидата по 3 кадрам и по звуку (паузы речи опускаются ниже −45 дБ?) до того, как обещать монтаж; лучший источник — своя съёмка пользователя (4K, чистый звук), затем 4K-клипы стоков с открытой лицензией (Pexels). Внешние ссылки на архивы из комментариев не открывать.

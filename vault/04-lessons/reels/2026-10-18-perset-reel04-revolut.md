# PERSET reel 04 — Revolut-промо (без голоса)

**Источник:** без съёмки и голоса; 100 % графика, 1080x1920 30 fps, 17.9 с. Проект `perset\reel04_revolut\`, выход `out\perset_reel04.mp4` + `out\perset_reel04_preview720.mp4` + `out\contact.png`. Референс `ref\ref_revolut.mp4` (16:9, 11.5 с).
**Уровень / бренд / приём бренда:** Мощный · PERSET, но палитра расширена по просьбе пользователя: чисто белые кадры, второй акцент — огненный градиент #FFD98A→#ECB03E→#E2622E, свечение текста на «БЕЗ ГРАНИЦ», «83», «КОМИССИЙ».

**Сцены:** белая сетка + карточка Telegram-бота, курсор → «ОТКРЫТЬ» → зум сквозь карточку в тёмное → 3D-телефоны (экраны бота) в золотой колонне света → полотно выгибается в ленту, «ОБМЕН ВАЛЮТ / БЕЗ ГРАНИЦ» → лента раскрывается в глобус с монетами, счётчик 0→83 «СТРАНЫ» → iris в кремовый кадр: ломаная курса + тикающие цифры, замок, линия становится ровной («пример, не текущий курс») → кинетика «БЕЗ / СКРЫТЫХ / КОМИССИЙ» разными весами → толчок вверх в тёмный чат «ОТВЕТ ЗА НЕСКОЛЬКО МИНУТ» → сжатие в круг → логотип рисуется, perset.de, «официальный сайт только perset.de», t.me/PERSET_bot.

**Что сработало:**
- Blender CLI (`blender/scene.py phones|globe`), RGBA PNG + фон со свечением собирается в ffmpeg (`tools/vid.sh`, geq-гауссианы) → mp4; тот же PNG стоит CSS-фоном полотна, видео кончается без шва.
- Глобус: точки суши из полигонов стран (`one-message-world/assets/geography.js` → `tools/landdots.js`, точки Фибоначчи + point-in-polygon, 3222 точки) → меш из вершин + `instance_type='VERTS'` с маленькой икосферой. Выглядит как настоящая карта.
- Монеты: COPY_LOCATION к пустышке на орбите + TRACK_TO камеры (ось Z) — символ всегда читается; наклон орбиты анимирован 78°→16° (круг → эллипс, как в референсе). Шрифт символов Segoe UI Bold (есть ₹ ₺ ₣).
- Экраны телефонов: HTML → скриншот headless Chrome → скруглённая альфа через ffmpeg geq (`hypot` от углов); chrome-headless-shell игнорирует прозрачный фон.
- Изгиб полотна: `clip-path: path()` с двумя квадратичными кривыми, параметры t/b/w — прокси GSAP с onUpdate (детерминированно при покадровом рендере).
- Без голоса громкость: loudnorm на редких SFX уходит в dynamic и даёт −15.5; надёжнее подобрать gain + alimiter 0.6 (16.8 дБ → −14.1 LUFS, TP −3.1 в mp4).

**Что исправили на QA:** зум в карточку оставлял белые полосы (ориджин не по центру карточки) + серые кадры при наложении полотна → ориджин 720/820, фон сцены А уходит в navy, подпись и кресты гаснут; «ОБМЕН ВАЛЮТ» уходил с хвостом букв под «БЕЗ ГРАНИЦ» → stagger .005; «СКРЫТЫХ» и «КОМИССИЙ» налезали → разнесли строки и время входа; letterSpacing-анимации → scaleX (lint); у видео нужны id (иначе кадр замерзает); финал удлинён до 17.9 с.
**Цифры:** 17.9 с, −14.1 LUFS, TP −3.1, 48 событий (2.7/с), 50 SFX (2.8/с), 4 новых SFX ElevenLabs (bend, coin_orbit, mouse_click, glint); переходов 7 типов (зум сквозь UI, изгиб, раскрытие ленты, iris, толчок вверх, сжатие в круг, рез). Контраст-чек ругается только на золотое SET в лого (брендовое исключение).
**Звон на цифрах:** вместо тонального «динь» — металлический щелчок монеты + sub (правило «без мелодичных звуков»).
**Перенести в плейбуки:** изгиб полотна clip-path; глобус из точек суши; монеты-билборды на орбите; зум сквозь UI-карточку в 3D-сцену.

## v2 — правки пользователя (2026-10-18)
- **Телефоны пересекались корпусами** → x ±0.53 + разнос по глубине (y ∓0.14), наклон Z 3°; проверять зазор на кадрах 1/20/40/60/84. Глянцевый экран ловил блики HDRI → roughness .3, specular .12.
- **Экраны = реальное приложение PERSET** (тёмная тема по скрину: фон #111216, карточки #191A20/#2A2B30, поля #21222A, жёлтая #EAB343/#F2C35A, USDT #26A17B), не придуманный светлый бот.
- **Первая сцена как в App Store**: белая карточка, иконка, синяя капсула #007AFF «Загрузить» → кольцо загрузки → «Открыть» → иконка раскрывается в приложение (clip-path inset от рамки иконки до полного кадра). Рейтинги/загрузки не выдумывать, без логотипа Apple.
- **«Мало экшена и SFX»** → пролёты 3D-монет (rotationY + дуга, дальние размыты), камера всё время в движении (дрейф/поворот/микрозум на каждой сцене), вспышки screen-blend на ударах, райзеры перед ключевыми фразами, удары на смене сцен, свиши камеры; мелкие SFX +4 дБ. 80 SFX (4.5/с), 8 новых ElevenLabs.
- Громкость при большем числе SFX: gain нужно пересчитать (16.8 → 9.0 дБ), иначе −11.7 LUFS. Итог −14.0 LUFS, TP −3.3.
- GSAP: если fromTo с opacity:1 заканчивается позже следующего tl.to(opacity:0) — призрак остаётся; укорачивать первый твин.

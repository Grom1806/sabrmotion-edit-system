# Ролик SABRMOTION — «2 из 200 → 190 из 200»

**Источник:** исходника нет. Пользователь написал «генерируй сам», и я сгенерировал озвучку в ElevenLabs голосом пользователя (eleven_v4, stab .45, 3 дубля). whisper large-v3-turbo: в дубле 1 пропало «Сохрани», в дубле 3 «эта» вместо «это», взят дубль 2. Теги [serious]/[pause] вслух не читаются. Темп ×1.0, без вставки пауз. Проект `claude-edit\reels\sabrmotion-be-honest\` (пайплайн 4oshibki).
**Уровень / бренд / приём бренда:** Мощный в рамках «Графики» · SABRMOTION (графит, красный = ошибка, зелёный = честный ответ) · Linear border beam. Из «ещё не пробовали»: smash-zoom хука, тряска камеры на «190», маркер-подчёркивание строк промпта.
**Что сработало:**
- Сквозной объект — строка ввода чата: живёт в сценах 1–5 (схлопывание чата в неё → «ОДНА ФРАЗА» → печать «Проверь отчёты» → печать «Будь честен в ответе» по таймингам слов). Связывает сцены без переходов-шума.
- Сетка 20×10 документов: появление волной из центра, красные точки падают по детерминированному hash (НЕ stagger from:"random" — при параллельных воркерах рендер разный), сканер по сетке на «проверить».
- Вау: волна 188 зелёных от строки ввода (задержка = расстояние до неё) + счётчик 2→190 через onUpdate прокси + sub hit + тряска.
- Маска с улыбкой наезжает на робота и закрывает красный «!» — метафора «хочет понравиться» читается без звука.
- Карточка-промпт статична ~2 с (кадр для скриншота), маркер-подчёркивание на словах голоса, «Копировать → Скопировано», затем карточка всасывается в иконку «сохранить».
- Петля: финал уходит в размытый чат первого кадра.
**Что исправили (QA покадрово):**
1. show(el, 0, …) на первом элементе = кадр 0 пустой (hyperframes ругается gsap_timeline_set_initial_hide) → только скрытие позже.
2. #dark (opacity 0) засчитывается check как перекрытие текста → visibility только на время паузы.
3. Почти пустой экран 1.2 с с мелкой плашкой → крупная карточка «ДАННЫЕ / СИНТЕТИЧЕСКИЕ» с подчёркиванием.
4. Клик «Копировать» совпадал с уходом карточки → клик на «ошибки» +0.3 с, уход на «Сохрани».
5. FT с видимым from (кольца opacity .95) висели точками с начала сцены → S0 opacity 0 + fromTo.
6. `display:flex; gap` у контейнера посимвольных span разносит буквы → display:block.
7. ElevenLabs SFX «shimmer»/«scan» вышли тональными (aspectralstats flatness < 0.1) → белый шум ffmpeg (anoisesrc + highpass + экспоненциальный спад) и свайп из библиотеки. Проверять flatness у каждого нового SFX (шум/клики > 0.3).
8. mix.js брал onset/peak по необрезанному файлу, а звук обрезан TRIM → сдвиг до 1.4 с. Теперь analyze(f, TRIM[k]) с `-t`. verify_solo: 47/47 в ±50 мс.
9. Флэш субтитра на кадр на границе HIDE → граница = начало следующего слова −0.03.
**Цифры:** 34.0 с, 1080×1920 30 fps; −13.9 LUFS, TP −2.8 (мастер 10 Мбит/с, 43 МБ; light 720p 2 МБ); лицо 0 %; 55 событий (1.6/с); 47 SFX (1.38/с), 43 разных звука; check 0/0.
**Перенести в плейбуки:** «сквозная строка ввода» для любых роликов про промпты/ИИ; волна-заливка сетки от источника действия + счётчик; луч по краю карточки (Linear) как рамка для «кадра для скриншота».

# Визитка SABRMOTION (portfolio-intro-copy)

**Источник:** только фото пользователя (720x1280, пляж) → кроп голова-плечи 300x350 → lanczos ×2.4 + unsharp, фон моря оставлен. Голос ElevenLabs (eleven_v4, stab .45, 3 дубля, все дословные по whisper.cpp large-v3-turbo; взят 2-й — естественнее паузы). Ударения в тексте: Субха́н, диза́йнер, фи́нтеха, нуридди́нов; «AI» писать «эй-ай», «10+» — «больше десяти». Паузы `gaps.js` (ключи теперь нормализуются NFD без U+0301), самая длинная 1.7 с после «Вот его работы» — под стену роликов.
**Проект:** `reels/portfolio-intro-copy/` (HyperFrames, index.html). Цифра — `const COUNT = "10+"` в начале скрипта (счётчик 0→N + суффикс); при смене цифры переозвучить строку.
**Что сработало:**
- Референс светлый (серый/белый) — по бренду всё перевели в чёрный/графит, свет только в акцентах (неон имени зелёным, лучи красный/зелёный/белый).
- Веер «профилей» клиентов — свои UI-карточки-заглушки (иконка ниши, цифры-примеры, сетка из градиентов), без чужих аккаунтов; слово над веером меняется ровно на слове голоса.
- Стена работ: 8 своих рилсов (нарезки 4.5 с 400x712, `-g 15`), два ряда в противоход, наклон −9°/rotX 8°, плашка «ВОТ ЕГО / РАБОТЫ» поверх, выход zoom-through.
- «За его плечами»: буквы стоят в обычной строке, дуга = смещение от их места (не абсолютные координаты — иначе Unbounded налезает буквами).
- «И это лишь часть»: карточка 10+ уменьшается и встаёт в сетку 6x10 тёмных плиток — визуальная метафора без текста.
- Ник печатается по слогам голоса (@subhan / . / nuriddinov), CTA «Написать в директ» + знак с RGB-сдвигом.
**Что исправили (QA):**
1. Сцена с show() на t=0 была чёрной: `tl.set(visible, 0)` не срабатывает на нулевой позиции → при a≤0 ставить visible через S0.
2. Дуга вылезала за край на 17.25 с → шаг угла 5.6° → 4.3°.
3. Карточка «СВОЙ» висела под въезжающей стеной → уход на 0.3 с раньше.
**Цифры:** 27.2 с, 1080×1920 60 fps; −14.6 LUFS, TP −3.5; 39 событий (1.43/с), пустот >1.6 с нет; 33 SFX (1.21/с), все разные, verify_solo макс |Δ| 5 мс. Новые SFX ElevenLabs: el_cam_shutter, el_sparkle, el_clock_tick, el_card_flick, el_reel_rush, el_rays_burst (тихие clock/sparkle нормализованы +15 дБ).
**Перенести в плейбуки:** «карточка становится плиткой сетки» для любых «и это лишь часть / один из многих»; дуга текста через смещение от строки.

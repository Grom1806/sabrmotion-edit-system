# Рилс plan-5 — «Что меня бесит в исламских приложениях»

**Источник:** дубля на камеру нет → 0 % лица. Озвучка ElevenLabs клоном пользователя (eleven_v4, stab .45, 3 дубля; whisper large-v3-turbo кусками — все дословные, на целом файле whisper «терял» «Ссылка в шапке»). Взят дубль 2 (чистые «Коран», «тафсир»). Паузы-вдохи tools/gaps.js (0.45 с тишины перед «Мне надоело»). Проект `claude-edit\plan5-reel5\`.
**Скриншоты:** настоящие экраны ummah-link.com через Playwright 390x844 @3x (cookie → «Только необходимые»; element.screenshot по тексту). /study/quran/1 и /study/hadith на сайте падают с React error #441 («Не удалось открыть страницу») — баг продукта, сообщён; экран суры и виджет намаза сделаны мокапом в цветах продукта (шапка — настоящий скрин).
**Уровень / бренд / приём:** Мощный · палитра B3 Midnight Teal + золото (по брифу; та же палитра была в offline-ai — в следующих рилсах плана взять другую) · Linear rotating glow (не border beam, он был в be-honest). Из «ещё не пробовали»: color-shift проблемы в обесцвеченный холодный мир, кинетический постер «МНЕ НАДОЕЛО» по буквам, курсор-палец с тапами, цепочка UI-морфов «плохой экран → хороший».
**Что сработало:**
- Сквозной счётчик ПРОБЛЕМА 1/3 → РЕШЕНИЕ 1/3 (коралл → мята) + 3 сегмента — структура читается без звука.
- Каждое решение начинается со вспышки «плохого» экрана: баннер схлопывается в точку, замок ломается, кнопки разлетаются — и три плитки улетают из телефона в карточки «Коран / время намаза / аят дня».
- Хук: 10 цветных абстрактных плиток падают pile-up, «10» на слове, слияние в одну серую плитку, она же становится телефоном (match cut).
- Лого собирается линией (pathLength=1 + dashoffset), книга раскрывается scaleX от svgOrigin, затем кроссфейд в настоящий PNG.
- Субтитры новым стилем: Manrope 800 строчными, активное слово в таблетке (мята / коралл на проблемах), Ummah Link латиницей.
**Что исправил аудит:**
1. Всё, что show() включал ровно в t=0, в рендере hyperframes оставалось скрытым (хук пустой, экран телефона пустой), хотя в браузере при любом seek всё видно. Решение: видимое с кадра 0 не прятать вовсе (gsap.set visible + только скрытие в конце).
2. `visibility: visible` у вложенных карточек пробивал скрытый экран-родитель → восстанавливать `inherit`.
3. check: текст, спрятанный сдвигом y внутри overflow:hidden (слот-счётчик), считается «перекрытым» → цифры/подписи переключать видимостью.
4. check: текст под баннером/пейволом = content_overlap → закрытые карточки прятать на время перекрытия; попапы «хаос-экрана» вынесены под сетку.
5. Пустой белый экран 0.2 с перед тёмной паузой (экран скрывался раньше затемнения); полупустой экран в начале П3 (15 кнопок сразу).
6. «НАДОЕЛО» 158 px и «нормальное приложение» 66 px вылезали за край → 136 / 54 px.
7. Самолётик улетал, оставляя пустой круг → возвращается снизу (петля).
8. Тональные SFX (касса со звонком, писки select/maximize/error, flatness < 0.08) заменены на шумовые; кромка вращалась не вокруг центра телефона (top −185).
**Цифры:** 36.1 с, 1080×1920 30 fps; −14.0 LUFS, TP −2.3; лицо 0 %; 58 событий (1.61/с); 40 SFX (1.11/с), verify_solo 40/40 в ±5 мс; check 0 ошибок. Мастер 16 Мбит/с (86 МБ), light 720p 3.3 МБ.
**Перенести в плейбуки:** счётчик «проблема → решение» с переключением цвета; вспышка плохого экрана перед каждым решением; правило «show на t=0 = не прятать».
**Статус:** по брифу превью не согласовывается — мастер и light выданы 2026-10-19.

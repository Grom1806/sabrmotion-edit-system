# Рилс «Отключи интернет» (reel9-offline-ai)

**Источник:** записей экрана и озвучки нет. Озвучка ElevenLabs голосом пользователя (eleven_v4, stab .45, 3 дубля, все дословные по whisper; взят 2-й — без паузы внутри «всё равно»). В TTS «Оллама», «айфоне», «пэ-ка»; на экране Ollama / ПК. Паузы `tools/gaps.js` → 37.4 с голоса, итог 38.7 с. Добавлена строка про MiniCPM-V 4.7 · 15.10 (без цифр скорости).
**Реальные данные вместо выдуманных:** `ollama list` на ПК → qwen3.5:9b; ответ на вопрос сценария сгенерирован локально (5 прогонов через API, взят самый точный, текст не правился; в Git Bash curl ломает кириллицу → запрос из node); `ollama pull qwen3.5:9b` дал настоящие хэши слоёв (921 MB + 5.6 GB, success); `nvidia-smi -lms 100` во время генерации → график Диспетчера задач (простой ~20 %, нагрузка 84–94 %, 10,1/16 ГБ, RTX 5080). Wi-Fi на ПК не выключали.
**Типы монтажа:** С1 «Тёмный эксплейнер» = Т06 HUD-эксплейнер + Т05 кинетика («ОФЛАЙН», «3 ШАГА», «ЛОКАЛ») + Т07 UI-демо (трей Win11, PowerShell, ollama.com, Диспетчер задач, iPhone) + Т03 цепочка UI-морфов (плитка Wi-Fi → окно терминала → экран монитора).
**Приёмы учебника:** фраза серым 35 % + активное слово вспыхивает циан и остывает в белый; streak-размазывание; окно rotateY 75° с вспышкой ребра; линия прочерчивается и на ней печатается текст; пиксель-сборка ЛОКАЛ (canvas, мозаика 40→1); печать–стирание–перепечатка команды; кнопка растёт из точки; кольца-волны на галочке; плитка-цифра → иконка; линза-схлопывание сцены в полоску; круговая маска из бейджа; искры.
**Что исправили (QA 10 к/с):**
1. Хук пустой 0–1.7 с: `tl.set(visibility:visible, 0)` не срабатывает на нулевой позиции (третий раз!) → `show()` теперь при a ≤ 0 ставит visible через S0.
2. 3D-флип плитки показывал зеркальную «1»: `filter: blur` на элементе (после blur-in) уплощает preserve-3d → флип плоский: scaleX 1→0, смена лица, 0→1.
3. Круглый stroke-linecap при dashoffset = L оставляет точку → у drawPath opacity 0 до старта.
4. Галочка шага 3 перекрывала текст ответа; вспышки на ударах .3 давали серый кадр → .1–.16.
5. check: контраст HUD (rgba-серый → #A3C2BE), скрытые цифры бейджа (yPercent за краем = «occluded») → плюс opacity 0; наложение «Подключено/Отключено» → скрывать старое содержимое плитки.
6. 4 тональных SFX из библиотеки (message_pop, select_002, drop_002, scan_beam; flatness < .06) заменены кликами; новый el_data_stream из ElevenLabs вышел тональным → синтез anoisesrc+tremolo.
**Цифры:** 38.7 с, 1080×1920 30 fps, 18.8 Мбит/с (91 МБ), light 720p 8.3 МБ; −13.9 LUFS, пик −2.4 dBFS; 81 событие (2.09/с); 83 SFX (2.14/с), verify_solo 83/83 в ±5 мс; 9 типов переходов; check 0 ошибок. iPhone сделан CSS-3D силуэтом (Blender не понадобился).
**Перенести в плейбуки:** «реальные данные для UI-реконструкции» (локальный запуск модели, лог nvidia-smi); show() с правилом t=0; плоский флип вместо rotateY, если на элементе был filter.

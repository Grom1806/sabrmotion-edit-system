# Ролик SABRMOTION — «4 ошибки»

**Источник:** исходник не нужен: озвучка ElevenLabs голосом пользователя (eleven_v4, stab .45, 3 дубля — все дословные по whisper large-v3-turbo, взят 3-й: лучше пауза перед CTA), темп ×1.0, «вдохи» 0.2–0.55 с (`tools/gaps.js`), обработка «остренькая» без де-реверба. Кадр для «серого цвета»: несгрейженная версия reel 2 (`_archive/reel2_v1/out/master.mp4`, кроп лица без плашек), исходника DJI на ПК нет. Лог-вид симулирован (curves 0→.16 / 1→.86, sat .5, лёгкий зелёный сдвиг), ПОСЛЕ = грейд L1 Clean Apple (contrast 1.08, глубокий чёрный, нейтральная кожа, виньет PI/5).
**Уровень / бренд / приём бренда:** Стандарт (темп Apple) · SABRMOTION · см. brand_move. Проект: `claude-edit\reels\sabrmotion-4oshibki\`, сценарий `reels\sabrmotion\reel-4-oshibki-script.md`.
**Что сработало:**
- **Цифра-плитка как якорь:** большая «4» (640 px, expo.out из blur 36) уезжает в левый верхний угол (scale .234) и переворачивается в «01»; дальше каждый пункт = флип 01→02→03→04 + **круговой вайп clip-path circle() из центра цифры** (графит с красным свечением ↔ чёрный). Содержимое пункта живёт внутри вайп-слоя → старый пункт закрывается сам.
- After Effects (MCP, без eval.run): (1) ДЁШЕВО — PNG слова из headless Chrome (Unbounded в AE нет) → Gaussian Blur blur-in → Turbulent Displace дрожь (эволюция экспрешеном `Math.floor(time*30)*47`) → Mosaic 1080→27 блоков → CC Pixel Polly (Object 4 = textured square) — рассыпание пикселями; (2) кривая: прямая linear → морф shape-path ключами `{__kind:"Shape"}` в expo.out, «робот»-квадрат linear без motion blur, «живой» квадрат с outSpeed 2300/influence 22 → overshoot 5 % → squash, motion blur 270°. Фон комп = #0B0B0C, в H.264 выходит 12/12/12 — шов с HTML невиден.
- ДО/ПОСЛЕ всегда ✕/✓ + рамка + плашка «ДО/ПОСЛЕ» (не только цветом). Шторка = clip-path inset сверху вниз + светящаяся полоса (y-transform).
- Пункт «тишина»: реальная пауза 0.45 с без SFX, затем 5 объектов падают на таймлайн, у каждого свой звук (поп, клик, whoosh, тик, стеклянный свайп) + спайк на волне + кольцо.
- Финал: МОНТАЖ по буквам с красной «волной» активной буквы, подписи ЧЕК-ЛИСТ → 12 ПУНКТОВ → БЕСПЛАТНО; слово уезжает вверх и становится шапкой карточки чек-листа (12 строк, stagger 60 мс, галочки рисуются); тёмная пауза → знак blur-in + RGB-сдвиг + блик + зелёная CTA.
**Что исправили (QA покадрово):**
1. GSAP `innerHTML: "01"` → строка-число превращается в `1`. Писать `"<span>0</span>1"`.
2. Флип rotationX на огромной цифре с perspective 600 давал кривую кляксу → perspective 2000 и флип, когда цифра уже уменьшилась.
3. AE-клип кончался за 0.1 с до вайпа (✓ висел на пустом кадре) → комп удлинён до 7 с (outPoint 'comp').
4. Плашки LOG/L1 и ДО/ПОСЛЕ просвечивали друг через друга → нижнюю гасить в момент шторки.
5. Lint: `top` у полосы шторки → `y` (transform). Видео log/grade с редкими ключами (4.17 с) → перекод `-g 30 -keyint_min 30`, иначе фризы при seek.
6. Субтитры дублировали текст карточки «ДВА-ТРИ СЛОВА / ВЫДЕЛЕНО» и ДОРОГО → скрыты на этих отрезках.
7. SFX сначала 1.11/с (41) — для Стандарта много → убраны флип, вход карточек, ✕-клик, веер, deep hit → 31 (0.84/с; пункт 3 сам по себе даёт 5 звуков за 1.8 с).
**Цифры:** 37.0 с, 1080×1920 60 fps; −14.5 LUFS, TP −3.5; лицо 0 % (кроме карточки грейда); 64 события (1.73/с), 0 пустот > 1.6 с; 31 SFX (0.84/с), verify_solo: все в ±50 мс (макс 0). 9 новых SFX ElevenLabs: pixel_crumble, error_buzz, dull_buzz, soft_thud, robot_tick, glass_swipe, logo_glitch, shutter_wipe, marker_scratch. 4 круговых вайпа + 2 шторки + 3D-веер со всасыванием в точку + тёмная пауза.
**Перенести в плейбуки:** «цифра-плитка в углу → круговой вайп из неё» для любых list-роликов; AE Pixel Polly после Mosaic для «рассыпания»; AE shape-path морф linear→ease как наглядное объяснение easing; приём «кодовое слово становится шапкой следующей карточки».

# Ummah Link «6236 аятов» — ризо-инфографика

**Выход:** `VIDEOS\ummahlink\2026-10-19_infografika\2026-10-19_ummahlink_infografika_master.mp4` (+ `_light.mp4`, `_sheet.jpg`, `extra\`: «сейчас vs 3 направления», sfx_events, резкость до/после). Проект AE: `reels\ummah-infographic\ummah-infographic.aep` (оставлен открытым). Ожидает отзыва.

## Что сделали
- Аудит 20 роликов ([[audit-2026-10-19-ai-tells]]) + ресерч практиков ([[practitioners-2026-10-19]]) → 3 направления, пользователь: «make all recommended» → ризо-плакат + вырезки экранов со стикерным краем.
- Сценарий 7 строк, факты сверены по репозиторию сайта (хатм = трекер по 30 джузам; один бесплатно, несколько — Premium). Озвучка клоном, 31.6 с.
- Инфографика в каждом бите на реальных данных: 114 полос = аяты каждой суры (сумма 6236 сверена), 9 корешков сборников, баннер «РЕКЛАМА» срывается → «0», сетка 114 со счётчиком, аят с выносками «арабский + таджвид / перевод / тафсир», дерево хадисов, дуга 5 намазов, трекер 30 джузов с закладкой «ты здесь», финал «бесплатно» + закладка (повтор образа).
- 24 fps, Hold-ключи, вход «штампом» за 2–4 кадра, posterizeTime(12) на выражениях, камера-нуль с ударами на 39 словах, без blur-in, без стекла, без HUD, без неона.
- Звук: 23 фоли (штампы Kenney, бумага/страницы Mixkit, карточки), без музыки, без тональных, без room tone; −14.7 LUFS, TP −1.4.

## Видимый таймлайн (по просьбе пользователя)
Никакого общего прекомпа: камера = нуль «Камера (удары на словах)», 170 слоёв с именами вида «03 Коран · 07 текст «перевод»», лейблы по типам, маркеры сцен 01–07 на компе, фразы озвучки маркерами на слое голоса, 23 SFX отдельными аудиослоями. Reduce Project → в .aep только этот ролик. Скриншот окна AE: `ae\shot_ae.ps1`.

## Ошибки и исправления
1. «6236 мыльная» — основная краска ризо стояла в Multiply → светлый двойной контур; на скриншоте вьювер был Half 40 %. Исправлено: основная краска Normal, призрак Multiply, зерно 5 %, Full. Правило → [[ae-pipeline]] «Резкость».
2. Цифра резалась краями: удар камеры от 103 %. Теперь база 100 %, поля ≥60 px.
3. Сборщик открывал MASTER и сохранял полную копию со старыми компами «Дня 90» (7 ошибок выражений) → добавлен reduceProject перед сохранением.
4. Экранирование: в JSX, собранном из bash/node, `\r`, `\v` и пути ломались несколько раз — писать JSX через Write/Edit, пути в JSX прямыми слешами.
5. Уборщик в параллельной сессии удалил все `.tmp` → рабочие файлы держать в `work\`, не в `.tmp`.

## Мыло во всём ролике: причина и решение (2026-10-19, отзыв «очень много мыла»)
**Аудит (кадры 1:1 из AE, ProRes, master, light; изоляция по слоям):**
1. **Light пережат:** 720×1280, 5.3 Мбит/с (ffprobe). На телефоне растягивается обратно до 1080 → мыло.
2. **Фактура поверх текста:** анимированное зерно (Fractal Noise, Multiply 5–9 %) и «волокна бумаги» (Overlay 12 %) лежали НАД всем контентом → края букв превращались в шум, кодер ещё и размазывал этот шум. Кадр без этих слоёв — сразу чистый (сравнение `audit/bt.png`).
3. **Камера всё время пересэмплировала кадр:** непрерывный зум 100–103 % (sin) + база 100.8–101.6 % между ударами + дробный wiggle → каждый кадр перерисовывался с интерполяцией.
4. Не причина: motion blur (разницы нет), разрешение исходных скриншотов (990 px → 800, уменьшение).
**Решение:** фактура перенесена ПОД контент (бумага шершавая, буквы чистые); камера между ударами ровно 100 %, без постоянного зума, wiggle на целые пиксели; master CRF 14 `-tune animation`, light теперь 1080×1920 CRF 18 (не 720p). До/после 1:1: `VIDEOS\ummahlink\2026-10-19_infografika\extra\myl_light_before_after_1to1.png`. Старые файлы — в `old\…_v1-soft_*`.

# PERSET инвест-ролик 01 — «Деньги, которые не могли дойти»

**Источник:** без съёмки, 100 % моушн-графика, голос ElevenLabs (EscobarRKZ XGyi3FDBCYWBQ6vRd0FV, eleven_v4, stability 0.35, speed 0.97), 1920x1080 30 fps. Проект `perset\invest01\`, выход `out\perset_invest01_preview_720p.mp4` + master 1080p.
**Уровень / бренд / приём бренда:** Мощный · PERSET v2 светлая · Revolut card-stack flip + Apple macro-to-wide, тёмная пауза перед финалом.

**Что сработало:**
- Голос **по сценам** (`tools/vo.js`, 19 кусков с previous_text/next_text), склейка с паузами в `tools/words.js`. Сцены 14–15 с плейсхолдерами — отдельные куски s14/s15: заменить текст в scenes.json → `node tools/vo.js s14 s15` → words → inject → mix, ничего больше не трогать. Значения на экране — объект `PH` в index.html.
- Транскрипт whisper (large-v3-turbo) совпал со сценарием дословно; «Персе́т» с U+0301 прочитан правильно; USDT писать для TTS как «ю-эс-ди-ти», в субтитрах маппинг `83{2}` (токен заменяет N слов голоса).
- **Тайминги слов брать из ElevenLabs alignment, не из whisper.cpp:** alignment совпал с паузами в огибающей до ~10 мс, whisper.cpp `-ml 1` опережал на 0.4–2 с.
- AE без eval.run (политика MCP) — всё атомарными ops в `batch.run`: shape.add_path + trim paths (прорисовка P и S знака), 3D-карты из PNG (карты рендерятся headless Chrome с прозрачным фоном), монета по эллипсу через **expression на Position + Slider Control** (сэмплы позиций по 15 к/с дают углы на быстрых петлях).
- AE рендерит H.264 напрямую (шаблон «H.264 — 40 Мбит/с»), фон AE-комп = #FAF7F2, в видео получается 250/246/243 — шов с HTML незаметен.
- 17 типов переходов, 1.01 событие/с, 0.80 SFX/с, 21 новый SFX из ElevenLabs (ошибки банка ×3 разные, флипы ×3 разные, звон, подключения).

**Что исправили на QA (до показа):**
- GSAP перетирает CSS `transform: translate(-50%,-100%)` у подписей → ставить `xPercent/yPercent` через gsap.set, а не CSS.
- Shape-слой AE по умолчанию стоит в центре компа (960,540): пути в координатах компа → Position [0,0].
- Fade полупрозрачных 3D-карт даёт «призраков» → вход стопки без перекрытия по opacity, выход через scale→0; в HTML включать видео карт после ухода прошлой сцены.
- Карту из точек центрировать по зоне действия (scale/x/y под origin), иначе всё в верхней трети; чипы на карте не ставить на линии.
- SVG-орбиты с transform-origin в px улетали при масштабе карты → заменили на пульс радиуса.
- 0.3 с пустого кадра между сценами 15→16 — вход следующей сцены начинать до конца ухода предыдущей.

**Цифры:** 2:11 (чистой речи 1:57 при плане ~3:00 — паузы растянули, искусственно не замедляли), -14.0 LUFS, TP -1.6, SFX попадание 103/105 в ±50 мс (2 мимо — фоновый swell без атаки), лицо 0 %.
**Открыто:** цифры s14/s15, контакт основателя, смысл «+1%» в цикле (в кадре как «[+1%]»), оригинал лого.
**Перенести в плейбуки:** card-stack flip в AE из PNG-карт; монета по пути через expression; macro-to-wide из толстой золотой линии (scale 9→1).

## v2 — правки пользователя (2026-10-18)
- **Рамку подсветки ячейки** делать дочерним элементом самой ячейки (`inset:-7px`), а не абсолютом в координатах карточки — иначе съезжает на соседнюю.
- **Подписи в карточках** (разрядка .24em) вылезали за 540 px: для длинных слов кегль 16 и разрядка .12em; проверять самое длинное слово («закупка у поставщика»).
- **Карта маршрутов:** у каждого героя своя точка отправления (Москва, Казань, Махачкала), аватар соединён с точкой ножкой, пунктир идёт из этой точки к подписанной стране и обрывается крестиком на своей линии; линии не должны проходить через чужие точки (маршрут семьи провисает ниже Европы, lift −0.06). Чипы ставить по длинным маршрутам, не в кластере.
- **Плейсхолдеры, которые пользователь не понимает** («[СУММА]», «[+1%]»), из кадра и голоса убрать; оставить только цифры сцены 14 и контакт, о которых договорились.
- AAC добавляет ~1 дБ к пику: в лимитере ставить TP −2.5, чтобы в mp4 было ≤ −2.
- Итог v2: 2:09, −14.1 LUFS, пик −2.1, 104 SFX.

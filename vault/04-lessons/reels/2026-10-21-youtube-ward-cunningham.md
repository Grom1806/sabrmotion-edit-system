## Пайплайн (повторить для длинных интервью)
`tools/cut.cjs` (EDL + silencedetect −35 дБ) → `tools/faces.py` (MediaPipe FaceLandmarker: центр лица и EAR на ±3 кадрах склейки) → `tools/plan.cjs` (крупности, рез по морганию, субтитры, карточки, таблица SFX) → `tools/matte.py` (rembg birefnet для «текста за человеком») → `ae/build_ward.jsx` (419 слоёв за ~1.5 мин) → `tools/mix.cjs` (голос + SFX-шина в памяти, двухпроходный loudnorm) → рендер очередью AE `ae/render_ward_rq.jsx`.

## Ошибки и решения
1. **Шрифты → Times в рендере.** aerender (отдельный процесс) и AE, запущенный заново после перезапуска сессии, не видят пользовательские шрифты, хотя `isSubstitute=false`. Решение: перед КАЖДЫМ запуском AE `ae\fonts_register.ps1` (AddFontResource + WM_FONTCHANGE), рендер очередью открытого AE, а не aerender. Проверять кадр глазами, а не `fontObject`.
2. **Special Elite без кириллицы** → русские строки уходили в подстановку. Машинопись = Courier New Bold (CourierNewPS-BoldMT).
3. **Ссылки на свойства шейпа устаревают** после добавления fill/stroke («Недопустимый объект») → брать свойства заново по индексу группы.
4. **`"текст" + errorObj` в catch** роняет ExtendScript модалкой → логировать `String(e.message)`.
5. **Ребёнок через parent не наследует opacity** → рамка штампа была видна до штампа; анимировать прозрачность у обоих.
6. `run.ps1` ловит «errors 0» как ERROR → задавать `RUN_TAG`.
7. Арабский/хинди в AE без движка сложных письменностей рисуются неправильно → для «сети языков» брать письменности без лигатурной сборки.
8. Сессия RC умирает → AE и рендер умирают с ней; длинный рендер запускать сразу, частичный файл переименовывать в `_INCOMPLETE`.

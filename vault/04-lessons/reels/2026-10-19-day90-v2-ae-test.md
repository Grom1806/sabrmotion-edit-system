# «День 90» v2 — тест системы v2 в AE

**Выход:** `VIDEOS\sabrmotion\2026-10-19_plan1-den-90\2026-10-19_sabrmotion_plan1-den-90-v2_master.mp4` (+ `_light.mp4`, `_compare.jpg` старое/новое по 20 кадров, `extra\..._styleframes.png`). Бриф: `reels\ummah-day90\brief_v2.md`. Ожидает отзыва пользователя.

## Что сделали
- Мир «журнал сборки», сквозной объект — реальный график коммитов (gitdata): рисуется → отмотка к первому коммиту `e92b6725 «new update»` → день 90 → git-лог с ускорением → «557» → штрих-код 557 коммитов (224 fix золотом, реальные флаги) → пустой день 91 на оси.
- S01 Documentary + S13 + момент S06. Шрифты Golos Text / PT Serif Italic / IBM Plex Mono. Субтитры слева, обычный регистр, акцент сменой гарнитуры (characterRange работает в AE 26.5).
- «Выкидывал в полный экран» показано следствием: постер урока раздувается на весь кадр.
- Звук: 15 нетональных SFX на 40 с (Mixkit/Kenney из `assets\sfx` + синтетический шорох ручки), фирменный звук — перелистывание ×3, room tone, −14.3 LUFS, TP −1.4.

## AE: что работает
- Скриптинг через `AfterFX.exe -r script.jsx` в уже открытый AE (`ae\run.ps1`, ждёт DONE в `ae\logs\run.log`). Полная пересборка 66 слоёв — 3 с. `saveFrameToPng` = стиль-фреймы мгновенно.
- `aerender` в фоне при открытом AE: аниматик (черновик) 30 с, финал 1080×1920 с motion blur 123–139 с на 40 с ролика (`ae\render.ps1`).
- LIB v01 в `ae\lib_v01.jsx` → прекомпы в папке LIB проекта `ae\MASTER_v01.aep`: page (журнальная страница), chart (график по слайдеру day), caption, proofCard (медиа на «фотобумаге» + источник), note (печать по буквам), annot (рукописная линия с кипением), sweep (переход-линия), grade (B&C + CC Vignette + зерно Fractal Noise). Плюс textcard, gitlog.

## Грабли (запомнить)
1. **AE на русском: обращаться к свойствам только по matchName** (`ADBE Position`, `ADBE Glo2-0003`, `ADBE Vector Stroke Width`…). Английские display-имена эффектов падают «null не является объектом». Source Text = `property("ADBE Text Properties").property("ADBE Text Document")`. Дамп matchName: `ae\logs\dump_fx.jsx`.
2. **Шрифты:** установка в `%LOCALAPPDATA%\Microsoft\Windows\Fonts` + HKCU мало — AE увидел их только после `AddFontResource` + `WM_FONTCHANGE` (PowerShell P/Invoke), перезапуск не понадобился.
3. Шаблоны рендера в ru-AE называются по-русски («Оптимальные настройки», «Настройки черновика», «Высокое качество» = ProRes). `.ps1` с кириллицей сохранять с BOM, иначе PowerShell 5.1 ломает имена.
4. MCP kumoproductions: `eval.run` выключен, `instance.start` без `install-agent` не работает; AE запускать без `-m`.
5. `package.json` в папке рилса с `"type":"module"` → node-скрипты называть `.cjs`.
6. Linear Wipe с выражением от слайдера — удобный «рисуй до курсора» для графика (Trim Paths меряет длину пути, а не X).
7. Пока я работал, параллельная сессия перенесла `out\` в `VIDEOS\` (новая система хранения) — готовое класть туда.

## Инструкция пользователю: шаблоны вывода (один раз)
Composition → Add to Render Queue → в очереди нажать стрелку у «Модуль вывода» → «Создать шаблон…» (Make Template):
1. `REELS_H264_40M`: формат H.264, битрейт 40 Мбит/с, звук AAC 320.
2. `REELS_ProRes4444_Alpha`: QuickTime, Apple ProRes 4444, каналы RGB + Alpha, «Прямой (без каше)» / Straight.
3. `REELS_ProRes422HQ`: QuickTime, Apple ProRes 422 HQ, RGB.
4. `PNG_SEQ`: PNG Sequence, RGB + Alpha.
Render Settings → «Создать шаблон…»: `Best_Full` (Наилучшее качество, Полное разрешение, Motion Blur вкл.) и `Draft_Half` (Черновик, Половина, Motion Blur выкл.). После этого `ae\render.ps1` переключить на эти имена.

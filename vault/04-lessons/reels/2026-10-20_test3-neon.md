# Тест 3 (2026-10-20)

Исходник: DJI_0028 4K (свой). Проект `reels\2026-10-20_practice-test3\`: tools/track_matte.py → ae/build_test3.jsx → tools/mix.cjs → finalize.ps1 → sharpcheck.ps1. Выход: `VIDEOS\tests\2026-10-20_test3_dolzhnik-neon\`.

## Текст за головой — рабочий рецепт (без Roto Brush)
- venv `.tmp\mattenv` (uv, Python 3.12): `rembg[gpu]` + `onnxruntime-gpu[cuda,cudnn]`. **Без `onnxruntime.preload_dlls()` и явного `providers=["CUDAExecutionProvider", ...]` считает на CPU (≈15 с/кадр);** на RTX 5080 — доли секунды.
- Модель `birefnet-portrait`, `only_mask=True` → 8-бит маска 3840×2160 на каждый выходной кадр пика.
- AE: слово над плитой → копия плиты (`duplicate()`, ключи сохраняются) над словом → PNG-последовательность маски, `parent` = копия, anchor = position = [1920,1080], `setTrackMatte(маска, LUMA)`.
- Слово ставить так, чтобы голова закрывала ≤ ¼ высоты букв (иначе «1__ 000» не читается); ширина ≤ 1000 px.

## Трек головы
- mediapipe ≥ 0.10.30 без `solutions` (нужна модель tasks); каскады Хаара в OpenCV 5 пустые. **Надёжно: по маске rembg** — верх силуэта + центр масс полосы 500 px под ним, 2.5 fps, гаусс 0.4 с внутри склейки.
- В AE: null с Point Control (координаты 4K) → `L.toComp(p)` через активный слой «ГОЛОВА…». Метки следуют дельтой от inPoint, **с ограничением ±70/±50 px** — иначе смена крупности внутри отрезка уводит счётчик за край.

## Ловушки
- Длинный счётчик («10 000 000+ ₽») в 170 pt не влезает — кегль по длине.
- Средний/общий план 4K не заполняет 9:16 → субтитры в нижнюю полосу (y 1790), карточки в верхнюю; на крупном субтитр y 1640, не на рту.
- Лицо в DJI_0028 левее центра кадра → position x 680 (W 630) для центра.
- Доступ computer-use к AE пользователь отклонил → «скриншот таймлайна» делал схемой из слоёв (`ae\dump_layers_test3.jsx` + PIL).
- Райзеры тональные — для «роста» брать свуш (без музыки).

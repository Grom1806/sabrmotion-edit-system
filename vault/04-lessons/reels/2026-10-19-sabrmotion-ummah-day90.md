# Ролик SABRMOTION — «Мне 17. День 90»

**Источник:** дубля нет → озвучка клоном (eleven_v4, stab .45, 3 дубля, взят 2-й по whisper.cpp). Записи экрана сняты самим Playwright (playwright-core + chromium из ms-playwright, мобильный вьюпорт 390x844 @2x): покадровый скриншот + свой ease-скролл, темп реального времени → таймер намаза тикает честно. Баннер cookie → «Только необходимые», для намаза grantPermissions(geolocation) + Москва.
**Уровень / бренд / приём:** Мощный · SABRMOTION, палитра B3 Midnight Teal (#0B1F24/#1F6F6B/#5FE3D0) + золото приложения #D4AF37, фон с исламским 8-конечным узором 6 % · Revolut 3D-телефон. Из «ещё не пробовали»: split-screen сравнение, данные git как графика (тепловая карта по дням, 557 точек с перекраской fix), макет-«поломка» UI (куски падают).
**Что сработало:**
- Сплит «День 1 / День 90»: левая половина — карточка реального первого коммита, справа маленький телефон; на «Сейчас» шторка уезжает, телефон бесшовно вырастает в героя.
- Счётчик 0→557 и клетки тепловой карты загораются по кумулятивной доле коммитов (обратная функция power2.out) — цифра и карта синхронны.
- 557 точек в хронологическом порядке, 224 fix перекрашиваются в золото волной синхронно со счётчиком; «40 % всех коммитов» — честная цифра.
- Пилюля «1/3→3/3» барабаном, push экранов внутри телефона + качание rotateY.
**Что исправили (QA):** пустой кадр 0; кольцо на таймере отставало от скролла (нужна линейная скорость скролла клипа, 255 px/с); пустоты перед сценами (0.4–1 с); счётчик 224 на «двести», а не «коммита»; субтитр «STORE» отдельно; серая вспышка screen-blend на 91; тональные SFX по flatness (<0.1).
**Грабли:** `git log --since=ДАТА` берёт текущее время суток → число коммитов «плавает»; считать от точного таймстампа коммита. Сайт с упавшей БД показывает «Не удалось открыть страницу» (React #441) — причину смотреть в Vercel runtime errors. Контраст-чек ругается на декоративный текст → текст через `::before { content: attr(data-t) }`.
**Цифры:** 40.3 с, −13.9 LUFS, пик −2.6; 80 событий (1.99/с), 71 SFX (1.76/с), verify_solo 71/71 ±15 мс; check 0 ошибок. Мастер 90 МБ, light 720p 10.8 МБ.
**Статус:** пользователь не отвечает → мастер и light сразу, 2026-10-19.

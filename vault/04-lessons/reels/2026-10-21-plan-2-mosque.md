# Рилс plan-2 «Мечеть за один вечер»

**Источник:** дубля на камеру и записи экрана не было → эксперимент провёл сам. `claude -p --safe-mode --output-format stream-json` (safe-mode = без моих CLAUDE.md/скиллов/хуков, как у обычного пользователя) в `reels/plan-2-mosque/site/`, рекордер `rec/run.js`: лог с таймкодами + Playwright-скриншоты сайта на каждое изменение файлов (телефон 390 @2x и десктоп). Итог: 0:00 → первая версия 1:03 ($0.29) → сверка с Aladhan: фаджр 04:24 вместо 04:19 (adhan `HighLatitudeRule.recommended` для широты > 48° = «седьмая часть ночи») → правка вторым промптом с `--continue` (2:12 → 3:12, $0.47). Текст озвучки переписан под факт («три минуты, а не вечер»).
**Уровень / бренд / приём:** Мощный · SABRMOTION (знак, Unbounded + JetBrains Mono), но палитра B3 Midnight Teal (#0B1F24 / #1F6F6B / #5FE3D0 / #F2B354 / #EAF2EF), красный/зелёный только как «ошибка/исправлено». Типы: Т07 UI-демо + Т13 HUD-таймер + Т05 кинетика + Т11 3D-телефон.
**Что сработало:**
- Реплей реального лога как «запись терминала»: строки `● Write index.html` и т.д. появляются по формуле `R(r) = B0 + r·(B1−B0)/63` (секунда сборки → время ролика); скриншоты сайта меняются в те же моменты → видно, как голый HTML обрастает стилями.
- HUD-таймер — одна функция от `tl.time()` (прокси `tim.v` + onUpdate на пустом твине длиной END), этапы 1/4…4/4 и сегменты; на «правке» быстрый прокрут 01:03 → 02:12 (время моей сверки), потом бег до 03:12, всё зелёное на «готово».
- Зум ×2 на настоящую ошибку + карточка-эталон «aladhan.com · MWL · 04:19» + «+5 мин» → правка: зачёркнут `.recommended(coords)`, зелёный `.MiddleOfTheNight`, строка сайта меняется кадром из второй версии (clip-path шторка).
- Blender: один телефон, экран — полная страница (1170×6699) через Mapping node: scale Y = 2532/H, location Y анимирован = прокрутка; экран — скруглённый меш (rrect), UV из координат. Кадр 1 = экран по высоте кадра (d = SH/(36/50)). 105 кадров EEVEE ≈ 1.5 мин.
- AE без второго экземпляра: в открытом чужом проекте временная композиция → `ae_render_frame` с `times` (31 кадр за вызов) → `comp.delete`. Чужие композиции не тронуты.
**Что исправили (QA 10 к/с):** зум ×2 обрезал «04:24» (строка шире окна → центр на цифрах); плашка на тексте эталона; жёсткий край radial-gradient (`closest-side` на большом блоке); пустые 0.6 с до карточек → заглушки 16 %; субтитры поверх 3D-телефона скрыты; полупустая карточка промпта; заголовок наезжал на улетающий терминал; точки от round-caps ненарисованных путей (stroke-dasharray) → visibility со старта отрисовки; lint top/height окна → transform страницы внутри окна. Тональные UI-блипы kenney select/switch, message_pop → щелчки (по медиане flatness < 0.1 у импактов это норма, у блипов — тон).
**Цифры:** 39.4 с, 1080×1920 30 к/с, 14 Мбит/с; −13.9 LUFS, TP −2.0; 0 % лица; 61 событие (1.55/с); 48 SFX (1.22/с), verify_solo 48/48, макс 5 мс; check 0 ошибок, 37/37 контраст.
**Перенести в плейбуки:** «эксперимент без дубля» = рекордер run.js (лог stream-json + скриншоты на изменение файлов) — честная запись экрана для любых роликов «проверил сам»; реплей лога вместо видео терминала; Blender-экран с прокруткой через Mapping.
**Статус:** мастер, light и превью отрендерены без ожидания «ок» (бриф координатора), отчёт отправлен.

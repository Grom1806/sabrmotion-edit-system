# Как вести брендбуки клиентов

Since 2026-10-08 the user edits reels for different clients. Brand kits live on the PC in
`C:\Users\subhan\Desktop\subhan\claude-edit\branding\`: README.md (index table of clients),
`_template\` (brand.md + logo\, fonts\, assets\, refs\). One subfolder per company, named after it.

**Why:** each client has its own colors, fonts, logo, tone.
**How to apply:** when the user sends a brand, copy _template to branding\<Company>\, file the
materials, fill brand.md, add a row to README's table. Edit by brand ONLY when the user says so;
brand rules override house style [[reference-style]]. Append client feedback to brand.md section 8.

# QA перед показом

2026-10-11: пользователь видел, что элементы попадают в слово только иногда, и был глитч.

Перед показом **любой** версии:
1. Каждая графика, субтитр и SFX синхронизированы с таймингами слов (whisper word timings).
2. Покадровый просмотр мест входа/выхода графики, нет мерцаний, пустых кадров, прыжков.
3. Громкость: ~-14 LUFS, True Peak ≤ -1.
4. Чек-лист из [[reference-style-guide]] (для Мощный/Ультра) или [[motion-tiers]] (проверка смысла).
5. **Анти-ИИ проверка** по [[anti-ai-qa]] (с 2026-10-19, система v2): не похоже на шаблон, есть идея, паузы, реальный материал, SFX в норме.
См. также [[variety]], [[SYSTEM]].

**Дополнения из правок пользователя (2026-10-18…19):** первый кадр хука не пустой; 3D-объекты (телефоны) не пересекаются ни в одном кадре; рамки подсветки ровно по ячейке; маршрут/стрелка стартует из своей точки; нет служебных подписей-заглушек («сумма сумма»); текст не выходит за блоки и поля во ВСЁМ ролике; резкость проверять на 100 % (вьювер Full), крупный текст не обрезается при ударе камеры; зеркальных цифр при поворотах нет.

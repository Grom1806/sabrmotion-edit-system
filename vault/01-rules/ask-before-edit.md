# Спросить перед монтажом

**С 2026-10-19 главный способ — [[control-panel]]:** пользователь заполняет «Пульт монтажа» (https://claude.ai/artifact/9KKFp4QoCgF5JJLVcrLSA3), Claude читает `state/current` через ArtifactData. Карточками спрашиваем только то, чего нет на пульте; ссылку на пульт даём в первом сообщении. Apple снова в списке направлений (D0).

Пользователь хочет меню с несколькими вариантами и уникальные сочетания каждый раз (2026-10-11, 2026-10-18). Система v2 (2026-10-19, [[SYSTEM]]) упрощает вопросы, но добавляет показ стиль-фреймов.

**Формат (2026-10-18/19):** пользователь: «дай мне кнопки, чтобы я нажимал». Каждый вопрос — отдельная карточка `ask_decision` с рекомендованным вариантом. Текстовые ответы вида «a Ультраa a a» неоднозначны — переспросить или взять рекомендованное и сказать какое. На открытый запрос («сделай рилс») сначала 3 идеи с рекомендацией.

**Вопросы:**
0. **Исходное видео (с 2026-10-20, каждый ролик):** есть ли съёмка (говорящая голова / b-roll / экран / фото / только голос / с нуля), где лежит, как снята; без исходника — из чего собирать картинку. Подробно в [[control-panel]].
1. **Направление:** 3 варианта из [[directions-v3]] (приёмы из [[styles-pro]]) под тему (основной стиль + 1–2 приёма), один рекомендован, не повторяет прошлый ролик. Можно смешать.
2. **Уровень:** Минимал / Стандарт / Мощный / Ультра ([[motion-tiers]], плотности [[rhythm-v2]]; нет ответа → **Мощный**: пользователь 2026-10-19 отверг спокойную плотность).
3. **Бренд:** SABRMOTION, PERSET, другой клиент или без бренда ([[client-branding]]). Без бренда → направление из [[directions-v3]] (Apple-стиль больше не по умолчанию).
4. **Цвет:** основные цвета (по умолчанию) или новая палитра/грейд из [[color-palettes-research]] (2–3 варианта, один рекомендован). Пользователь: «главные цвета пусть остаются, пусть каждый раз спрашивает». Самому палитру не менять.

Тип переходов (бесшовный / резы в ритм / смешанный) теперь часть стиля; если пользователь хочет выбрать его отдельно — спросить (он просил 2026-10-18 не решать за него).

**После ответов:** короткий бриф ([[concept-first]]) + 3 стиль-фрейма из After Effects → одобрение → анимация. Если пользователь сказал «делай сам», рекомендованное и без остановки на кадрах, но кадры всё равно приложить к превью.

**Если пользователь не отвечает** (он часто уходит на часы): не парковать ролик. Взять рекомендованные варианты, в брифе блок «что я решил за тебя» + «непроверенное» ([[fact-check]]), сделать мастер и light, в ответе одной строкой назвать выбор. Шаг, который нельзя отменить (публикация, удаление, отправка наружу), ждёт ответа.

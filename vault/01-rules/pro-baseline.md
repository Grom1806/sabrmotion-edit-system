# Арсенал «дорого»

**Пользователь 2026-10-21:** сначала «наш монтаж улучшился… это уже намного лучше, чем раньше», затем уточнение: **«эти техники не обязательно, пусть пользуются тогда, когда подходит в видео»**.

Значит: приёмы из [[pro-advanced-editing]] (одобренное демо `VIDEOS\tests\2026-10-21_pro-techniques-demo`) — **арсенал, а не чек-лист**. Квот нет. Приём берём, только если он помогает смыслу этого ролика.

## Как выбирать (в брифе, на этапе «Идея»)
Для каждого бита задать вопрос: что здесь поможет зрителю понять мысль? Если ответ — один из приёмов ниже, берём; если нет — не берём, даже если «давно не было».
| Приём | Когда подходит | Когда не надо |
|---|---|---|
| Слово за головой (Т1), морф слова (Т2) | хук, одно ключевое слово-тема, есть место над головой | спокойный, доверительный тон, длинная фраза |
| Подпись у головы по треку (Т3), выноска (Т4) | человек перечисляет, называет пункт, цифру, имя | без нового факта — просто дублирует речь |
| Слова из-за головы (Т5), своя 3D-плоскость (Т6) | эмоциональная фраза, поворот мысли, контраст «есть / не у меня» | частое повторение — эффект приедается |
| Текст на плоскости b-roll (Т7) | вставка показывает предмет, к которому относится слово | b-roll — просто фон |
| Смена ракурса | новая мысль, акцент, кульминация | каждый рез «для движения» |
| Сложные переходы П1–П9 | смена места, темы, b-roll ↔ голова | внутри одной мысли — там простой рез |
| Сквозная инфографика | в речи есть растущие/сравниваемые числа | цифр нет — не выдумывать |
| SFX от событий | всегда, когда есть событие на экране | звук без события — никогда |

Уровень ([[motion-tiers]] / Пульт) задаёт, сколько всего: Минимал и Стандарт — 0–2 приёма на ролик, Мощный — несколько, Ультра — по максимуму, но всё равно только к месту. Приёмы ротировать между роликами ([[variety]]): хук, главный переход и главный текстовый ход не повторять из 2–3 прошлых роликов; в уроке — раздел «Взятые приёмы». Общий принцип для всех техник — [[techniques-by-situation]].

**Внутри ролика:** приём — акцент 1–3 сцен, не в каждой сцене и не в двух сценах подряд; часть сцен без приёмов ([[techniques-by-situation]] §«Внутри ролика тоже по-разному»).

## Обязательно — только качество, если приём взят
- Текст сбоку головы — отступ от **края маски**, не от точек лица; не ближе 56 px к краю кадра.
- Слово за головой: базовая линия по верху волос, голова закрывает ≤30 % букв.
- Подписи по трекингу — 3 уровня сглаживания, не дрожат на 0.5×.
- Переходы — с motion blur, пик whoosh на склейке; один тип не подряд.
- Каждый SFX привязан к событию, буква = тик, `sfx_audit.tsv` перед сдачей.
- Резкость и громкость как везде ([[sharpness-guard]], −14 LUFS).

**С 2026-10-24:** высокий профессиональный уровень исполнения — умолчание без просьбы ([[pro-default-quality]]); выбор приёмов остаётся по ситуации.

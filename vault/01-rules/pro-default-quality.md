# Про-монтаж — по умолчанию

**Пользователь 2026-10-24:** «Как у профессионалов… все наши скиллы используй… делай так, чтобы каждый раз я это не говорил».

Это значит: «сделай красиво / профессионально» больше не надо просить. Каждый ролик по умолчанию:

1. **Чистка исходника — всегда.** Неудачное начало, оговорки, запинки, повторы, «э-э», паузы > 0.25 с вырезаются по словам (whisper word timings), без обрубания слов (запас 40–60 мс). Если фраза сказана дважды — берём лучший дубль.
2. **Пульт первым сообщением** ([[ask-before-edit]], [[panel-link-first]]) — с перечнем умолчаний, работа идёт параллельно.
3. **Уровень по умолчанию — «Мощный»** ([[motion-tiers]]), если пульт не задал другой.
4. **Полный конвейер [[SYSTEM]]**: бриф → материал → стиль → сборка → подписи/звук по 07-system → QA → урок. Никаких «упрощённых» версий без просьбы.
5. **Живой монтаж**: плотные резы + смена планов (кроп-зум 1.0 → 1.15–1.35 на новых мыслях, лицо в центре), свип на резких зумах.
6. **Все навыки в ходу**: маска человека (текст за головой), трекинг лица (подписи у головы, выноски), полноэкранные инфографические сцены на числах, 3D-предметы, SFX от событий громко ([[sfx-expressive]]), ассеты из каталога ([[use-everything]]).
7. **Качество не обсуждается**: −14 LUFS, без зерна, резкость ([[sharpness-guard]]), грейд не темнит, оригинальный фон, без музыки, время чтения ([[reading-time]]), QA по кадрам ([[qa-frame-by-frame]]).

## Что НЕ меняется
«Про по умолчанию» ≠ «все приёмы в каждом ролике». Выбор приёмов — по-прежнему **по ситуации** ([[techniques-by-situation]], [[pro-baseline]]): арсенал, не чек-лист; приёмы ротируются между роликами ([[variety]]). По умолчанию поднимается **планка исполнения и полнота конвейера**, а не число эффектов.

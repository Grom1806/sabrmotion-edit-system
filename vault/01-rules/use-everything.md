# Всё в работу

2026-10-19 пользователь: «Скачай ещё ассеты… и дай задачу, чтобы всё это использовалось. Все наши техники, все наши ассеты, все наши вещи должны использоваться». Раньше (2026-10-18) уже было правило «весь vault на максимум каждый раз». Проблема: знания и паки лежат, а в ролик попадает одно и то же. Это правило делает использование проверяемым.

## 1. Перед брифом (этап 0 [[SYSTEM]])
Открыть:
- `claude-edit\assets\КАТАЛОГ.md` (что есть в паках, по темам);
- `claude-edit\assets\_usage.csv` (что уже использовали и когда);
- все `01-rules`, все `07-system`, заметку бренда, 2 последние заметки `04-lessons/reels/`;
- по теме ролика: `rg -il "<тема>" vault/` и папки `assets\icons\_themes\<тема>`, `assets\photos\<тема>`.

## 2. Карта арсенала в брифе (этап 2) — обязательна
В брифе таблица «Что берём из арсенала»: категория → конкретные файлы/заметки → в каком бите → зачем (доказательство, предмет, фактура, ритм). Пустая строка допустима только с причиной («в этом стиле не нужно, потому что…»).

| Категория | Минимум на ролик 30–60 с |
|---|---|
| Фото / фактуры (`assets\photos`, `assets\images`) | 2 (реальный материал против «ИИ-вида», см. [[anti-ai-qa]] п.6) |
| Иконки (линейные / цветные / 3D) | 3, служебно (указатели, пункты списка, UI, подписи к инфографике), не как главная графика ([[SYSTEM]] v3); одно семейство на ролик; 3D-эмодзи только акцент |
| Инфографика (`assets\infographics`) | 1, если в речи есть число, процесс, сравнение, рост или список |
| Карты / флаги | когда звучит страна, город, «по всему миру» |
| Lottie (`assets\lottie`) | 1 микро-анимация (галочка, уведомление, загрузка) |
| SFX (`assets\sfx`; фон — только нашид из `assets\nasheed`, природные звуки запрещены) | по норме [[sound-v2]], минимум 1 файл, который ещё ни разу не звучал |
| Шрифты (`assets\fonts` + бренд) | пара по бренду; без бренда — пара, не повторяющая прошлый ролик |
| Техники vault | направление D1–D6 ([[directions-v3]]) или стиль S01–S13 ([[styles-pro]]), 1 приём бренда ([[brand-moves-table]]), 2 свежих приёма из [[trends-2026-motion-web]] / 03-techniques, палитра или грейд из [[color-playbook]] |

**Ротация (чтобы ничего не лежало мёртвым грузом):** в каждом ролике минимум 1 ассет и 1 техника, которые ещё ни разу не использовались (по `_usage.csv` и заметкам `04-lessons/reels/`). Тот же файл фото/иконки не повторять в двух роликах подряд.

**Границы:** ассеты служат идее ролика ([[concept-first]]), а не украшают. Не обкладывать кадр иконками ради квоты, не нарушать [[keep-original-background]], [[no-music]], [[no-negativity-about-others]]. Квота — нижняя планка для брифа, но если ассет ломает идею, записать причину и не ставить.

## 3. После сборки, перед сдачей (этап 8)
- Сверить готовый ролик с картой арсенала: каждая строка либо в ролике (тайм-код), либо снята с причиной.
- Дописать строки в `claude-edit\assets\_usage.csv`: `дата;ролик;категория;файл или заметка;тайм-код`.
- В заметке ролика `04-lessons/reels/` раздел «Арсенал»: что использовали впервые, что сработало, чего не хватило (что докачать).
- Пункт 19 в [[anti-ai-qa]] проверяет это правило.

Без заполненной карты арсенала и записи в `_usage.csv` ролик не сдаётся.

См. [[SYSTEM]], [[self-learning]], [[variety]], [[assets-library]].

# Формат выдачи

- Выход по умолчанию 9:16, 1080x1920, ~-14 LUFS. 16:9 только по запросу (для Ультра пользователь просил горизонталь).
- Источники разные: вертикаль 60 fps с телефона; DJI 4K 16:9 29.97 (кроп с трекингом лица).
- Монтаж идёт на ПК DESKTOP-NEAHN3N, папка `claude-edit`, через Remote Control. Облако не качает whisper-модели, транскрипция на ПК.
См. [[tools-installed]], [[phone-clips]].

# Камера и ракурсы разрешены

Пользователь (2026-10-20): «можно использовать камеру и ракурсы».

**Разрешено:** push-in, pull-back, панорамы и проезды по кадру/карточке, параллакс, 3D-ракурсы, наклон перспективы, камера как переход между сценами.

**Отменено:** правило «кадр не двигается / движется содержимое, а не кадр» (отзыв «6236», 2026-10-19).

**Урок из старого запрета (остаётся в силе):**
- движение плавное, с motion blur 180°, у каждого проезда есть причина (показать следующий элемент, сменить сцену);
- без десятков резких ударов камеры подряд (39 ударов в Ummah Link ризо — «плохо для глаз»);
- после движения масштаб растров/прекомпов ровно 100 % (settle без вечного затухания, [[sharpness-guard]]);
- крупный текст держать в полях ≥60 px, если обрезка краем не задумана.

Первый ролик по правилу: UI-карточка Sabrmotion ([[2026-10-20-ref-ui-card]]) — виртуальная камера = видимый нуль «Камера» (якорь = точка фокуса, масштаб = зум), дети через `setParentWithJump`.

См. [[SYSTEM]], [[motion-v3]], [[ae-pipeline]].

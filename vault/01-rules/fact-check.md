# Факты только проверенные

- **Цифры продукта** брать из кода/репозитория/сайта (git log, конфиги, premium.json), не из памяти. Пример: «Коран, тафсир и хадисы бесплатно», а не «всё бесплатно» — Premium существует.
- **Исследования** — из первоисточника, ссылка мелко в кадре (arXiv-номер). Если ролик утверждает эффект — по возможности проверить на своём коде; если разницы нет, честно менять текст («фраза не волшебство, а бесплатная страховка»).
- **Эксперимент** реальный, не постановка; цифры в озвучке подгонять под факт (у «Мечети» вышло 3:12 — так и говорить).
- **Время намаза** сверять с Aladhan API (ИИ однажды поставил фаджр 04:24 вместо 04:19).
- **UI-реконструкции** только с реальными данными (скорости, ответы модели — с ПК), ничего не выдумывать.
- **Живой сайт** перед записью экрана открыть и проверить: ummah-link.com падал (Prisma spendLimitReached, React #441 на /study/quran/1 и /study/hadith). При падении снимать только рабочие страницы.
- **Неизвестные цифры** клиента (PERSET invest) — отдельным аудио-куском-заглушкой, чтобы заменить без пересборки.
- В брифе блок «непроверенное» (например «без команды и без инвесторов», «App Store»); такие фразы не усиливать графикой, спросить пользователя.

**Почему:** пользователь публикует ролики под своим именем и для клиентов; ошибка в факте бьёт по доверию. См. [[no-negativity-about-others]].

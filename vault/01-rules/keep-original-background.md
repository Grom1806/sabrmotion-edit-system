# Оригинальный фон

2026-10-12: пользователь отклонил AI-замену фона в ролике Adobe (свет не совпадал). По умолчанию оставлять **реальный фон**, только цветокор ([[color-playbook]]). Замена фона только по прямой просьбе. На уровне Стандарт фон вообще никогда не меняется ([[motion-tiers]]).

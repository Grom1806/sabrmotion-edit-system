# Технические грабли

## Рез говорящей головы (тред 1, проверено)
- Маска речи: порог −30 dBFS, скользящий максимум ±30 мс, речь держится от 110 мс; глухие окончания добирать до 250 мс; границы интервала −20/+30 мс. Тихий исходник (−40 LUFS) — анализ с усилением (+26 dB).
- Паузы от 160 мс сжимать до 50 мс; порог ниже 150 мс не опускать. Рез concat-фильтром с аудиофейдом 15 мс.
- Вдохи перед важными фразами оставлять ([[rhythm-v2]]).

## whisper
- Два дубля одной фразы склеивает в одну строку → проверять фрагментами ≤5 с; пауза >1 с внутри интервала = шов между дублями. Брать дубль, который дословно совпал с расшифровкой.
- На шорохе ткани выдумывает текст («Продолжение следует») — хвосты проверять на слух.
- Якорные слова сравнивать без краевой пунктуации и регистра.
- Облако не скачивает модели whisper (HF заблокирован) — транскрибировать на ПК; silero-vad работает в облаке.

## HyperFrames / GSAP (запасной путь)
- Рендер по умолчанию 30 к/с — прописывать fps исходника. `data-has-audio` на video.
- `gsap_exit_missing_hard_kill`: обёртка `*-in` + `tl.set(..., {autoAlpha:0})` в конце.
- Начальное состояние в `fromTo`, не в CSS. Скрытые autoAlpha-блоки держат высоту → `height:0; overflow:hidden`.
- `--resolution` только повышает DPR; уменьшать кадр отдельным ffmpeg.

## Звук
- Двухпроходный loudnorm, лимитер по true peak, HP 80 Гц, цель −14 LUFS, TP ≤ −1.
- Деноиз не делать, если шум ниже −50 dBFS. Голос не де-реверберировать ([[voice-processing]]).
- Room tone на чистую озвучку не класть (нормализация поднимает его в шум — «День 90» v2).
- Подставлять звук в готовый рендер `-c:v copy`, без перекодирования видео.
- Ударение в ElevenLabs: отдельный mp3 с вариантами названия, выбрать на слух, сравнить длительность/громкость слогов; итог через U+0301 (перСЕ́Т, Субха́н Нуридди́нов). TTS: «Оллама», на экране «Ollama».

## Картинка
- Фото со стоков проверять по разрешению (один сток отдал превью 960 px). Растр не увеличивать >100 % — иначе мыло.
- Пустые первые кадры хука были в 3 рилсах из 5 — первый кадр уже с главным визуалом.
- rotateY 180° даёт зеркальную цифру — менять содержимое на 90°.
- Промпт/текст для скриншота держать на экране ≥2–2.4 с.
- Phone clips: SAR/rotation ([[phone-clips]]); HLG/bt2020 тонмапить в 709.

## Файлы и сессии
- Лимит ~20 МБ на файл в папке проекта: мастер и light (1080×1920 CRF 18) на ПК; в облако — preview 720p ≤20 МБ, если light не влезает.
- Облако → ПК: send_message частями <60 КБ или артефакт с base64 + sha256 (распаковку при блоке делает пользователь). ПК → облако: device_commit/зеркало; проверять, что вложения реально дошли до треда.
- Один рилс = один тред = одна RC-сессия = своя папка; чужие папки не трогать.
- 5 параллельных сессий разом упёрлись в `seat_org_spend_limit` → перед лимитом обновлять `HANDOFF.md` в папке ролика, потом продолжать новой сессией.
- RC-сессия засыпает от простоя — «continue» будит. Wi-Fi на ПК во время RC не выключать.
- Синхронизация уроков: перед перезаписью копий (PC ↔ зеркало) сравнивать и сливать, не перезаписывать вслепую.
- Перед новым роликом прошлый архивировать (`_archive\reelN_*` / [[video-storage]]).

## Два ролика в одном After Effects (2026-10-19)
Когда два треда одновременно собирают ролики, `AfterFX.exe -r` выполняет скрипт в **том проекте, который сейчас открыт**, а не в проекте этого треда. Так preflight «Твоей минуты» прошёл по чужому `quran-115.aep`. Обошлось: 0 изменений, проект только пересохранён, в его `logs\` лёг лишний `sharp_preflight.txt`.

Правило:
- Перед любым `-r` проверить `app.project.file` и сравнить его с путём проекта своего ролика.
- Если открыт чужой проект, работать во втором экземпляре AE: `AfterFX.exe -m`.

## After Effects: один владелец за раз (2026-10-21)
Пользователь спросил, почему AE «перезапускается каждый раз». Причины в ту ночь: (1) две сессии (учёба и Уорд v2) делили один AE и закрывали/перезапускали его друг для друга; (2) новый шрифт (Inter) AE видит только после перезапуска; (3) после ~полуночи AE завис: API отвечает, рендер и saveFrame не пишут, закрыть из Claude нельзя (защита блокирует taskkill) — закрывал пользователь. **Правило:** AE отдаётся одной задаче за раз (очередь между тредами через сообщения), шрифты ставить заранее одним пакетом (`ae\fonts_register.ps1`) до запуска AE, команды слать только после полной загрузки (иначе второй AfterFX). Зависание «API жив, рендер молчит» → сохранить проект копией и сразу попросить пользователя закрыть AE.
